# marketing-skills

Skills-only plugins for marketing work, by Sergey Skripko. Each plugin lives in its own folder under `plugins/` and has its own README, license and privacy note.

| Plugin | What it does |
|---|---|
| [seo-audit](plugins/seo-audit/) | Evidence-based SEO audits of sites, pages, Search Console and crawler exports, and site source code, plus developer-ready fix plans. |
| [ai-seo](plugins/ai-seo/) | Measure how a brand appears and is cited in AI answers: prompt panels, run reports, export analysis, page citability checks, answer gaps, off-site plans. Sample data in [samples/ai-seo](samples/ai-seo/). |
| [copywriting-kit](plugins/copywriting-kit/) | Diagnose, edit and draft marketing copy with a fact lock, a rule-by-rule change log and a proof check against your own evidence. |
| [cold-email](plugins/cold-email/) | Review, check and write cold emails: scorecard with a fact lock, per-row merge QA, sender-setup checks from pasted DNS records. |
| [content-strategy](plugins/content-strategy/) | Decide what to keep, merge or retire, map topics, and plan a quarter that fits your team's hours. |
| [token-saver-kit](plugins/token-saver/) | Short-but-safe answers, session handoff notes, context diet and lossless instruction trimming. |
| [customer-research](plugins/customer-research/) | Interview guides, traceable synthesis, feedback and churn analysis, evidence-backed customer profiles. |
| [site-architecture](plugins/site-architecture/) | Site Architecture Kit: URL trees, links, redirects. |
| [copy-editing](plugins/copy-editing/) | Copyedit & Proof Kit: Proof, copyedit, style, cut. |
| [marketing-ideas](plugins/marketing-ideas/) | Marketing Ideas Kit: Ideas gated on payback. |
| [churn-prevention](plugins/churn-prevention/) | Churn Prevention Kit: Cancel flows, dunning, signals. |
| [ad-creative](plugins/ad-creative/) | Ad Creative Preflight Kit: Ad preflight and test readouts. |
| [marketing-psychology](plugins/marketing-psychology/) | Marketing Psychology Kit: Graded evidence, rule checks. |
| [lead-magnets](plugins/lead-magnets/) | Lead Magnets Kit: Plan, check, read lead magnets. |
| [community-marketing](plugins/community-marketing/) | Community Marketing Kit: Community growth, disclosed. |
| [sales-enablement](plugins/sales-enablement/) | Sales Enablement Kit: Rep practice and coaching. |
| [cro-kit](plugins/cro/) | CRO Audit and Test Kit: Page checks and A/B test math. |
