# marketing-skills

Skills-only plugins for marketing work, by Sergey Skripko. Each plugin lives in its own folder under `plugins/` and has its own README, license and privacy note.

| Plugin | What it does |
|---|---|
| [seo-audit](plugins/seo-audit/) | Evidence-based SEO audits of sites, pages, Search Console and crawler exports, and site source code, plus developer-ready fix plans. |
| [ai-seo](plugins/ai-seo/) | Measure how a brand appears and is cited in AI answers: prompt panels, run reports, export analysis, page citability checks, answer gaps, off-site plans. Sample data in [samples/ai-seo](samples/ai-seo/). |
| [copywriting-kit](plugins/copywriting-kit/) | Diagnose, edit and draft marketing copy with a fact lock, a rule-by-rule change log and a proof check against your own evidence. |

## Install in Claude Code

```
/plugin marketplace add grayskripko/marketing-skills
/plugin install seo-audit@marketing-skills
/plugin install ai-seo@marketing-skills
/plugin install copywriting-kit@marketing-skills
```
