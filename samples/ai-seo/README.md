# Sample files for the ai-seo plugin

All brands, domains and numbers here are fictional. Use them to try the plugin without your own data.

- `panel-runs-2026-08.csv`, `panel-runs-2026-09.csv`: two months of logged prompt-panel runs for three engines. Try: "Score these two panel logs. Which changes are real, and who is cited instead of us?" (skill: ai-visibility-report)
- `bing-ai-pages.csv`, `page-value.csv`, `gsc-genai-pages.csv`: an AI citation export, a page value list and AI-feature impressions. Try: "Here is our AI citation export and page value list. Which pages should we improve first?" (skill: ai-citation-data)
