# Privacy

Marketing Psychology Kit is a set of instructions and reference text for an AI assistant. It has no server, no account and no storage of its own.

- Network scope: this plugin ships no code and calls no service of its own. It reads what you paste or attach; when you give a public URL and your assistant has a web-fetch tool, it reads that page and at most four more public pages you name, with no logins or forms and robots.txt respected. Without a fetch tool it asks you to paste the text. It changes no files or settings unless you ask. For arithmetic, price-framing and behavior-diagnosis may use your assistant's own code tool when one is available; that code runs only in your session and sends nothing anywhere.
- Categories of data: the plugin collects none. What you paste is typically page text, prices, flow descriptions, step counts and customer quotes. Remove customer names and emails before pasting; if any remain, the skills replace them with labels and never repeat them.
- Purpose: producing the audit, check or table you ask for, during that conversation.
- Recipients: what you paste goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends it nowhere else.
- Retention: the plugin keeps nothing. Retention of your conversation is set by your assistant provider.
- Your controls: paste only what the task needs, strip personal data first, and do not paste anything you are not allowed to share.
