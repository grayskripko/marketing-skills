# Three ethics tests

Run them on every element marked Fix or Remove, on every High or Medium register row, and on every new lever the plugin suggests. Print only the tests that fail or cannot be decided, one line each with the fact that would decide it; passes are not printed.

1. Disclosure: would the element still work, and would the customer be fine with it, if they were told plainly how and why it is there? A mechanic that only works while hidden fails. A deadline that is real passes; a timer that restarts for each visitor fails.
2. Reversal: can the customer undo the result as easily as they did it? One-click sign-up with cancellation only by phone fails.
3. Truth: is every fact the element implies true today? "Most popular" needs a real basis; "only 2 left" needs a live count.

A failed test makes the honest version mandatory in the output: the element needs its fact fixed or the element removed. It is not a legal finding; legal rows come from `rule-register.md`.
