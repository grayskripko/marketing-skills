# Privacy

RevOps Metrics & Forecast Accuracy is a set of instructions and reference text for an AI assistant. It has no server, no account and no storage of its own.

- Network scope: this plugin fetches nothing and runs no web search. It works only on data you paste or attach, runs no scripts of its own, changes no files or settings unless you ask, and uses the assistant's code or spreadsheet tool to compute the tables it shows.
- Categories of data: whatever you paste, typically deal, lead and account ids, amounts, dates, stages, sources and segments. Exports may also contain owner names or contact names, emails and phone numbers; the skills do not need these.
- Purpose: computing the tables you ask for, during that conversation.
- Recipients: the data goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends it nowhere else.
- Retention: the plugin keeps nothing. Retention of your conversation is set by your assistant provider.
- Your controls: remove contact and owner columns before pasting; you can replace account names with labels such as A1, A2.
