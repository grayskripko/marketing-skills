# Privacy: Export Cleanup

This package contains instructions and references. It runs no service and ships no executable code.

- Data: supplied CSV/XLSX files and pasted rows may contain names, contacts, financial records and sensitive free text. Only task-needed data should be supplied. Credentials are never needed.
- Purpose: inspect, clean, combine and review authorized exports, and save a reusable recipe.
- Recipients: the chosen AI host processes conversations and uploads under its own terms. Nothing is sent to a plugin-operated service.
- Storage: the plugin has no independent retention. The host handles conversation and uploaded-file retention under its own terms. When requested, host tools create cleaned copies and recipes in the user's workspace. Original files remain unchanged; those copies persist until the user removes them.
- Controls: users can minimize or redact inputs before supplying them. Host conversation deletion and local file deletion are separate controls.
- Network scope: none. No URLs are fetched; no telemetry, live connections, external uploads, accounts or paid APIs are required. Free local processing tools may be needed; setup is user-controlled and separate from processing exports.
