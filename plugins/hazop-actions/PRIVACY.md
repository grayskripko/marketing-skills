# Privacy

HAZOP Actions is a skills-only package: Markdown instructions, one reference file, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, servers, connectors or hooks, and installing it runs no program.

It works only on the worksheet rows, tracker rows and closure records you provide for the task, pasted or attached. It makes no network requests: no web search, URL fetching, uploads, account connections or telemetry.

The publisher receives no data and runs no collection or storage service for this plugin. Your conversation is processed and retained under your assistant provider's own settings. Personal names of action owners are not needed for the checks; you can replace them with roles or initials.
