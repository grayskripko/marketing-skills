# Fact pack template

A set of true facts for consistent use. Fill only supplied or public-page facts; omit optional missing fields rather than asking for the rest.

| Field | Approved content | Evidence status / supplied public proof |
|---|---|---|
| One-sentence description | What the company does, for whom, where | |
| Good fit | The customers and use cases it suits | |
| Not a fit | Cases where another type of product is a better choice | |
| Key features | Three to five, each with a concrete detail | |
| Public pricing | As published, with the date checked | |
| Limits | Known limits a buyer should know | |
| Differences | What it does differently, stated as facts, without comparisons to named competitors | |
| Proof | Case studies, customer names or figures the user can publish | |
| Company facts | Founded, headquarters, size range, as the user states | |
| Contact for corrections | A role or channel, not a personal address, unless the user provides one | |

Rules:
- Leave out optional unsupported rows; ask only for missing facts necessary for the requested deliverable. Supplied facts support internal drafts even when public proof is not supplied; mark proof needs only where required for external use.
- Include supplied suitability exclusions when relevant. Ask for missing exclusions only when suitability or the destination's requirements make them necessary for the requested deliverable; otherwise omit the row without inventing exclusions.
- Keep one version and date it; update it when facts change.
