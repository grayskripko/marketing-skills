# Rewrite patterns

Rewrites use only page or supplied facts and preserve their exact scope. When a necessary detail is missing, state it in one plain sentence and still give the complete answer, with any assumption clearly marked; never put bracketed placeholders or fill-in slots in the text. Omit optional unknowns and add no unsupported claims.

## Patterns

1. **Answer first.** Default: 1-2 sentences immediately answer the heading, then detail. Use additional sentences when the supplied claim has material conditions/exceptions that cannot fit without changing its scope; keep those conditions with the answer. State the extended treatment only when needed to explain a requested length constraint.
2. **Stand alone.** Replace "as mentioned above", "this", "it" and "they" that point outside the section with the thing they refer to. A reader landing on the section should not need the previous one.
3. **Claim, reason, limit, example.** Each key paragraph states the claim, why it holds, where it stops holding, and one example or source. The limit is what makes a passage safe to quote.
4. **Specifics over adjectives.** Replace "fast", "flexible" or "powerful" with the number, condition or feature the user can confirm; if none is supplied, say which fact is missing in one plain sentence.
5. **Use the requested shape.** Use a table when a comparison needs one or the user asks for it. Do not repeat the same simple facts in prose and a table. For requested ready-to-paste sections, give each section once, name the product, and keep evidence notes outside the copy.
6. **Name the source.** Say who the company is and what the page is in plain words near the top.
7. **Dates that match edits.** Show an updated date only when the content changed, and update the facts that date refers to.

## Output format for each rewrite

Give the requested ready-to-paste text or markup directly. Explain only changes needed to interpret or apply it, outside the copy. Use a passage/evidence/rewrite table only when requested, not as a default wrapper. Do not add missing-facts columns or questions when the supplied facts suffice.

Default: up to 3 rewrites for the weakest distinct checks. Use the user’s complete requested passage list when supplied, or fewer when fewer weaknesses exist. Preserve meaning, conditions and tone; add no sales claims.
