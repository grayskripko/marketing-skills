# Gap matrix template

## Matrix

| # | Sub-question | Source label | Covered on our page? | Where on our page | Cited instead | Fact in the answers | Class | Action |
|---|---|---|---|---|---|---|---|---|
| 1 | How many approvers can an invoice need? | from plan | no | — | vendor-docs.example | "up to 3 approvers" | not covered | Add a short answer under "Approval rules" |
| 2 | What happens when an approver is away? | inferred | partly | "Delegation" section, paragraph 2 | review-site.example | delegation to a backup | covered but not cited | Page check on the "Delegation" section |

- **Source label**: `from plan` when the sub-question came from a research plan the user pasted; `inferred` when you decomposed the query yourself.
- **Covered on our page?**: yes, partly or no, judged from the page text only.
- **Cited instead**: the source the pasted answers cite for that sub-question, or "none shown".
- **Fact in the answers**: what the pasted answers say, briefly. Quote nothing longer than a short phrase.

## Classes

| Class | Meaning | Next step |
|---|---|---|
| not covered | The page does not answer the sub-question | Add content, if it serves the query's intent |
| covered but not cited | The page answers it, but the answers cite others | Run the page check on that section |
| wrong about the brand | An answer states something false about the brand | Correct owned pages; ask the cited source to correct it through the off-site plan |

## Ranked additions

Rank by: wrong-about-the-brand items first (accuracy), then sub-questions that most readers of the query need, then the rest. For each addition, name the facts the user must supply. Never write that the change will make an engine cite the page.
