- **Source label**: `from plan` when the sub-question came from a research plan the user pasted; `inferred` when you decomposed the query yourself.
- **Covered on our page?**: yes, partly or no, judged from the page text only.
- **Cited instead**: the source the pasted answers cite for that sub-question, or "none shown".
- **Fact in the answers**: what the pasted answers say, briefly. Quote nothing longer than a short phrase.

## Classes

| Class | Meaning | Next step |
|---|---|---|
| not covered | The page does not answer the sub-question | Add content, if it serves the query's intent |
| covered but not cited | The page answers it, but the answers cite others | Record the observation; recommend a section check only when supplied evidence identifies an issue or the user requests one |
| wrong about the brand | An answer states something false about the brand | Correct owned text only if wrong or unclear; request a cited-source correction only when its own text is confirmed wrong |

## Ranked additions

Rank by the requested goal: for “what to add first”, prioritize the missing requirement over rearranging covered facts, and separately correct false copied-answer claims. Name missing facts only when necessary for the requested addition. Never write that the change will make an engine cite the page.
