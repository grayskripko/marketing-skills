# Privacy policy: AI Search Visibility Kit

Effective date: 2026-10-08.

AI Search Visibility Kit is a set of instructions and reference documents for an AI assistant. It contains no code that runs, no server, no analytics and no tracking. The publisher receives nothing from your use of it.

| Topic | Answer |
|---|---|
| Categories of personal data collected | None. |
| Purposes of processing | None, because nothing is collected. |
| Recipients or third parties | None. The plugin sends data nowhere. |
| Retention | None. The plugin stores nothing. |
| Your controls | None needed. You can remove the plugin at any time; nothing remains. |

## What happens when you use it

- Network scope: this plugin fetches only URLs you type or paste, including URLs inside logs or exports you paste, plus the robots.txt file of those sites. It fetches public pages only, never logs in or submits forms, and skips paths a site's robots.txt disallows. At most 10 page fetches per run; robots.txt files do not count. Web search is used only when you explicitly ask for it, at most 10 queries per run, and every query is listed in the output. The plugin never queries AI answer engines, runs no code of its own and stores nothing; if the assistant has a code or spreadsheet tool, it may use it to compute the tables you see.
- Any fetching or searching is done by the assistant's own tools under the assistant provider's privacy terms, not by this plugin.
- Brand and competitor names, logs, exports and answers you paste stay in your conversation with the assistant, under the assistant provider's privacy terms.
- Before sharing analytics exports, remove personal data such as user IDs or email addresses. If pasted material still names private people or shows their emails or user IDs, the skills do not repeat them: they refer to Person 1, Person 2 and ask you to remove such data before the next paste.
