# Funnel leaks

Open with the answer: which step or segment to prioritise and what it is worth, in the user's numbers.

- Compute each step rate and show the arithmetic once.
- When periods differ, check whether segment rates moved or only the traffic mix did; if rates held, say the mix explains the drop and point at the traffic change, not at a redesign.
- Size stakes against the reference the user gave, actionable target first, then any stronger segment or earlier period, as "at unchanged volume, not a forecast". Show the resulting totals.
- Keep the user's real goal in view (completed versus qualified signups, orders versus paid orders).
- Next step: what to inspect or observe at that step to find the cause. Add test sizing only if the user asks about testing.
- No industry benchmarks as targets.
