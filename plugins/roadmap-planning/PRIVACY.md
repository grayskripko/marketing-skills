# Privacy: Roadmap Planning

This package supplies Markdown instructions and references, JSON metadata, a static SVG icon and a license; it bundles no executable scripts, solver, installer, dependency, hook, MCP/LSP server, or background process, and installation runs no program or account connection. All four skills work from data you provide for this task, pasted or as the export you name or attach for this request, and may use your assistant's existing local tools only to read that export and bundled references and calculate, which may execute code and create temporary tool artifacts in the assistant provider's environment; the decision model permits host calculation tools and explains CP-SAT results if that solver is used, without requiring or installing it. The skills request no web search, URL or robots.txt retrieval, API calls, account access, message delivery, tracker updates, publication, settings changes, or file writes. Source and support URLs are references only; supply relevant URL content as text, and linked decision procedures are bundled local Markdown. The publisher operates no collection, telemetry, or storage service and receives no task data; your assistant provider processes supplied backlog material, request text and tool inputs/artifacts under its own processing and retention terms. Any output file you explicitly request is saved by the assistant's existing file tools and remains under your control. Remove unnecessary customer or employee identifiers and credentials before supplying backlog rows. The skills do not scan folders or projects, read every attachment, or use memory, chat history, conversation summaries or Claude conversation exports. Development scripts and evaluation records are outside the plugin folder.
