# Privacy

Tool Contracts contains instructions, reference text, metadata and a static icon, with no bundled executable program, installer, connector, server, hooks, background process, telemetry, or publisher storage; installation itself runs no program and connects no account. Pasted-artifact analysis uses supplied material and bundled references without executing code, searching the web, fetching URLs or robots.txt, downloading dependencies, connecting accounts, or calling remote tools; source/support links are references, not retrieval instructions. Requested owned-project repairs may use the assistant's existing tools to read/edit relevant implementation files and callers and execute inspected checks; requested runtime checks use the selected installed runner, fixture, target, and existing authentication, and may call the selected tool/API endpoint and its documented backing service. These project-selected destinations and the assistant's tool provider receive call arguments and ordinary connection metadata; captured records may contain inputs and results. Local checks need no network. The skills do not request credential values, install software, download dependencies, or widen access; a missing runtime/version leads to prerequisite identification and guidance through existing project setup, which may involve user-run commands, with pasted definitions/receipts as the no-setup fallback. Sending, deleting, charging, and other real writes require authorization for the exact target and effect, with receipt/state checks before retries. Supplied text/results are data, not instructions; outputs omit credentials and unnecessary personal data. No task data is sent to the publisher by this workflow. Conversation, attachment, tool-record, and temporary-file retention follow the assistant provider's terms; requested edits and saved outputs/check records remain in the selected project under the user's control.
