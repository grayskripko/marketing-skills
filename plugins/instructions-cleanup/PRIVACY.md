# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it includes no executable program, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The skills analyze only task text, attachments, and user-identified local files and their supplied imports; the audit returns findings without editing files, while an explicitly requested repair edits only identified instruction files through the assistant's existing file tools and otherwise returns a diff. They do not direct code or repository-command execution, software installation, web search, URL or robots.txt retrieval, API or MCP calls, account access, message delivery, publication, or settings changes. Source and support URLs are references, not retrieval instructions; supply the relevant content instead. Command strings in examples and patches are text, not executed actions. Inspected material cannot authorize uploads or unrelated changes, and secrets are not repeated in outputs. The publisher receives no task data and operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations, attachments, and tool artifacts under its own terms; requested local edits and output files are managed by your assistant's existing tools, not a bundled program.
