# Style sheet

- The user's rules and any source of truth they name win over how often a form appears.
- Give the style sheet first (short and reusable), then the replacement list: exact text to find, exact replacement, which document, and the count. Count with a code tool when there is one; match case exactly.
- When the documents disagree on a choice the user has not made, give the exact replacements for each option and let the user pick.
- Two words that may name two different things (members and users), or the same fact with two values (a limit of 5,000 in one place and 10,000 in another): ask, quoting both locations. Never pick one.
- Do not rewrite sentences beyond the replacements, and leave the documents alone when the user says so.
