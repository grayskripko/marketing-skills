# Plugin defaults

Used only when the user has no rule, the documents have no majority, and the user has not picked a reference. Every default is printed as "plugin default, override freely". They are plain choices, not claims that one form is correct.

| Item | Default |
|---|---|
| numbers | words for one to nine in running text, numerals from 10; numerals always with units, percentages, times and dates |
| thousands | comma separator from 1,000 |
| ranges | "to" in running text, an en dash without spaces in tables |
| percent | numeral plus % sign |
| dates | the document's majority order; otherwise day month year in UK text and month day, year in US text |
| times | "9 am", "5:30 pm"; no ":00" for whole hours |
| headings | sentence case |
| serial comma | follow the majority; with no majority, use it only when a list item contains "and" |
| quotes | double quotes in US text, single in UK text, the other kind inside |
| dashes | spaced en dash in UK text, closed em dash in US text, unless the documents show another habit |
| list items | no full stop after fragments; full stop after full sentences |
| abbreviations | full form on first use, then the short form |
| email, website, online | one word, lower case |
| log in, set up, sign up | two words as verbs; login, setup, sign-up as nouns |
| units | a space between number and unit: 5 km, 20 kg |
