# Wordy phrases and shorter forms

Swap only when meaning, tone and any obligation stay the same. Grouped by what the phrase does; within a group, no fixed order of priority.

## Time

| Long | Short |
|---|---|
| at this point in time | now |
| at the present moment | now |
| prior to the start of | before |
| prior to | before |
| subsequent to | after |
| in the near future | soon (or give the date) |
| on a daily basis | daily |
| on a monthly basis | monthly |
| for the duration of | during |
| until such time as | until |
| at an earlier date | earlier |

## Connectors and framing

| Long | Short |
|---|---|
| in relation to | about |
| with regard to | about |
| on the subject of | about |
| in the event that | if |
| on condition that | if (check: may carry an obligation) |
| in spite of the fact that | although |
| regardless of the fact that | although |
| by means of | by, with |
| by virtue of | by, because of |
| in the case of | for |
| is able to | can |
| has the ability to | can |
| it is recommended that you | you should (keep the strength of the advice) |
| whether or not | whether, when "or not" adds nothing |
| in lieu of | instead of |
| in a timely manner | promptly, or give the deadline |
| it is important to note that | (drop) |
| please be advised that | (drop) |
| it should be noted that | (drop) |
| what this means is that | (drop, or "so") |
| the fact of the matter is | (drop) |
