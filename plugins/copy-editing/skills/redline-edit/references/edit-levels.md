# Edit levels and change categories

The three levels below are this plugin's own working definitions. The type labels borrow three of the nine edit-type names (mechanical style, language, substantive) listed in Van Buren and Buehler, The Levels of Edit, 2nd ed., JPL Publication 80-1, 1980 (abstract on NASA's technical reports server, read 2026-10-03). Never work above the level asked; work that would need a higher level becomes a query.

## What each level does

| Work | Light | Medium | Heavy |
|---|---|---|---|
| spelling, grammar, punctuation, confusables | yes | yes | yes |
| consistency inside the text | yes | yes | yes |
| dates, counts, totals computed | yes | yes | yes |
| ambiguity | query | rewrite the sentence, query if meaning could move | same as medium |
| wordy phrases | no | yes | yes |
| parallel lists | only broken grammar | yes | yes |
| abbreviations expanded on first use | no | yes | yes |
| sentence-level clarity | no | yes | yes |
| plain-language checks before and after | no | yes | yes |
| main point first inside a section | no | no | yes |
| headings that say what follows | no | no | yes |
| splitting overloaded paragraphs | no | no | yes |
| moving text across sections | no | no | query |
| adding or removing a claim | no | no | query |

## Change categories

| id | Category | Type | Example |
|---|---|---|---|
| CE-01 | spelling | mechanical | "seperate" → "separate" |
| CE-02 | grammar and agreement | language | "each of the desks have" → "has" |
| CE-03 | confusables | language | "loose your badge" → "lose" |
| CE-04 | punctuation | mechanical | missing closing bracket |
| CE-05 | capitals | mechanical | "Monday Through Friday" in running text |
| CE-06 | numbers and units | mechanical | "5km" → "5 km" if the sheet says so |
| CE-07 | dates and times | mechanical | weekday query; "9.00am" formats |
| CE-08 | abbreviations | mechanical | expand on first use (medium and up) |
| CE-09 | compounds and hyphens | mechanical | "a two week trial" → "a two-week trial" |
| CE-10 | lists and parallel structure | language | "booking, to pay, and cancel" → "book, pay and cancel" |
| CE-11 | pronoun reference and dangling modifiers | language | "they" with two possible owners → query |
| CE-12 | repetition | language | the same point twice in one paragraph |
| CE-13 | clarity | language | a sentence readers must parse twice (medium and up) |
| CE-14 | order | substantive | main point moved up within the section (heavy) |
| CE-15 | residue | mechanical | "Sure, here is your text:"; stray `**`; a placeholder left in |
| Q-MSG | persuasion issue | none | query only, "outside a copyedit" |

## Reasons

Each logged change carries one short reason that names the reader's benefit or the rule: "agreement with 'each'", "the reader needs the deadline before the steps".

## Sounds-like-AI requests

Only CE-15 applies. No list of "AI words" is used, and nothing is stripped for sounding machine-made.
