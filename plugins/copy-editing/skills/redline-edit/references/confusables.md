# Confusable words

Fix only when the sentence leaves one reading. If both fit, query.

| Pair | Quick test |
|---|---|
| its / it's | expand to "it is" or "it has"; if that fits, use "it's" |
| your / you're | expand to "you are" |
| their / there / they're | "they're" = they are; "there" = a place or "there is"; "their" = belonging to them |
| whose / who's | "who's" = who is or who has |
| affect / effect | as verbs, "affect" = influence, "effect" = bring about; as a noun, usually "effect" |
| accept / except | "except" leaves something out |
| advice / advise | noun ends in -ice, verb in -ise (both variants) |
| practice / practise | UK: noun -ice, verb -ise; US: -ice for both |
| licence / license | UK: noun -ce, verb -se; US: -se for both |
| complement / compliment | "complement" completes; "compliment" praises |
| principal / principle | "principle" is a rule; "principal" is main, or a head of school |
| stationary / stationery | stationery is paper and pens |
| discreet / discrete | discrete = separate; discreet = tactful |
| ensure / insure | insure = cover with a policy |
| assure / ensure | you assure a person; you ensure an outcome |
| lose / loose | "lose" = misplace; "loose" = not tight |
| then / than | "than" compares |
| fewer / less | fewer for things you count; less for amounts (time and money are amounts) |
| lead / led | past tense of the verb "to lead" is "led" |
| passed / past | "passed" is the verb; "past" is time or position |
| breath / breathe | "breathe" is the verb |
| loath / loathe | loath = unwilling; loathe = hate |
| elicit / illicit | elicit = draw out |
| eminent / imminent | imminent = about to happen |
| canvas / canvass | canvass = ask for votes or opinions |
| cite / site / sight | cite = quote a source |
| capital / capitol | capitol = a building (US) |
| council / counsel | counsel = advice or a lawyer |
| dependant / dependent | UK noun "dependant" = a person; adjective "dependent" in both variants |
| everyday / every day | one word = ordinary; two words = each day |
| any one / anyone | "any one" = any single item |
| may be / maybe | "maybe" = perhaps |
| log in / login | verb two words; noun or adjective one word |
| set up / setup | verb two words; noun one word |
| sign up / sign-up | verb two words; noun often hyphenated |
| check in / check-in | verb two words; noun hyphenated |
| back up / backup | verb two words; noun one word |
| on to / onto | "onto" = to a position on |
| in to / into | "into" = movement inside |
| to / too | "too" = also, or excessively |
| i.e. / e.g. | i.e. restates; e.g. gives examples |
| farther / further | farther for physical distance in US usage; further for extent |
| historic / historical | historic = important in history |
| comprise / compose | the whole comprises the parts; the parts compose the whole |
| flaunt / flout | flout = break a rule |
| pore / pour | you pore over a document |
| peak / peek / pique | pique interest; peek = look; peak = top |
| reign / rein | you rein in costs |
| tenant / tenet | tenet = belief |
| wave / waive | waive a fee |
| bated / baited | with bated breath |
| premier / premiere | premiere = first showing |
| aid / aide | aide = assistant |
| altogether / all together | all together = as a group |
| alright / all right | "all right" is the safe form; "alright" is a style choice |
| who / whom | whom if "him" would fit |
| amount / number | number for countable things |
| between / among | between two or distinct items; among a group |
| imply / infer | the speaker implies; the listener infers |
| precede / proceed | precede = come before; proceed = go on |
| weather / whether | "whether" = if |
| appraise / apprise | apprise = inform |
| allude / elude | elude = escape |
| disinterested / uninterested | disinterested = impartial |
| emigrate / immigrate | emigrate = leave a country |
| a while / awhile | "a while" after a preposition ("for a while") |
| which / that | many US houses use "that" for defining clauses: a house choice, not an error, unless the commas are wrong |
