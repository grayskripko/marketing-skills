# Cut to length

- Count with a code tool when there is one. "At most N" or "no more than N" allows N; "under N" means fewer than N. Hyphenated words count as one word; say how you counted only if it matters.
- Keep every item the user names exactly as written, qualifiers and units included ("more than 15 years" never becomes "15+ years").
- Within the limit, keep as much practical information as possible. Shorten wording before dropping facts: drop repetition and lead-ins, use compact phrasing, and use the spare words rather than leaving them unused.
- If the limit cannot be met, say so in one line and give the truly shortest usable version. Try each way of joining the kept phrases (different punctuation, with and without spaces) and count each one.
- Give: the shorter text, its exact count, and what readers lose, honestly. Do not say nothing is lost when a fact went.
- When the user asks for the cuts, list each one with the words or characters it saved, measured on the actual text, and make the savings add up to the difference.
