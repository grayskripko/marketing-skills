# Privacy: SKU Margin

The seller-analysis skills process only text, attachments and local files you explicitly supply, plus bundled method notes; they do not direct web search, URL or robots.txt retrieval, API calls, software installation, account connections, message delivery, publishing, repricing or ad-account changes. Your assistant's existing file-reading, OCR and local calculation tools may read those inputs and create a worksheet or output file you request in your workspace; execution, temporary files, conversation and attachment retention are controlled by your assistant provider under its own terms. The publisher operates no collection, telemetry or storage service for these skills and receives no task data. Repository and support URLs are references, not seller-workflow endpoints. Supply only needed seller records, redact buyer names and contact details, never supply credentials, and remove downloaded workpapers separately using your host and workspace controls. Support: https://github.com/grayskripko/marketing-skills/issues
