# Privacy: Cold Email Kit

This plugin is a set of instructions and reference text. It ships no code and runs no service of its own.

- Categories of personal data: it reads what you paste, which can include names, job roles, company details, email addresses and reply text about your prospects and recipients. It does not ask for more than the task needs; email addresses are never required.
- Purpose: to review, check and draft your own outreach emails in the current conversation.
- Recipients: none beyond the AI assistant you are already using, whose provider processes your conversation under its own terms. The plugin sends nothing anywhere.
- Retention: the plugin stores nothing. Your assistant's own conversation retention applies.
- Controls: redact names and addresses before pasting when the task does not need them; you can delete the conversation in your assistant.
- Network scope: only the cold-email-hooks skill fetches anything, and only public pages at URLs you give, at most 3 public pages per run, one request each plus the site's robots.txt, following no links and never logging in; a page the site's robots.txt disallows is not fetched. No skill runs a web search. The plugin sends no email, looks up no address, runs no DNS query, calls no other service and stores nothing; if your assistant has a code tool, it may use it to count words and rows.
