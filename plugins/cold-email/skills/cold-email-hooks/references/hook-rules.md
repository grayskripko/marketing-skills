# Hook rules

## Keep a fact only if it is
- sourced: from the user's notes (including what the prospect told the user directly) or a page the user linked;
- dated, or clearly current;
- public or shared with the user directly, and about the company or the person's work;
- true without implying any relationship with the sender.

## Drop, with the reason
| Reason | Example |
|---|---|
| Stale | Older than 12 months (heuristic) |
| Personal life | Family, health, holidays, hobbies unrelated to work |
| Unsourced | Not in the notes or the linked page |
| Private | Information about the person that was neither published by them nor shared with the user directly (for example leaked, scraped or third-party personal data). What the prospect told the user directly, and the user confirms, is kept. |
| Implied relationship | "We both know X", "as we discussed" without confirmation |
| Generic | True of everyone in the segment |

## Relevance (for kept facts; generic facts are dropped above)
- 1: true and work-related, but unrelated to the problem the offer solves.
- 2: connected to the problem the offer solves (a hiring post for the role the product supports, a public statement about the pain).

## Opening line
One plain sentence that states the fact and connects it to the reader's problem. No compliments, no "I noticed you", no claim that the sender read everything the person wrote.
