# Offer brief template

Use these fields internally; print this table only when the user requests a field table. Otherwise produce the requested concise brief and fixes.

| Field | What goes here |
|---|---|
| Who | Observable role/company criteria, credible shared relevance and reachable accounts appropriate to the user's objective; a small viable segment need not contain ten companies |
| Trigger event | What recently happened that makes the problem current (hiring, a launch, a price change, a new rule) |
| Pain in the buyer's words | How the reader would describe the problem, taken from the user's notes where possible |
| Mechanism sentence | Explain how a claimed outcome is produced when pitching that outcome. For exploratory or transactional outreach, state the concrete proposition, relevance and next step instead; do not invent a mechanism |
| Result | What changes for the reader, stated only as far as the user's facts support |
| Proof inventory | Each proof item with its source; "none yet" if there is none |
| Reason to act now | Only a real reason from the user's material; otherwise "none" |
| One ask | One clear next step with effort appropriate to the email recipient, offer and user's objective |
| Not a fit when | Who should not get this email |
