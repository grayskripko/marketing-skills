# Privacy: Lawyer Meetings

This skills-only package contains Markdown instructions and reference text, JSON metadata and a static SVG icon; it provides no executable program, dependencies, installer, hooks, MCP or LSP server, background process or account connector. Its skills analyze only authorized task text, attachments and local files explicitly supplied by the user, together with bundled dated references; they do not instruct code execution, software installation, web search, URL or robots.txt retrieval, API calls, account access, message delivery, filing, publishing or settings changes. Public source and support URLs are reference text, not retrieval endpoints; paste relevant content when a supplied link is insufficient. The assistant's existing file readers and optional OCR process supplied files, with key scan passages checked against the image; explicitly requested output files are written only to the user's requested destination, otherwise results stay in the conversation, and originals are not overwritten or deleted. The publisher receives no task data and operates no collection, telemetry or storage service; the assistant provider processes and may retain conversations, attachments and tool data under its own terms, and requested output files remain in the chosen destination until removed. This is not a promise of wholly local assistant processing or legal privilege. Remove unnecessary personal and financial details and credentials before supplying material, keep necessary party names for the lawyer's conflict check, and review outputs before sharing.
