# Privacy

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installing it runs no program or account connection. The assistant analyzes records you paste or explicitly supply, may read authorized named local files and bundled references using its existing file tools, and may save a deliverable only to a destination you request; it does not search for unrelated sessions. The skills prohibit assistant web retrieval, web search, connector or service API calls, runtime installation, permission changes, agent restarts, process cancellation, sending, publishing, checkpoint edits and action replays. Documentation and support URLs are references, not runtime retrieval instructions. Plans may ask you for host inspection/export evidence and propose operator resume commands or SDK state-restoration steps; the skills do not execute them. If you execute a plan, your existing runtime may run code, contact configured providers or services, write files or repeat external effects under its own configuration and your approvals. The publisher receives no task data and operates no collection, telemetry or storage service; your assistant provider processes and may retain conversations and attachments under its own terms. Keep credentials and unnecessary personal data out of supplied records.
