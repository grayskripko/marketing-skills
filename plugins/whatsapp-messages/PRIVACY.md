# Privacy — Chat Replies and Notes

This package contains instructions and reference text. It runs no service and ships no connector.

- Data read: supplied chat excerpts/exports and task context. They may include participant names, phone numbers, dates, messages, business details and sensitive third-party content. Supply only material you are entitled to process; redact unrelated details. Media is unnecessary unless your task depends on it.
- Purpose: summarize supplied conversations, extract decisions/tasks, draft replies and plan setup.
- Recipients: the AI assistant provider processes the conversation and supplied files under its own terms. Local file tools may read supplied files at your request. The package has no additional recipients and makes no account connections.
- Retention: no plugin storage, message archive, telemetry or retention service. Your assistant's conversation/file retention applies. Temporary files created by host tools follow the host's controls.
- Controls: use participant labels and redacted excerpts; omit attachments; remove uploaded files and conversations using your assistant's controls. Export possession does not establish permission for every downstream use.
- Network scope: none. This package fetches no URLs, robots.txt, documentation, messages or API resources. It reads only supplied task text/files. It does not send messages, pair devices, install software or handle credentials.
- Optional implementation: setup advice is not a connected integration. A later Cloud API or unofficial bridge implementation has different data flows: API requests/webhooks or linked-account synchronization, plus hosting and possible message/session storage. Assess that implementation's privacy policy, access controls, retention and account risks separately. Never paste tokens, session files, login codes or QR pairing images into the assistant.
