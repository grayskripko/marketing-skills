# Privacy

This plugin is a set of instructions and reference text for an AI assistant. It has no server, no code of its own and no account.

## What it reads

What you paste or attach in the conversation: page URLs, page titles, menu text, anchor texts, link exports, filter names, redirect lists and, if you include them, traffic, click or backlink counts. If you name your own site and your assistant has a web tool, it also reads that site's robots.txt, up to three sitemap files and up to five public pages, all on that same host, and no other site, even one you name. It does not need personal data. Query parameters that carry an email address or a token-like value are removed from the URLs it shows and only counted; this holds even if you ask otherwise.

## Purpose

To compute the trees, tables, link plans, URL counts and redirect maps the skills produce.

## Recipients

Your data goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends nothing anywhere else.

## Retention

The plugin stores nothing. Any retention is decided by your assistant's provider.

## Network

Network scope: this plugin calls no service of its own and stores nothing. It reads what you paste or attach and, only when you name your own site and your assistant has a web tool, that site's robots.txt, up to three sitemap files it lists and up to five public HTML pages, all on the same host; it fetches no other site. It changes no files, sites or settings unless you ask, and it may use your assistant's code or spreadsheet tool to compute the tables it shows.

## Your controls

Paste only what the task needs. Remove personal data, such as profile URLs or email addresses in query strings, from exports before you share them. Do not name a site if you do not want its public pages read.
