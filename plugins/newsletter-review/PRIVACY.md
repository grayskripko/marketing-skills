# Privacy: Newsletter Review

The editorial skills process only the newsletter text, source excerpts, approved terms, voice samples, attachments, and local files you explicitly supply; redact unnecessary personal data and never provide credentials. All three skills permit the assistant's existing local counting tools to check length or arithmetic without uploading material, which may involve host code or spreadsheet execution and provider-managed temporary files. They do not direct installation, web search, URL or robots.txt retrieval, API calls, account access, sending, publishing, mail-tool drafts, settings changes, or file writes; URLs are reference text, and missing passages must be supplied. Any output file you explicitly request uses your assistant's existing file tools. The publisher operates no collection, telemetry, storage service, or connector for this workflow and receives no task data through it; your assistant provider processes and may retain conversations, attachments, workspaces, and tool activity under its own terms.

Questions: https://github.com/grayskripko/marketing-skills/issues (a support reference, not a skill connection endpoint).
