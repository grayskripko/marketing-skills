# Sources and scope

## Public sources

- FTC, Consumer Reviews and Testimonials Rule Q&A: https://www.ftc.gov/business-guidance/resources/consumer-reviews-testimonials-rule-questions-answers . Project research: read 2026-10-09; builder reopened 2026-10-10. US scope only. Sections 465.2, 465.4 and 465.7 discuss false reviews/testimonials, sentiment-conditioned incentives and specified review-suppression conduct. The plugin's broader refusal to hide criticism is its own safety choice, not a claim that every removal is unlawful.
- Shopify sales reports: https://help.shopify.com/en/manual/reports-and-analytics/shopify-reports/report-types/default-reports/sales-report . Project research: read 2026-10-09; builder reopened 2026-10-10. Shopify reporting scope only. Reports distinguish physical returns from financial reversals. Read the supplied export definitions rather than assuming all platforms use the same fields.

## Answer scope

Keep decisive source qualifications beside the verdict or action, without adding a standard closing block. Retain the exact supplied cohort dates; shipment dates and dashboard labels do not establish receipt dates.

## Method choices

Grouping by SKU/variant, preserving dropdown reasons separately, recording row exclusions, deduplicating imports by stable identity, retaining unknown overlap and drafting investigation questions are this plugin's rules of thumb. No numeric benchmark, defect threshold, inspection standard or causal model is supplied. For a safety complaint, include a referral in the draft only if an approved process is supplied; otherwise ask which process applies and leave the referral unresolved. Do not imply a referral was performed. This package does not certify safety or prescribe a recall.
