# Privacy: Product Returns

This skills-only package contains Markdown instructions and reference text, JSON metadata and a static SVG icon, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes; installation runs no program and connects no account. The skills use only authorized text, attachments and local files you explicitly supply, and direct no web search, URL or robots.txt retrieval, API calls, software installation, account access, message delivery, publishing or settings changes. Source and support URLs are references, not retrieval instructions; paste relevant content for link-only input. Supplied CSV/XLSX files require the assistant's existing file reader, scans require OCR, and the skills acknowledge arithmetic with a tool without specifying a code runtime; this is not a strict no-tool-execution workflow. Explicitly requested local output is created by the assistant's existing tools, with originals preserved. Supplier checks, emails and listing changes remain drafts or proposals. Remove customer identities, contact details, identifying order data and credentials before supplying material; outputs use neutral source IDs and necessary complaint paraphrases. The publisher receives no task data and operates no collection, telemetry, server or storage service; nothing is sent to suppliers, marketplaces or customers. Your assistant provider processes and may retain conversations, attachments and tool activity under its own terms, and manages generated files; use its deletion controls and delete local outputs when no longer needed.
