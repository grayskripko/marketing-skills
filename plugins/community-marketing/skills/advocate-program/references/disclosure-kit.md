# Disclosure kit, monitoring and audit

## Material-connection table

| Benefit | Classification | Rows |
|---|---|---|
| Cash, commission, referral fee, affiliate link | disclose | US-255.5, UK-CAP2, EU-A7-2 |
| Free or discounted plan, product, upgrade, early access | disclose | US-255.5, US-FAQ |
| Swag, travel, event tickets, gift cards, points exchangeable for prizes | disclose | US-255.5 |
| Employment, contract, agency work, family tie | disclose | US-255.5-Ex8, US-465.5 |
| Status perks with money value (priority support, credits) | disclose | US-255.5 |
| Badge, public thanks, featuring the member's own work, with no money value | recognition only | heuristic of this plugin |
| Anything unclear | disclose | heuristic of this plugin |

## Default lines (POL-PLAIN: pass under both US and UK sources)

- Staff or founder: "I work at [BRAND]." / "I'm one of the founders of [PRODUCT]."
- Paid ambassador: "I'm a paid [BRAND] ambassador."
- Free product: "I get [PRODUCT] for free from [BRAND]." For UK readers start with "Ad:" as well.
- Commission: "I get a commission if you sign up through this link."
- Any paid or rewarded social post: "Ad:" at the start, then the plain line.

Placement: the opening sentence of every post, comment, message, caption and video; said aloud and shown on screen in video; repeated during live streams. Never only in the bio, at the end, in a pile of hashtags or behind "more" (US-D101, UK-ASA). The kit never depends on a brand-named tag alone.

## By surface

| Surface | Where | Notes |
|---|---|---|
| Forum or community reply | Opening sentence | Signature lines do not count (PC-02) |
| Chat message | Start of the message | Repeat in each new thread, not once per server |
| Social post | Start of the text, before "more" | A platform's own label helps but may not be enough (US-D101) |
| Video | Spoken and on screen near the start | The description box alone is not enough |
| Live stream | Spoken and shown, repeated | People join part-way |
| Review site | First line of the review | Only where the site allows incentivised reviews (P-GMAPS, P-OTHER-REV) |
| Profile | Optional extra | Never the only place |

## US/UK split (print whenever tags or labels come up)

| Wording | US | UK | Kit |
|---|---|---|---|
| "#ambassador" or "partner" alone | ambiguous (US-FAQ) | not enough (UK-ASA) | never |
| "#[Brand]_Ambassador" | likely more understandable (US-FAQ) | likely not enough (UK-ASA) | never alone |
| "sponsored" | acceptable (US-D101) | advised against (UK-ASA) | not used; use "Ad" |
| "Gifted" alone / "Gifted by [brand]" | ambiguous / adequate for a free product only (US-FAQ) | not enough (UK-ASA) | use the plain free-product line |
| "Thanks [BRAND] for the free product" | can be adequate (US-FAQ) | thanks-style wording unlikely clear (UK-ASA) | US-only fallback |
| "Ad" | acceptable (US-D101) | likely fine, up front (UK-ASA) | yes |

Fails everywhere: bio or profile only, "sp", "spon", "collab", a discount code alone, disclosure at the end or behind "more".

## Monitoring

The brand stays responsible for what endorsers it works with say (US-255.1d). There is no fixed percentage to check (US-FAQ).

1. Offer pre-approval of advocate posts first (US-FAQ suggests it when regular checks are too much).
2. Otherwise sample each month: 10 posts or one per advocate per quarter, whichever is larger, or all if fewer, chosen at random across advocates (heuristic of this plugin; the user may change it).
3. A miss is any Fail on PC-01, PC-02, PC-03, PC-08 or PC-11.
4. First miss: ask the advocate to edit the post and resend the brief. Second miss: pause rewards until fixed. Third miss: end the arrangement (heuristic ladder of this plugin).
5. Keep a log: date, post id, check ids failed, action, date fixed. Advocates appear as A1, A2 in summaries.

## Audit mode

Run pasted advocate posts through PC-01, PC-02, PC-03, PC-08 and PC-11 (`post-checks.md`). Report misses/posts checked with a Wilson 95% interval first, then one row per post (P1, P2, ...): advocate id, checks failed, quoted words, compliant / fix / stop.

## Measurement

Sign-ups by code or link, with the counting rule printed. Write "attributed, not caused" unless there is a comparison group.
