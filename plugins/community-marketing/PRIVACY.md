# Privacy

Community Marketing Kit is a set of instructions and reference text for an AI assistant. It has no server, no account and no storage of its own.

- Network scope: this plugin runs no web search and calls no service. It works on what you paste or attach. If you name the address of one public community-rules page and your assistant has a fetch tool, the skill may read that single page: public pages only, robots.txt respected, no login, and no second attempt when the site blocks the request; if robots.txt cannot be confirmed or the page is blocked, paste the rules instead. Reddit pages are never fetched; paste the subreddit rules instead. It posts nothing, sends no messages, and changes no files or settings.
- Personal data: read only. Categories: draft posts and community rules you paste; advocates' posts and names if you include them; descriptions of moderation incidents; from community exports, pseudonymous member ids, join dates, post, thread and reply ids, timestamps and staff, bot and question flags. Message text, display names, emails or IP addresses appear only if you paste them despite the column whitelist; the skills ignore them and never repeat them.
- Purpose: running the checks and computing the tables you ask for, during that conversation.
- Recipients: the data goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends it nowhere else.
- Retention: the plugin keeps nothing. Retention of your conversation is set by your assistant provider.
- Your controls: remove message text, display names, emails and IP addresses before pasting; use your platform's own admin export, not tools that run on a member's login; replace handles with ids. The skills show members only as M1, M2 and never build member profiles or contact lists. As the community owner, you decide how member data is used.
