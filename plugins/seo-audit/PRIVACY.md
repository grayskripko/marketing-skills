# Privacy policy: SEO Audit Kit

Effective date: 2026-09-29.

SEO Audit Kit is a set of instructions and reference documents for an AI assistant. It contains no code that runs, no server, no analytics and no tracking. The publisher receives nothing from your use of it.

| Topic | Answer |
|---|---|
| Categories of personal data collected | None. |
| Purposes of processing | None, because nothing is collected. |
| Recipients or third parties | None. The plugin sends data nowhere. |
| Retention | None. The plugin stores nothing. |
| Your controls | None needed. You can remove the plugin at any time; nothing remains. |

## What happens when you use it

- If you ask for a site audit and the assistant has a web tool, that tool fetches public pages on the site you name: the URLs you give, that site's robots.txt and sitemaps, and other pages on the same site chosen from its sitemap or navigation, at most 10 HTML pages per run. A page audit fetches only that page, up to three competitor URLs you name, and the site's robots.txt. The fetching is done by the assistant's own tool under the assistant provider's privacy terms, not by this plugin.
- Exports, logs and source files you share stay in your conversation with the assistant, under the assistant provider's privacy terms.
- Before sharing server logs, remove or mask personal data such as visitor IP addresses.
