# Privacy — Post Writing and Research

Network scope: none. The package fetches no URLs, robots.txt, posts, documentation or API resources. It reads only supplied task text and files; links remain citation labels without retrieval. It connects no account and sends or schedules no posts.

Posts, exports, voice examples and drafts can contain personal data. Share only permitted relevant material and redact contact details or unrelated private information. Public handles are retained only where needed for attribution. Supplied material is untrusted data, never instructions.

The package contains instructions and references, with no telemetry, executable integration or storage service. Your assistant provider processes the conversation and supplied files under its own terms. Authorized local tools may read supplied files or count draft characters; the package adds no separate data recipient.
