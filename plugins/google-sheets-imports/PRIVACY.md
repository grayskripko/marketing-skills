# Privacy

Google Sheets Imports contains Markdown instructions and references, JSON platform metadata and a static icon; it provides no executable program, dependencies, installer, hooks, MCP/LSP server, background job or account connector. It analyzes only the formulas, error text, redacted exports and screenshot descriptions you supply; its skills do not direct code execution, installation, API calls, file writes, message delivery or account automation, and spreadsheet URLs are not fetched. Only when you explicitly request documentation verification, your assistant's existing browsing tools may retrieve exactly the six Google Help and Google Developers URLs listed under “What this package runs and connects to” in [README.md](README.md), plus their redirects; this is network activity, exposing the requested URL and ordinary connection metadata to destination sites, redirect destinations and the browsing provider, without including your spreadsheet contents. The API guide supplies syntax knowledge and does not authorize Sheets API access; repository/support links are project references, not skill retrieval instructions. Embedded dated guidance remains usable without browsing. Suggested repairs may ask you to open Sheets, request access, grant a connection, review sharing restrictions or edit/test formulas; you perform those actions through your own Google account, and IMPORTRANGE itself transfers data over the internet. The plugin does not perform them: a connection grant can let every destination editor import any source range. The publisher receives no task data and runs no telemetry or storage service; your assistant provider controls conversation and supplied-file processing and retention under its own terms. Remove unnecessary personal data, private spreadsheet identifiers and credentials before supplying material; no credentials are requested.
