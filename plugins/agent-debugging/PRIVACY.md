# Privacy: Agent Debugging

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, hooks, MCP or LSP servers or background processes, and installing it runs no program and connects no account.

The skills analyze the traces, logs, configurations, transcripts and files you supply. They make no network requests: no web search, URL fetching, API calls, server connections, trace uploads, downloads or telemetry. They do not run, retry or replay any action with external effects. Supplied URLs stay text.

The publisher receives no task data and operates no collection, telemetry or storage service. Conversation and attachment retention follows your assistant provider's settings. Supply no credentials and no personal data the task does not need.
