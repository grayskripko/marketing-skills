# Privacy

This skills-only package contains Markdown instructions and references, JSON metadata and a static SVG icon; it bundles no executable script, installer, dependency, hook, MCP/LSP server, connector or background process. Installation does not execute a program or connect an account. The skills review only task text, attachments and selected local files you explicitly supply, redact credentials, and may save requested local exports at your chosen destination through your assistant's existing file tools. They do not install validators, retrieve remote schemas, search the web, fetch URLs or robots.txt, call APIs, access accounts, upload data, send messages, run agents or graders, replay actions, import into services, or deploy releases. Prepared patches/assertions and later runner prerequisites are preparation only, not execution by these skills. Source/support URLs are reference text, not retrieval instructions; supply the relevant content instead. The publisher operates no collection, telemetry, server or storage service and receives no task data. Your assistant provider processes and may retain conversations, attachments, tool results and temporary files under its own settings and terms; requested local files remain under your control until you remove them.
