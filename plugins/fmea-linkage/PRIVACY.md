# Privacy

FMEA Linkage is a skills-only package: Markdown instructions, one reference file, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, servers, connectors or hooks, and installing it runs no program.

It works only on the process flow, PFMEA, control plan, work instruction and change rows you paste into your request. It makes no network requests: no web search, URL fetching, uploads, account connections or telemetry.

The publisher receives no data and runs no collection or storage service for this plugin. Your conversation is processed and retained under your assistant provider's own settings. Customer names, part numbers and supplier names are not needed for the checks; you can replace them with neutral labels.
