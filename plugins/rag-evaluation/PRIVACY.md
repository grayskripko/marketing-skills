# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG; it bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers, connector, background process, telemetry, or storage service. Installation runs no program and connects no account. The assistant analyzes only the task text, attachments, and relevant local artifacts you explicitly supply; the skills direct no assistant-side code execution, installation, web search, URL/robots.txt retrieval, API calls, account access, message delivery, publishing, or settings changes. Source and support links are references; supply their relevant content instead. Corrections are returned as text or diffs, with a named local configuration file edited through the assistant's existing file tools only when you explicitly request that edit. The skills can recommend user-run pipeline reruns and adding `include=["file_search_call.results"]` to your next OpenAI Responses file-search request, retaining its existing store, filters, and result limit; those requests can contact OpenAI and your configured vector store, while other user-run pipelines use their already-configured services. The plugin does not execute requests, run SDKs/evaluators, connect MCP servers, mutate indexes, or deploy changes. The publisher receives no task data and operates no collection service; your assistant provider controls conversation, attachment, and tool-activity processing and retention, and your pipeline services control data handling for your own reruns. Explicitly requested local edits and output files use the host's file tools. Redact credentials and unnecessary personal data before supplying evidence.
