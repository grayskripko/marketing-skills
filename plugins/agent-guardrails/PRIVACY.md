# Privacy: Agent Guardrails

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers or background processes; installation runs no program and connects no account. Reviews use pasted workflows, permissions, settings, logs, traces, transcripts, attachments and explicitly authorized files; redact credentials and unnecessary personal data. The normal supplied-material review makes no plugin-directed network requests, but a source refresh you request uses the assistant's existing web tool to fetch only exact public official-documentation URLs you supply, disclosing requested URLs and ordinary connection metadata to those sites and the tool provider without including workflow contents in requests; there is no web search, unrelated link traversal, account connection or application API call. If retrieval is unavailable, paste or attach the relevant documentation. The skills return reviewable text and do not run code, install software, change settings, send messages, publish, delete or pay. The publisher operates no collection, telemetry or storage service and receives no task data; conversation, attachment and tool-activity processing and retention are controlled by your assistant provider under its own terms. Source links are references unless included in your requested source refresh, and homepage/support links are not fetched automatically.
