# Myths

Answer in one or two sentences and name the source.

| Claim | Answer |
|---|---|
| Google penalises any page made from a template or a dataset | Google's spam policies target many pages made mainly to manipulate rankings without adding value, not templates as such (spam policies, 2026-08-28). |
| Pages written with AI are penalised for being AI-made | Google's generative-AI guidance does not ban automation; the problem is many pages without added value (2026-10-01). |
| Swapping the city name makes each page unique | Google's doorway examples include pages aimed at cities that funnel users to one page (spam policies, 2026-08-28); a changed key is not new information. |
| Duplicate pages get a penalty | Google's canonical documentation describes choosing one version among duplicates and how to signal your preferred one; it frames this as consolidation. |
| A canonical tag fixes thin pages | A canonical signals which duplicate to show (canonical documentation, 2026-07-10); it does not add information to a thin page. Rule of thumb of this plugin: fix or merge thin pages instead. |
| noindex on some pages hurts the whole site | Google's noindex page describes the rule as page-level; this plugin knows of no Google statement about site-wide harm. |
| More pages means more traffic | Not supported by any Google page cited here; this plugin never uses page count as a goal. |
| Blocking a page in robots.txt removes it from the index | robots.txt controls crawling, not indexing; a blocked URL can still be indexed without its content. To keep a page out, allow crawling and use noindex (noindex page, 2025-12-10). |
