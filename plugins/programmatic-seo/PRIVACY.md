# Privacy

Programmatic SEO Gate is a set of instructions and reference text for an AI assistant. It has no server, no account and no storage of its own.

- Network scope: this plugin fetches nothing and runs no web search. It works only on rows, tables and page text you paste or attach, runs nothing and changes no files or settings unless you ask, and may use the assistant's code or spreadsheet tool to compute the tables it shows. It stores nothing.
- Categories of data: whatever you paste, typically business, product, place or tool rows and sample page text. It is not meant for personal data; page sets about private individuals are declined, and personal contact columns are ignored and never repeated.
- Purpose: computing the tables you ask for, during that conversation.
- Recipients: the data goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends it nowhere else.
- Retention: the plugin keeps nothing. Retention of your conversation is set by your assistant provider.
- Your controls: remove personal columns before pasting.
