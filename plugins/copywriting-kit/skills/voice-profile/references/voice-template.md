# Voice profile template

Select only sections that help the requested guide; this is a menu, not a required report. Ground each rule in samples or mark it as from interview. Keep quoted examples beside the rule they demonstrate. Use qualitative rhythm guidance by default; numeric targets and before/after rewrites are opt-in. Label new illustrative examples and do not use them to invent product behavior. If figures are requested, compute them or mark them approximate and state the counting convention.

```markdown
# Voice profile: [organisation]

Source: [n samples, total words] or [interview, date]

## Voice in one sentence
[How this organisation sounds to its reader.]

## Tone rules
1. Do: [rule]. Don't: [opposite].
2. ...
(5 to 7 rules)

## Sounds like / does not sound like
| Sounds like (from samples) | Does not sound like |
|---|---|
| [user's own sentence] | [the same idea in the voice to avoid] |

## Words
- Use: [words and phrases that recur in the samples]
- Avoid: [words the samples never use, plus the user's own list]

## Rhythm targets
- Average sentence length: [n] words (range [a]–[b]).
- Share of sentences under 10 words: [x%].
- Paragraphs: [n] sentences on average.
- Person and address: [we / I; you / third person].
- Punctuation: [exclamation marks, questions, dashes, lists: how often].

## Never say
- [user's items]
- [stock phrasing the user wants gone]

## Before / after (the user's own sentences)
1. Before: [...] → After: [...] (rules applied: [...])
2. ...
3. ...
```

## Rules for the profile

- Every "sounds like" example is a sentence the user wrote. Never invent one and present it as theirs.
- Rhythm targets describe the samples; they are not a standard.
- The profile describes the user's organisation. It never names or imitates another real person's style.
