# Privacy policy: Copywriting Editor Kit

Effective date: 2026-10-08.

Copywriting Editor Kit is a set of instructions and reference documents for an AI assistant. It contains no code that runs, no server, no analytics and no tracking. The publisher receives nothing from your use of it.

| Topic | Answer |
|---|---|
| Categories of personal data collected | None. |
| Purposes of processing | None, because nothing is collected. |
| Recipients or third parties | None. The plugin sends data nowhere. |
| Retention | None. The plugin stores nothing. |
| Your controls | None needed. You can remove the plugin at any time; nothing remains. |

## What happens when you use it

- Only the copy-diagnose skill fetches pages: public pages at URLs the user gives, at most 3 per run, and never a page the site's robots.txt disallows. Checking that may read the site's robots.txt file. No skill runs web searches or calls any other service. The fetching is done by the assistant's own web tool under the assistant provider's privacy terms, not by this plugin.
- If the assistant has a code tool, it may use it to count words and patterns in the text you pasted; the plugin ships no code.
- Drafts, notes and evidence you paste stay in your conversation with the assistant, under the assistant provider's privacy terms.
- A voice profile is returned as text in the conversation. It is written to a file only if you ask.
- In its answers, the plugin refers to private people named in pasted reviews, notes or samples by a role or a label ("Customer A") and does not copy their email addresses, phone numbers or account ids. A name stays only where your own copy or brief already uses it, such as the credit of a quote or the team on an about page.
- Before pasting customer reviews or notes, remove personal data you do not want in the conversation.
