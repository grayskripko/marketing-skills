# Privacy: Tenant Replies

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installation runs no program or account connection. Its skills analyze only task text, attachments, and local files you explicitly supply; they do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, account access, message delivery, publishing, dispatch, record changes, or account settings changes. Source and support URLs identify references, not retrieval endpoints; paste relevant content instead. Scanned-page text extraction is handled by your assistant provider and checked against the supplied original; emergency notifications in a handoff are instructions for the authorized manager, not messages sent by the plugin. The publisher receives no task data and operates no collection, telemetry, or storage service; your assistant provider processes and may retain conversations and attachments under its own terms, and any output file you explicitly request is created by the assistant's existing file tools under your storage settings. Supply only authorized case material, redact unnecessary personal and financial details, credentials, access codes, and medical information, and review tenant drafts separately from private manager notes before sharing.
