# Tenant Replies

Draft tenant replies from a signed lease and case facts. Get a separate private manager note with sources and open questions.
For landlords and property managers. Provide the signed lease, relevant amendments, tenant message and history, current approved policy, unit label and property jurisdiction. Mark unknown details as unknown.
No accounts, keys, installs or paid APIs are required. Paste text or provide readable files; for scanned pages, your AI app must extract the text, which must be checked against the original page.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account.

These skills work only from task text, attachments, and local files that you explicitly supply. They do not instruct the assistant to run code, install software, search the web, fetch URLs or robots.txt, call APIs, send messages, publish content, or change account settings. URLs in this package identify sources or support pages; they are not connection endpoints or retrieval instructions. A supplied URL is treated as text: paste the relevant content instead.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider still processes and may retain your conversation and attachments under its own terms. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

The Claude and Codex manifests are cross-platform metadata for the same skills; neither defines a server. Scanned-page text extraction is handled by your assistant provider and must be checked against the supplied original. Emergency notifications described in a handoff are actions for the authorized manager, not messages sent by these skills.

## Skills

| Skill | Give it | You get |
|---|---|---|
| find-lease-clause | signed documents and the tenant's question | relevant passages, source locations and missing or conflicting support |
| draft-tenant-reply | documents, message and approved case facts | a calm reply first, then a separate private source note |
| property-manager-escalation | case history, work orders and approved emergency process | a private handoff with reported facts, open decisions and source references |

Ask to write a reply when you need tenant text. Ask for lease support when you only need the passages. Ask for a manager handoff when a decision or escalation is needed.

## How to use it

Keep each case tied to the correct property and unit. Include whether the lease is signed, relevant amendments and printed page labels where available. Redact personal contact details, access codes and unrelated records. Tell the assistant which policy and commitments are approved. Unknown facts stay unknown; a property policy does not become a lease obligation.

Examples:

- “Draft a reply to this locker request using the signed lease and approved manager instruction. Put sources and unresolved questions in a private note.”
- “Find the lease clause on pets in this signed lease and its amendment.”
- “Prepare a private manager handoff from this repair thread about a leak.”

The internal note states the supplied property jurisdiction, or marks it unknown. The package does not draft eviction/default notices, screen tenants, approve accommodations, send messages, dispatch repairs or change records. For safety issues, it follows the supplied approved emergency process before routine case work. Without that process, it says so and still lists the decisions and actions to take that day.

## Data and network

Network scope: none. No URL fetching, web searches, telemetry, accounts or paid APIs. The plugin reads only authorized text and files you provide through your AI host. It ships instructions, references and an icon, with no executable runtime or storage service. Your AI host processes and retains conversations and uploads under its own terms. Saved outputs follow your host and storage settings.

## Troubleshooting

If the scan is unclear, provide the relevant original page and verified text. If the lease is incomplete or sources conflict, the draft leaves the affected point unresolved. This package does not perform current legal research; use the manager handoff for unresolved legal questions.
