# Codebook

This file is identical in every skill that uses it. Start from these codes; add a new code only when an excerpt fits none of them, and print its definition in the coding table.

| Code | What it captures | Example of a fitting excerpt (fictional) |
|---|---|---|
| trigger | the event that made the problem urgent | "When we hired our third bookkeeper, the spreadsheet broke." |
| pain | what goes wrong today | "Month-end takes us four days." |
| workaround | how they cope now | "We copy totals into a shared sheet every Friday." |
| cost of workaround | time, money, errors, stress the workaround costs | "That's a day of someone's week, every week." |
| desired outcome | the progress they want, in their words | "I want to close the month by the 2nd." |
| anxiety | worry about switching or buying | "Moving five years of data scares me." |
| habit | what keeps them with the current way | "Everyone already knows the sheet." |
| alternative | other ways or products they tried or considered | "We tried a bank feed add-on last year." |
| objection | a reason they would not buy or stay | "Per-seat pricing kills it for us." |
| success measure | how they would know it worked | "If the auditor stops asking questions." |
| customer phrase | wording worth keeping as the customer said it | "the Friday copy-paste" |

Rules:
- One excerpt can carry more than one code.
- Codes describe what the excerpt says, not what you think the person meant. Interpretation goes into themes, with ids.
- An excerpt that only answers the interviewer's leading or hypothetical question is flagged "low-weight: prompted".
