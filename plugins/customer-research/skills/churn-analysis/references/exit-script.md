# Follow-up script for customers who cancelled

Default: 5 past-event questions in this order. Use only unanswered questions when supplied notes already answer some, and add a targeted past-event probe for each unresolved competing explanation needed for the user’s decision. State which questions were retained or added.

1. "Think back to when you first thought about stopping. What was going on that week?"
2. "What did you try before deciding to cancel?"
3. "Who else was part of the decision, and what did they care about?"
4. "What are you using now to get this done, and how did you pick it?"
5. Default: "What did you expect to have working by the end of the first month, and what did you actually have?" Use the actual promised milestone and elapsed period when supplied onboarding notes show a different milestone or cancellation before a month; state which milestone was used.

Notes: ask for permission before recording; keep notes under a source id, with role and segment instead of the name. This is practice, not legal advice.
