# Privacy policy: Customer Research Kit

Effective date: 2026-09-30.

Customer Research Kit is a set of instructions and reference documents for an AI assistant. It contains no code that runs, no server, no analytics and no tracking. The publisher receives nothing from your use of it.

| Topic | Answer |
|---|---|
| Categories of personal data | The text you paste or attach, which may include personal data of interview participants or customers (for example names, roles, contact details in notes). The plugin itself collects nothing. |
| Purposes of processing | Analysis of that text inside your own conversation with the assistant. |
| Recipients | The plugin sends data nowhere. The text you provide is processed by the provider of the AI assistant you use, under that provider's terms. |
| Retention | The plugin stores nothing. Retention of your conversation is set by your assistant provider. |
| Your controls | Remove personal data you do not need before pasting. Output uses role labels and pseudonymous ids, removes contact details, replaces company names with segment descriptions and drops sensitive details. |

## What happens when you use it

- Network scope: this plugin fetches nothing and runs no web search; it works only on text and files you paste or attach, runs no code of its own and stores nothing, and if the assistant has a code or spreadsheet tool it may use it to count codes and themes.
- Ids such as S03 or C07 are pseudonyms, not anonymisation: anyone with your original files can link them back.
- This policy makes no claim that your use of the plugin complies with any particular law. You remain responsible for having the right to use the research data you paste.
