# Privacy

TierII Inventories is a skills-only package: Markdown instructions, one reference file, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, servers, connectors or hooks, and installing it runs no program.

It works only on the inventory rows, receipts, usage, SDS extracts and report lines you provide for the task, pasted or attached. It makes no network requests: no web search, URL fetching, uploads, account connections or telemetry. It does not file or send anything.

The publisher receives no data and runs no collection or storage service for this plugin. Your conversation is processed and retained under your assistant provider's own settings. Facility names, addresses and contact details are not needed for the calculations; you can replace them with neutral labels.
