# Excel Formulas

Write, fix and explain Excel and Google Sheets formulas; propose Excel Power Query cleaning and merge steps; check pivot summaries.
For people working from pasted cells, headers, sample rows or M code. No file access, account, paid API or installation is needed for text advice.
Paste the actual cell locations, intended result and application/version; include locale or an existing formula where possible.

## Skills

- **excel-formula-help:** XLOOKUP, INDEX/MATCH, SUMIFS, dynamic arrays, dates, #N/A and #VALUE! repairs, explanations and fill-down checks.
- **power-query-steps:** proposed Excel M patches or editor steps, type conversion, safe merging, unmatched/ambiguous rows and next-file checks.
- **pivot-summary:** grouped tables, totals, percentage denominators and pivot settings from pasted records.

Example: “Excel 2019: my lookup needs an exact match. Here are A1:B4 and the formula; fix it for E2 and explain what happens when copied.”

The answers are text proposals. They do not open or change spreadsheets, execute formulas, refresh queries or create native pivots. Expected sample results are calculated from the pasted rows; checking the target spreadsheet's behavior is a separate step. Use a copy when applying a query patch.

Network: nothing is fetched. No telemetry, service, stored data, credentials or live connections. Your assistant processes the pasted conversation under its own terms. Redact personal data that the calculation does not need. See [PRIVACY.md](PRIVACY.md).
