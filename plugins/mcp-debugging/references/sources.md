## Authored operational choices

Minimal configuration edits, request-shaped answer-first output and deliberate read-only checks are this package's rules of thumb. They are not protocol mandates. Examples use fictional organizations, reserved endpoints and illustrative calls; they are not working services.

Use this register for the specific rule needed in the answer; it is not an output checklist. For a minimal next-step request, explain the observed failure and the necessary correction without adding a separate infrastructure repair or source inventory.
