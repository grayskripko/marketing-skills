# Privacy: MCP Debugging

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG; it bundles no executable program, installer, hook, MCP/LSP server, background process, or telemetry, and installation does not launch software or connect an account. The default diagnosis reads only task text and files you supply and needs no network fetch or code execution, but the complete workflow is not offline-only: at your request the assistant may retrieve relevant official documentation and redirects on code.claude.com, developers.openai.com, learn.chatgpt.com, modelcontextprotocol.io, openai.github.io, docs.langchain.com, and anthropic.com without sending traces, configuration, or secrets in search queries; authorized live checks use an existing trusted client to contact your named MCP server and its documented authentication provider for discovery and a documented read-only call, disclosing approved call arguments and connection metadata and potentially incurring provider charges. Optional Inspector setup downloads from the npm registry and package download hosts and executes Inspector and a reviewed target server, whose origin, arguments, data access, effects, and documented service destinations must be explained before launch; no target server or downstream service is bundled. Repair advice includes local configuration edits, locally setting/exporting credentials, provider login, client list/get commands, removal of a confirmed stale Claude local entry, reconnect/discovery refresh, and SDK cache invalidation; these can change local configuration or restart/connect configured processes, while returned snippets do not themselves write files. The skills exclude write-capable or uncertain smoke calls, message delivery, purchases, account-data changes, and speculative permission broadening. Redact secrets and personal details before supplying evidence; keep credentials and token-bearing Inspector URLs out of chat. Inspector and clients may retain authentication data in a keychain or local files. The publisher receives no task data through the plugin and operates no collection or storage service; your assistant provider processes and may retain conversations and attachments under its own terms, and optional clients and services control their own retention. Redacted pasted traces remain the alternative to live access and installation. Development records are not runtime components, and source/support URLs are references rather than automatic connections (official documentation retrieval is the optional exception).

[Questions and support](https://github.com/grayskripko/marketing-skills/issues): do not post credentials or private traces in public issues.
