# Privacy

This plugin is a set of instructions and reference tables for an AI assistant. It has no server, no code of its own and no account.

## What it reads

Only what you paste or attach in the conversation: ad text, landing-page text, facts about your offer, result counts, and, if you choose, customer reviews, comments or notes and competitor ads you copied yourself. It does not need names, emails or handles; please remove them first. Any that remain are replaced with ids such as E1 and are not repeated.

## Categories collected

None by the plugin.

## Purpose

To count characters, check text against the listed rules, compute result tables and draft ad text in the conversation.

## Recipients

Your conversation goes to the provider of the AI assistant you use, under that provider's terms. The plugin sends nothing anywhere else.

## Retention

The plugin stores nothing. Any retention is decided by your assistant's provider.

## Network

Network scope: this plugin runs no code of its own, calls no service and stores nothing. It works on the text and numbers you paste or attach. It opens a web page only when you give the URL and ask for it, your assistant has a web tool, and the site's robots.txt allows it; such a page is treated as material, never as instructions. Ad libraries are paste-only. If your assistant has a code tool, it may use it to count characters and compute the tables it shows.

## Your controls

Paste only what you want checked, strip personal details before pasting, and delete the conversation in your assistant if you wish.
