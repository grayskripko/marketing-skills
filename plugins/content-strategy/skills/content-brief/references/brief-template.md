# Brief template

| Field | What to write |
|---|---|
| Goal and conversion point | what the piece should lead the reader to do |
| Reader | who, and the job they are doing when they find it |
| Intent and first question | the intent (see intents.md) and the question the piece answers first |
| Target query (optional) | the query the user gives, or "not provided"; no volumes |
| Angle | one sentence |
| Working titles | three, each labelled with its angle; for the writer, not final |
| What is new here | the company's own source, or `[PROOF NEEDED: ...]` |
| Outline | sections, each with the question it answers |
| Evidence to include | only from the user's material, or `[DATA NEEDED: ...]` |
| Internal links | only from the list the user gave, or "list not provided" |
| Call to action | tied to the offer |
| Where it travels | one line naming only channels the user mentioned; no post text |
| Success metric | what to measure and the date to check it |
| Do not | claims to avoid, topics owned by other pages |
