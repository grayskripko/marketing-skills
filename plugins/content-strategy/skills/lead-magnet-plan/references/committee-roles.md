# Buying-committee roles

In B2B, one purchase usually passes several people. A topic should say which of them it helps.

| Role | What they need from content |
|---|---|
| user or champion | proof the tool solves their daily problem; how to explain it inside the company |
| economic buyer | cost, return, risk, time to value |
| technical evaluator | integrations, data flow, setup effort, limits |
| blocker (security, legal, procurement) | answers to objections before they are raised: security, compliance, contract terms |
| end user after purchase | setup, habits, advanced use |

A topic can serve two roles; name the main one.
