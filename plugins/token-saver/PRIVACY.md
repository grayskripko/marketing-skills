# Privacy

Token Saver Kit is a set of instructions and reference text for an AI assistant. It contains no code that runs, and it has no server.

Network scope: this plugin fetches nothing and sends nothing. It works only on text the user pastes or files the user names in the current workspace, and it runs nothing and changes no files or settings unless the user asks.

- **Data collected by the plugin:** none.
- **Purposes:** none, because nothing is collected.
- **Recipients:** none. Your conversation is handled by the AI assistant you use, under that provider's own privacy policy.
- **Retention:** none. The plugin stores nothing.
- **Your controls:** the plugin acts only on text you paste or files you name, and changes nothing unless you ask.

Pasted instruction files and logs can contain secrets. The skills replace keys, tokens and passwords with `<redacted>` in their output, and never copy them into handoff notes.

If the assistant has a code tool, the skills may use it locally to count words or estimate tokens.

Questions: [GitHub Issues](https://github.com/grayskripko/marketing-skills/issues).
