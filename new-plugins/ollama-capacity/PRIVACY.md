# Privacy: Ollama Capacity

This package contains skills and reference text. It reads pasted hardware inventories, environment settings, model metadata and logs to prepare ledgers and configuration proposals. These inputs can contain usernames, paths, device identifiers or prompt text. Remove secrets and unrelated personal content before pasting. Reports omit unrelated identifiers.

Network: none. The skills use bundled official reference summaries and supplied text or exports. They fetch no URLs, call no APIs and download no dependencies. No telemetry, accounts or paid APIs.

The plugin runs no service and stores no input. Conversation processing and retention belong to the assistant you use. You can redact input and delete the conversation through that assistant. No recipients are added by this plugin.
