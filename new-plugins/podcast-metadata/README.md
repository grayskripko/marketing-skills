# Podcast Metadata

Repair Apple podcast RSS and episode metadata from XML and host-form exports.
For podcast producers and editors fixing existing episode records.
Needs pasted RSS XML or a host/Apple Podcasts Connect export; no account, key, API, or install is needed for analysis.

- **Repair podcast RSS:** corrected XML fragments, stable GUIDs, duplicate enclosure diagnosis, and missing media/date fields.
- **Reconcile podcast forms:** a field change table showing where to edit, with Connect limits and sorting separated from availability.

Paste the relevant channel and items, or supply a local XML, CSV, JSON, or text export. Include the error or intended change. For form limits or ordering, include episode origin, show type, and any season or episode numbers you have. A partial export supports a partial repair; absent media sizes or time zones remain named missing fields. The output is ready to review and copy into your host or Connect form. Audio transcription and metadata generation from audio are outside these jobs.

Network: none for pasted-text/export repair. When current rules need verification, the assistant may fetch the seven public Apple documentation URLs listed in each skill's source register, including their redirects. It sends no episode text, exports, or personal data to those pages. It does not fetch feeds, artwork, or media URLs embedded in exports.
