# Privacy

Podcast Metadata contains instructions, source references and an SVG icon. It runs no service and contains no connector or executable code.

It uses pasted XML, episode fields, and local exports you supply to repair metadata in the current conversation. These may contain author names, contact fields, media URLs, and unpublished descriptions. Supply only the records needed; remove private contact fields and signed URLs when they are irrelevant. The assistant may read supplied files and write requested local repair artifacts.

Network: no requests are needed for export repair. To verify current platform rules, the assistant may fetch only the seven Apple documentation URLs in the source registers and their redirects. It does not send export content to Apple or fetch any feed, artwork, enclosure or website URL found inside the input. It does not read accounts or change a host or Apple Podcasts Connect.

No telemetry, external storage, or plugin retention. The assistant provider processes and retains the conversation under the user's existing account settings. Delete the conversation or supplied files through that host's controls.
