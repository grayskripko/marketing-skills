# Privacy

Accounting Journals uses task text, attachments and readable local files you explicitly supply to your assistant; remove unnecessary personal data and credentials before supplying journal material. This skills-only package contains Markdown, JSON metadata and a static icon, with no executable scripts, dependencies, installers, hooks, MCP/LSP servers or background processes, and its skills do not direct code execution, shell commands, software installation or API calls. It is not strictly offline: optional source refresh and current/conflicting-rule verification may use the assistant's existing web/search tools to retrieve linked official Xero Central articles or a user-supplied official Xero documentation/template URL, the site's robots.txt and redirects confined to official documentation; official article-title searches may retrieve indexed text when pages return empty shells. Those requests disclose public URLs or article titles and ordinary connection metadata to documentation sites and web/search providers, never private journal rows. If retrieval fails, dated bundled references remain usable with the affected rule marked unresolved; supplied-text preflight can proceed without retrieval. Requested corrected CSVs or local output files use the assistant's existing text/file tools. Template downloads, organisation connection/selection, import previews, uploads and posting are separate user-led Xero/Conversion Toolbox actions that the skills may explain, not actions executed by this package. The plugin performs no account authentication, ledger access, account creation, uploads, posting, message delivery or settings changes, and the publisher receives no task data and operates no server, telemetry or retention store. Your assistant provider controls processing and retention of conversations, attachments, output files and tool activity under its own terms.
