# Privacy: Support Targets

This package contains skills, reference text and an icon. It runs no service.

- Data read: supplied policy settings, schedules, ticket identifiers, timestamps, actor roles, comments and report rows; only task-relevant files the user supplies. Names, email addresses and comment bodies are unnecessary when role and visibility fields suffice.
- Purpose: explain SLA policy matches, measured instances and breaches in the current task.
- Network: none. No URL fetching, API calls, login, connector, telemetry or external transmission by the package.
- Recipients: the assistant provider processing the conversation. The package adds no recipients.
- Retention: no package storage. The assistant’s conversation and user-requested output-file retention apply.
- Controls: use redacted identifiers, omit unrelated comments, and delete supplied files or the conversation using the host’s controls.
