Write Instagram captions, carousels and reel scripts with hooks and hashtags from your facts.

# Instagram Content

For creators and small businesses who need draft copy from product details, event notes, transcripts or an existing draft. Paste the facts and tell the assistant your audience, voice and desired format. No account, paid API or setup is required.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account.

These skills work only from task text, attachments, and local files that you explicitly supply. They do not instruct the assistant to run code, install software, search the web, fetch URLs or robots.txt, call APIs, send messages, publish content, or change account settings. URLs in this package identify sources or support pages; they are not connection endpoints or retrieval instructions. A supplied URL is treated as text: paste the relevant content instead.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider still processes and may retain your conversation and attachments under its own terms. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

The bundled references also recommend checks you perform separately: preview a finished cover crop, check ambiguous character counts or publisher validation in your target tool, review account status and current rules when eligibility matters, and review a paid-partnership label when relevant. Reel timing should be checked by reading the script aloud before filming. These are production reminders, not instructions for the assistant to access an account, retrieve a page, run software, or publish. The two platform manifests are metadata, not executable runtimes.

| Skill | Input | Output |
|---|---|---|
| instagram-captions | Facts, photo description or draft | Caption, opening hook, relevant hashtags |
| instagram-carousels | Notes and requested slide count | Slide copy, visual suggestions, accompanying caption and hashtags |
| instagram-reel-scripts | Facts, available footage and duration | Timed filming beats, spoken and on-screen copy, caption and hashtags |

Ask “Write a caption for this launch”, “Make this a five-slide carousel”, or “Turn this transcript into a 20-second reel”. Specify the language, maximum words, hashtag count and details to omit when they matter.

The assistant keeps supplied claims, uncertainty and exceptions. Missing details are omitted, briefly marked or asked about after usable copy. Timing is a filming estimate, not rendered video. Visual suggestions are plans; this package does not make images or videos. Hashtags are topic suggestions, not checked trends or promises of reach.

The skills include dated first-party guidance for caption search wording, original media, accessibility and route-specific production constraints. API specifications are distinguished from app limits; no recommendation eligibility or performance is guaranteed. References are packaged for offline use.

## Data and network

Network scope: nothing is fetched. The skills use pasted text or local exports you explicitly select. They do not open supplied links, connect to Instagram, log in, publish, schedule or send messages. The package contains instructions and an icon, with no executable service, telemetry or storage. Your assistant processes the conversation under its own terms. Remove private customer details before sharing notes. See [PRIVACY.md](PRIVACY.md).
