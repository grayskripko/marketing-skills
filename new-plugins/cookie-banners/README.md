# Cookie Banners

Checks EU cookie banner text, buttons, consent settings and cookie lists; gives corrected wording, specific changes and the evidence needed.
For people responsible for website consent, privacy review and CMP configuration.
Needs pasted banner text, choice paths, redacted CMP settings or tracker exports, and, when known, the country in scope. No account, keys, installation of a CMP or paid API is required.

## Skills

- **review-cookie-choices**: corrected banner copy and a choice-by-choice designer handoff, including accept, reject, save, close and withdrawal.
- **reconcile-cookie-settings**: reconcile settings, tracker purposes and observed behavior; return field-specific corrections and the missing evidence.

For a combined request, review the copy and choices first, then reconcile configuration against the same purpose names. Screenshots support visual review; text alone supports wording and supplied path review. Include mobile and desktop captures when visual prominence matters.

## Inputs

Paste the displayed text and buttons on each layer, what each action saves, default toggles, country, CMP/version/date and any known withdrawal route. For inventories, include tracker name, domain/provider, actual purpose, duration, category and when it was observed. Exclude cookie values, user IDs and raw consent identifiers. A redacted CSV, JSON export or table works.

## Sources and network

The package includes official EDPB findings and France-specific CNIL guidance, including the January 2026 consolidated recommendation. Both skills work entirely from supplied material and embedded references. They fetch no URLs, run no web searches and make no network requests. They review exports and prepare corrections; they do not connect to or change a CMP, scan a site or execute browser tests. Evidence collection steps describe what to capture, and supplied captures can be reviewed here.

The source register records URLs, publication dates and actual verification dates. National guidance embedded here covers France. Other EU countries use the EDPB baseline plus applicable official national material you supply. Source refresh is a separate research request.
