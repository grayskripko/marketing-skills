# Privacy

OOS Investigations is a skills-only package: Markdown instructions and reference text, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers or background processes, and installing it runs no program and connects no account.

The skills analyze only the laboratory and production records you paste or attach for the task. They make no network requests: no web search, URL fetching, uploads, downloads, API calls or telemetry. Supplied URLs are treated as text. Source documents were read at build time and are embedded in the package.

The publisher receives no task data and operates no collection, telemetry or storage service. Conversation and attachment retention follows your assistant provider's settings. Do not supply credentials, and remove personal data the investigation does not need; the skills do not repeat personal identifiers beyond the analyst or role labels needed to keep results traceable.
