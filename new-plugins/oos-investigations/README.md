# OOS Investigations

Investigate an out-of-specification (OOS) lab result from the original result, approved specification, analyst notes, raw data and retest history.
For QC investigators and QA reviewers at contract laboratories, CDMOs and pharmaceutical quality units.
Needs the records pasted or exported into the conversation: result, specification, method, analyst notes, instrument and standard records, retest data and, for Phase II, batch records and distribution status. No account, API key, connector or installation is required.

| Skill | Result |
|---|---|
| oos-lab-investigation | Phase I evidence chronology, hypothesis register, conclusion draft and missing-record requests |
| oos-retest-review | Verdict on retests, resampling, averaging and outlier tests, recomputed statistics and the supported outcome (invalidated, confirmed or inconclusive) |
| oos-phase-two-handoff | Full-scale investigation handoff: manufacturing review plan, other-batch impact, reporting clocks, CAPA candidates |

Try "We got an OOS on assay, help me write the Phase I", "Can we average the retests with the original?" or "Draft the Phase II handoff and tell me if we need a field alert".

The skills keep every result, passing and failing, with the original OOS first. They mark each laboratory hypothesis as supported, contradicted, untested or no longer testable, and say "Cannot conclude yet" with the deciding records when the data cannot support a conclusion. Every output supports, and does not replace, the quality unit's review and sign-off: invalidation, retest authorization, root cause, CAPA closure and batch disposition stay with them.

Built on the FDA OOS guidance (Revision 1, May 2022), FDA data integrity Q&A (December 2018), 21 CFR 211.22, 211.160, 211.165, 211.192, 211.194 and 314.81, EU GMP Chapter 6, ICH Q7 section 11.15 and the MHRA OOS/OOT guidance. The FDA guidance covers chemistry-based testing; microbiology and biological assays are flagged and handled with their own compendial rules.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, a license and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account.

Network use: none. The skills make no web requests, searches, uploads or downloads, and send no telemetry. Supplied URLs are treated as text. Regulatory sources were read when the package was built and are embedded in the references file. The skills read only what you paste or attach for the task.

The publisher receives no task data and runs no collection or storage service. Your assistant provider processes conversation and attachments under its own settings. Remove personal data that the investigation does not need.
