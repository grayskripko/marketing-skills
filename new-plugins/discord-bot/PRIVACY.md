# Privacy: Discord Bot

This skills-only package contains instructions, reference text, metadata and a static icon, plus development notes and historical test records; it provides no executable bot, connector, installer, hook or background service. The assistant uses pasted requirements, redacted settings, command drafts and selected exports to return planning text and declarative payloads; the skills prohibit URL fetching, Discord API calls, software installation, command registration, sending messages and account changes, and provide no assistant code-execution or file-writing instructions. Owner guidance separately asks you to use the Discord developer portal, check current settings and documentation, install an application in an authorized test server, and have an implementer register commands, implement handlers and test them. That implementation may connect through a public HTTPS interaction endpoint or a Gateway process, send messages, deliver reports, store case results and perform approved role or moderation actions; its hosting, credentials, destinations and retention are separate choices with separate privacy behavior. The plugin publisher operates no server, collection, telemetry or storage service and receives no task data; your assistant provider processes and may retain your conversation under its own terms. Source/support URLs are references rather than assistant retrieval instructions. Remove unnecessary member details and never paste bot tokens, client secrets, webhook URLs or interaction tokens; revoke or rotate exposed secrets locally.
