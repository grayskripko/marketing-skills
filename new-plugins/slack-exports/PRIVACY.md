# Privacy: Slack Exports

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it provides no executable scripts, dependencies, installers, hooks, MCP/LSP servers, background processes or account connector. Analysis uses only messages, identifiers, timestamps, export settings, filenames, attachment metadata and screenshot descriptions that you explicitly supply; the skills do not direct code execution, software installation, web search, URL retrieval, API calls, message delivery, publishing, account changes or file writes. Archive, attachment, canvas, source and support URLs are text or references, not fetched endpoints. When export setup is requested, the assistant explains how an authorized owner/admin selects scope/dates and downloads an export through Slack's workspace or Enterprise export settings, and that additional access may require contacting Slack for approval; the user performs these network/account actions in Slack, not the assistant. Bundled coverage notes request a publisher documentation recheck before a later release, separate from runtime analysis. The publisher receives no task data and operates no collection, telemetry, server or storage service. Your assistant provider processes and may retain supplied conversations and files under its own terms; any output file you explicitly request uses the assistant's existing file tools, not a bundled program. Supply only necessary records, redact credentials and irrelevant personal data, preserve stable pseudonyms for joins, and manage conversation/file retention through your provider.
