# Privacy: Context Triage

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, connectors, or background processes. Installation runs no package program and connects no account. The assistant analyzes only task text, attachments, and local files you explicitly supply, returning reports, continuation packs, and proposed patches as text; the skills do not direct assistant code execution, installation, web search, URL retrieval, API calls, account access, message delivery, publishing, or settings changes. Documentation and support URLs are references, not retrieval instructions. Advice can suggest user-run Claude Code `/context`, `/compact`, `/clear`, and runtime context-report or outgoing-payload checks; packs can retain pending user-task actions, including an unrun check in the fictional parser example. The plugin does not execute these actions or prescribe a network destination for the checks; user-run checks and resumed tasks may execute code or connect according to your environment, and clearing loses active continuity. The publisher receives no task data and operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations and attachments under its own terms; separately requested output files use the host's existing file tools and remain where you choose. Supplied traces and files can contain confidential information: provide only necessary material, redact credentials, and use your provider's deletion controls as needed. Support: https://github.com/grayskripko/marketing-skills/issues — do not post sensitive task data there.
