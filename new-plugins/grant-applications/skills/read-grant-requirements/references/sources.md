# Source notes

These instructions use the user’s actual funder packet as the deciding source. Record its title, version and page/section in the working check. No generic website replaces it.

Background opened 2026-10-10 (not a universal grant rule): [Grants.gov applicant guide](https://www.grants.gov/quick-start-guide/applicants), “Naming Files for Upload,” says applicants should check their notice for agency-specific filename instructions. Its file constraints apply to that US portal, not every funder. They are deliberately not imported into these skills. The same guide separates document preparation from portal error checks and authorized submission.

Requirement mapping, source labels, fact preservation, uncertainty handling and calculation display guide the check; they do not prescribe the answer’s format or create funder requirements. Use the requested deliverable and include only the source context needed to act on it. No universal grant deadlines, eligibility thresholds, indirect rates or AI permissions are asserted.
