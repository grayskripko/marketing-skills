# Privacy: Substack Migration

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, and development documentation; it bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers, or background processes, and installation runs no program or account connection. The assistant analyzes only task material you explicitly supply, may read selected exports, use a CSV-aware parser and existing local tools for parsing/calculations, and create requested import or reconciliation files while preserving originals. Only on your explicit rules-refresh request may it search public Substack help and retrieve official support.substack.com/substack.com pages, including redirects; subscriber data, payment details, credentials, and private URLs must not be sent in those requests. No software installation or API calls are instructed. Exports/downloads, ZIP extraction, uploads/imports, Stripe setup and Ghost revocation, billing/access changes, support requests, and message sending are user-performed handoffs, not assistant-executed account actions. The publisher receives no task data and operates no telemetry, collection, or storage service; assistant-provider terms govern conversation, attachment, tool, and file processing and retention, and requested outputs remain wherever you save them. Minimize supplied personal data, use row IDs in reports, keep real addresses only in necessary private import/reconciliation files, and omit card details, payment tokens, credentials, and unrelated profile information. Source links are references except during the explicitly requested refresh; the support link below is for you to open yourself.
