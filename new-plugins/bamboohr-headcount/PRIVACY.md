# Privacy — BambooHR Headcount

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static icon and development evidence; it supplies no executable program, installer, dependency, hook, MCP or LSP server, connector or background process. Headcount analysis uses only text, attachments and local files you explicitly supply, preserves originals, and does not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, account access, settings changes, message delivery or publication. API corrections and extraction plans are text only; you obtain any additional exports through your own authorized BambooHR access. Local output is created by your assistant's existing file tools only when you request it. Each bundled reference separately instructs release maintainers to reopen ten public pages at `https://documentation.bamboohr.com` before the planned 2026-10-17 submission and refresh changed rules: this maintenance step makes public-documentation requests, disclosing requested URLs and ordinary connection metadata to that host and the browser or assistant tool provider, without requiring employee records or credentials. GitHub source/support links are references, not automatic retrieval or issue-submission instructions. The publisher operates no collection, telemetry or storage service and receives no task data; your assistant provider processes and may retain conversations and attachments under its own terms, and you control requested local outputs. Inputs may contain employment categories, dates, department history and identifiers: use pseudonymous IDs and omit unnecessary contact, pay, address, national-identifier and credential data.
