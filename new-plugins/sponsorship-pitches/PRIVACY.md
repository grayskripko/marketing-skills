# Privacy: Sponsorship Pitches

This skills-only package contains Markdown instructions and references, JSON metadata, a static icon, and development evaluation text; it supplies no executable scripts, dependencies, installers, hooks, MCP/LSP servers, connector, or background process. Installation runs no bundled program and connects no account. Its three skills analyze only the text, attachments, and local files you explicitly supply, including aggregate audience figures, survey summaries, brand briefs, draft messages, rates and terms. They permit the assistant's existing tools to read those files and perform local counting and arithmetic, which may execute code or spreadsheet calculations and create provider-managed temporary files; they specify no particular execution tool or installation. They do not direct web search, URL or robots.txt retrieval, API calls, account access, settings changes, file writes, message sending, mailbox draft creation, publishing, deal acceptance delivery, contract signing, or Spark code generation/sharing. Outputs are draft text. Source and support URLs are references, not runtime retrieval instructions; paste relevant content instead of supplying only a URL. Historical source-verification dates describe publisher research. No task data is sent to the publisher or brands, and the publisher operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations, attachments, and tool activity under its own terms; this does not claim the provider operates without network access. Redact unnecessary individual audience records, private contact details, confidential terms, and credentials before supplying material.
