## Metric definitions
https://help.bloomerang.com/en/articles/12632860-about-raised-and-revenue-amounts
Observed: updated over a week ago. Donations, recurring payments and membership payments count in both measures; pledges only in raised, pledge payments only in revenue. Schedules, credits and fundraiser copies add no independent money. Donation raised deducts all pledge-applied credits with a zero floor; revenue and donation type stay unchanged. Report Amount can inflate comparisons because it spans transaction categories.

## Credit linkage
https://help.bloomerang.com/en/articles/12632409-add-or-edit-soft-credits
Observed: updated yesterday. Pledge selection lists active pledges; Add to Pledge appears only for an original donation. Unlinking removes that application; recalculate using any other remaining applications. Credit records and Timeline indicators are attribution evidence, not extra revenue.

## Report grain
https://help.bloomerang.com/en/articles/12632838-what-are-report-types
Page date: October 26, 2025; read 2026-10-11. Constituent rows represent accounts; transaction rows represent transactions, even when constituent columns are included. This prevents adding account aggregates to transaction rows.

## Export completeness
https://help.bloomerang.com/en/articles/16142808-export-reports
Page date: September 3, 2026; read 2026-10-11. CSV, Excel and PDF exports are available. A PDF holds at most 5,000 rows and wide columns can be cut off. Generated downloads remain available for 24 hours. Request CSV/Excel or pasted rows for complete numerical work when a PDF loses coverage. The legacy /16142808-export-a-report URL redirects here.
