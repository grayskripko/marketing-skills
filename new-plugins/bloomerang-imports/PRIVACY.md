# Privacy — Bloomerang Imports

This package contains Markdown instructions and references, JSON metadata, a static SVG icon and development/evaluation records; it bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers or background processes, and installation runs no program or account connection. Both skills use supplied CSVs, exports, errors and settings by default; your assistant's existing tools may parse CSVs, count rows/bytes, reconcile amounts and write requested corrected files, held rows and trace records to your chosen destination, potentially using host code execution and provider-managed temporary files. CSV cells and their links are never executed or followed. Only when you request a current-rule check may the assistant fetch public HTTPS articles on `help.bloomerang.com` and that site's `robots.txt`; the site and tool provider receive the requested URL and ordinary connection metadata, with no donor-data upload, login, off-domain redirect or web search. Blocked retrieval falls back to supplied article text. No software installation, API integration, account operations, message delivery, publishing or settings changes are instructed for the assistant. Preview review, skipped-record downloads, manual entry and test/final imports are operator actions in Bloomerang CRM; those imports can create records and trigger configured acknowledgements. Inputs and corrected files may contain donor identities, contact details, amounts and notes; findings minimize unnecessary personal details. The publisher operates no collection, telemetry or storage service and receives no task data. Your assistant provider processes and may retain conversations, attachments and tool activity under its own terms; you control requested output files and can remove them and conversations through your assistant. No credentials or payment-card data are needed; redact unnecessary personal material, recognizing that redacted or partial exports limit matching evidence. Repository/support links identify project pages rather than account connectors.
