# Privacy: Acquisition Reporting

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, and text development records; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it runs no program and connects no account. The skills analyze only task text, attachments, and local files you explicitly supply, including aggregate report rows, attribution settings and client drafts; they do not direct code execution, installation, web search, URL or robots.txt retrieval, API calls, account access, message delivery, publication or account-setting changes. Arithmetic and word-count checks use supplied material without an instruction to run code. You obtain reports and copy tables yourself in LinkedIn Campaign Manager; comparison guidance can ask you to adjust reporting filters and dates there, but the skills do not perform those actions. Source and support URLs are references, not retrieval endpoints; paste relevant content for a supplied URL. The publisher receives no task data and operates no collection, telemetry or storage service; your assistant provider processes and may retain conversations and attachments under its own terms. Any output file you explicitly request is created by the assistant’s existing file tools, not a bundled program. Supply aggregate or anonymous evidence rather than contact details or credentials, and use your provider’s conversation and file deletion controls.
