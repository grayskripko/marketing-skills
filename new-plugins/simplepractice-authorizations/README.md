# SimplePractice Authorizations

Check remaining authorized sessions, authorization expiration dates and box 23 on SimplePractice claims.

For practice administrators and billing staff using SimplePractice. Needs de-identified authorization settings, dated remaining-use records, session dates/statuses/units, and payer-specific claim fields. Paste text or provide selected CSV, JSON or text exports. No account, keys or installation beyond the plugin is needed.

- **authorization-exceptions**: compare authorized dates and supported remaining uses with planned sessions.
- **authorization-claim-review**: review active authorization, payer-specific box 23, claim line limits and relevant paper/electronic differences.

Include an as-of date, snapshot timestamp, what the snapshot already includes, authorization unit basis, payer approval evidence and primary/secondary status. Use stable case aliases instead of client identifiers.

Network: routine analysis fetches nothing. When you request a source refresh, the agent reads the official support URLs listed in the skills’ source registers and their robots.txt on support.simplepractice.com; redirects are followed only within that host. Case data stays out of requests. No telemetry or external uploads.
