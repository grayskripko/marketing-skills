# Privacy

This skills-only package contains instructions, reference text, metadata, a static icon and development/evaluation records; it bundles no executable scripts, dependencies, installers, hooks, servers or background processes, and installation does not run a program or connect an account. Supplied-text/export review needs no network, but the skills direct your assistant's existing web tool to refresh deciding rules or retrieve historical versions from source-register URLs on `www.ecfr.gov`, `www.govinfo.gov` and `www.fac.gov`, or an official agency URL you supply for award implementation, including redirects. Contacted sites, redirect destinations and the tool provider receive the requested URL and ordinary connection metadata; report text, personal data, identifiers and private context must not be placed in queries or uploaded to those sites. The skills do not direct code execution, software installation, authenticated API calls, account access, message delivery, publication, repayments, award amendments, issued management decisions or FAC submissions. Only user-selected local files are read, and output files are created only on explicit request using the assistant's existing file tools. The publisher receives no task data and operates no collection, telemetry or persistent storage service; conversation, attachment and tool-activity handling and retention follow your assistant provider's terms and settings. GitHub source, documentation and support links are package information, not workflow retrieval endpoints. Prefer role names and omit credentials, bank information, participant identifiers and unrelated personal data.
