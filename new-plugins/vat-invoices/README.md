# VAT Invoices

UK VAT invoice and credit-note review. Other jurisdictions require their own references.

Check this UK invoice before I send it and show exactly which fields need fixing.

For UK sole traders and companies preparing invoices or VAT credit notes. Needs pasted text, a readable invoice export, a screenshot the host can read, or your description of its fields. No account, key, installation of invoicing software or paid API is required.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON platform metadata, and a static SVG icon. It bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. This working folder also contains development notes and test/evaluation records; those are not a plugin runtime.

The skills review task text, attachments and readable files you explicitly supply, but this is not a strictly offline workflow. When current verification is needed, your assistant's existing web tool may retrieve the named official GOV.UK/HMRC guidance and the linked legislation.gov.uk PDF, follow their redirects, and follow relevant official GOV.UK or legislation.gov.uk guidance links from those pages for special cases. These requests disclose public guidance URLs and ordinary connection metadata to the requested sites, redirect destinations and the assistant's tool provider. Invoice contents, personal data and private search terms must not be sent. Invoice hyperlinks, QR codes and payment destinations are not fetched. The skills also require verification before adding an exact source-link fragment; source URLs are therefore retrieval targets as well as citations. The National Archives licence link and GitHub documentation/support links identify attribution or support pages, rather than instructed retrieval targets.

Neither skill instructs code execution, shell commands, software installation, API integration, account access, message delivery or account-setting changes. Calculations use supplied amounts and rates and show formulas and inputs. Corrected drafts and proposed field changes are returned for you to apply; the credit-note workflow can tell you to provide a corrected note to the customer by its deadline, but does not deliver it. No automatic file write is instructed. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

The publisher operates no collection, telemetry or storage service for this plugin and receives no task data through it. Your assistant provider processes and may retain your conversation, attachments and tool activity under its own terms. If official guidance cannot be retrieved, provide the relevant official passage and deciding facts; unsupported special-case tax wording cannot be verified from a URL alone.

## What you get

- **Check UK invoice:** exact fixes for ordinary, full VAT, eligible simplified and modified retail invoices, including field names and corrected totals.
- **Check UK credit note:** missing original-invoice references, credit amounts, original VAT rate and refund-based timing issues.

Paste the draft and say whether the seller is VAT registered, the business type and whether the view is complete. Include the agreed VAT rate and original invoice for credits if available. A cropped screenshot produces a partial review; a field outside the crop is not assumed absent. If an export omits the footer, the agent can help you export the full document or transcribe it.

The review proposes changes for you to make. It does not send invoices, pay refunds, change accounting records, verify registration numbers or file returns. Special schemes, reverse charge and cross-border cases receive visible field fixes and a request for the deciding facts or official guidance before tax wording is proposed.
