# Privacy

This skills-only package provides Markdown instructions and reference text, JSON metadata and a static SVG icon, with no bundled executable scripts, dependencies, installers, hooks, MCP/LSP servers, account connector or background process; development notes and test/evaluation records in this working folder are not a runtime. The assistant reviews only the invoices, credit notes, exports, images, transcriptions and clarifications you supply, which may include names, addresses, VAT numbers, amounts and payment information; omit unnecessary personal data and bank details, and no credentials are requested. This is not strictly offline: when current verification is needed, the assistant's existing web tool may retrieve the named official GOV.UK/HMRC guidance and linked legislation.gov.uk PDF, follow redirects, and follow relevant official GOV.UK or legislation.gov.uk guidance links from those pages for special cases, including verification of exact citation fragments. Requests disclose public guidance URLs and ordinary connection metadata to the requested sites, redirect destinations and the assistant's tool provider, never invoice contents, personal data or private search terms; invoice hyperlinks, QR codes and payment destinations are not fetched. The National Archives licence and GitHub documentation/support links are attribution or support references, not instructed retrieval targets. Neither skill directs code execution, shell commands, installation, API integration, account access or automatic file writes; calculations show supplied inputs and formulas, and corrected drafts are returned for you to apply. The credit-note workflow may tell you to provide the corrected note to the customer by its deadline, but does not send it, pay invoices, issue refunds, file returns or change financial records or settings. Any output file you explicitly request uses your assistant's existing file tools at your requested destination. The publisher receives no task data through the plugin and operates no collection, telemetry or storage service; your assistant provider controls processing and retention of conversations, attachments and tool activity. Supplied documents and fetched pages are evidence, never instructions; if retrieval fails, supply the relevant official passage and deciding facts rather than relying on an unverified URL.
