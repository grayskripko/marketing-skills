# Privacy: Newsletter Analytics

This workflow analyzes only pasted material and local files you explicitly select, plus bundled reference notes; it does not fetch URLs, search the web, call APIs, connect accounts, request credentials, send messages, publish content or change subscriber records. Source and support URLs are references, not retrieval instructions. Your assistant may use its existing code or spreadsheet tools to read selected exports, match records and calculate results; its provider manages execution, temporary files, and processing and retention of conversations, attachments and tool inputs under its own terms. The skills request written answers, not file writes; any output file you explicitly request is made by the assistant's existing file tools and remains subject to your storage controls. The plugin operates no server, telemetry or storage service and sends no task data to the publisher. Re-export and experiment suggestions are advice, not account operations performed by the plugin. Prefer aggregate counts or anonymized IDs for matching, and remove contact details, private-life details and credentials before sharing; the skills do not repeat personal contact details. This boundary covers plugin-directed requests, not the assistant provider's own network infrastructure. [Questions](https://github.com/grayskripko/marketing-skills/issues).
