# Privacy: Course Completion

This skills-only package contains Markdown instructions/references, JSON metadata and development records, and a static SVG; it has no executable program, installer, hook, server or account connector. Diagnosis uses supplied settings, progress records, quiz histories and relevant supplied files plus bundled references, without directing code execution, installation, runtime URL retrieval/web search, API calls, account changes or message delivery. Both source registers separately instruct maintainers to reopen public support.teachable.com documentation before submission and update changed rules; following that maintenance instruction makes public-page requests through the maintainer's browser or assistant tools. Owners obtain records and perform any recommended recovery through their existing Teachable access; a quiz reset deletes prior attempt results and triggers Teachable's learner email, while other progress/access changes are also owner actions, not plugin execution. The publisher receives no task data through the plugin and operates no telemetry, collection or storage service for it; conversation, attachment and requested-output processing/retention belong to your assistant provider and its existing file tools. Use learner aliases and omit unnecessary personal details and credentials. Repository/support links are project references, not task-data endpoints.
