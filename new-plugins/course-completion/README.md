# Course Completion

Find why a Teachable learner's next lesson is locked or Complete and Continue will not advance.
For school owners and course support teams diagnosing Teachable web courses. Paste settings, lesson records or exports without connecting an account or supplying keys. Owners use their existing Teachable access to obtain records or carry out recovery steps.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. The local folder also contains Markdown/JSON development and validation records. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The Claude and Codex manifests are platform metadata, not connectors.

The diagnosis workflows use only task text, attachments, and local files that you explicitly supply, together with bundled reference text. They instruct no code execution, software installation, runtime web search or URL retrieval, API calls, message delivery, publication, or account changes. For current help or conflicting settings, paste the relevant text; a URL alone is not fetched for diagnosis. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

There is a maintenance exception: both bundled source registers instruct the maintainer to reopen public Teachable documentation before submission around 2026-10-18 and update changed rules. Those links point to support.teachable.com articles on Course Compliance, Add Lesson Content, Student Progress Reports, Course Reporting Tools, and Navigate and View Course Content; the progress-blockers register also links Drip Content. Following that instruction retrieves public pages through the maintainer's browser or assistant tools. It is not a school-account connection or a runtime diagnosis step.

Recommendations can ask an owner to obtain reports, preserve history, check playback/preferences, or perform Teachable recovery using their existing access. A quiz reset performed by the owner removes prior attempt results and causes Teachable to email the learner; lesson/course resets change progress, and manual completion or drip-access changes affect access records. The skills describe these actions and effects but do not perform them or send the email.

The publisher receives no task data through this plugin and operates no collection, telemetry, or storage service for it. Your assistant provider still processes and may retain your conversation and attachments under its own terms. Repository and support links identify project pages, not task-data endpoints.

| Skill | Give it | Get back |
|---|---|---|
| progress-blockers | Gate settings, curriculum order, media origin, learner progress and displayed message | The earliest supported blocker, its evidence and the next check |
| quiz-attempt-review | Grading/enforcement settings, score floor, dated attempts and remaining-attempt text | Per-learner score/retake review and a narrow recovery recommendation |

## Start with pasted evidence
Use learner aliases. Include the exact setting labels and values, whether a video is uploaded or embedded, and the lesson's Complete/Incomplete status. For quiz rows, label the initial submission separately from retakes and keep reset dates. Missing details are called out after the useful diagnosis.

Examples: “This Teachable lesson stays locked after the video—here are the settings and progress report.” “Here are our quiz attempts; who can retry and who needs a reset?”

## Data and network
Runtime network fetches: none. The skills read your pasted text and files you supply for the case, using bundled official documentation. They connect to no school account and make no account changes. Reset recommendations explain lost history and learner notifications. No telemetry or plugin-managed storage. See [PRIVACY.md](PRIVACY.md).

The source registers record six official pages verified on 2026-10-11. For newer settings, paste current official help text with its URL. Support: [repository issues](https://github.com/grayskripko/marketing-skills/issues).
