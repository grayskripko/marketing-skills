# Privacy: Shopify Discounts

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon; it bundles no executable code, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installing it runs no program or connects no account. The assistant analyzes task material you explicitly supply and reads bundled references; the skills do not direct code execution, software installation, file writes, store API calls, message delivery, publishing or account changes. Ordinary analysis fetches nothing, but when current rules are needed both skills permit public documentation retrieval on `help.shopify.com` or `shopify.dev`, with redirects confined to those domains and no supplied cart or customer data sent; the Discount Function API URL is documentation, not an API call. GitHub source/support links are references rather than runtime endpoints. The assistant may give copy-ready replies and guide you through admin, Orders/payment-status, support or cart/code checks; you perform external actions yourself and stop checkout before payment. The publisher receives no task data and operates no server, telemetry or storage service for this plugin; your assistant provider handles conversation, attachments and web-tool requests and controls their retention under its own terms. Supply local files only for this task, redact customer names, contact information and order identifiers, use anonymous eligibility labels and country/market details where sufficient, and never provide passwords, tokens or payment details.
