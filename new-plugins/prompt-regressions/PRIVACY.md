# Privacy

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG; it bundles no executable program, installer, hook, server or connector and operates no publisher collection, telemetry or storage service. Preparation from supplied material and exported-result review retrieve nothing, but the skills may write explicitly requested artifacts with the assistant's existing file tools. Requested documentation verification retrieves linked official pages on code.claude.com, developers.openai.com (including learn.chatgpt.com redirects), modelcontextprotocol.io and openai.github.io, exposing the requested URL and ordinary connection metadata to those sites and the web-tool provider. Explicitly requested runner execution may inspect local CLI help, use supported login/status flows, prepare configuration and run the supplied Claude Code, Codex or OpenAI Agents SDK workflow; separately authorized installation can contact selected package registries. The runner can send prompts, inputs and tool arguments to its configured model provider and MCP endpoints, incur charges, write artifacts and perform configured tool side effects, including authorized external writes or sends; the actual destinations depend on the supplied configuration and require authorization for reads, writes, network calls and paid usage. The skills prohibit trace uploads to other services, credential-file reads and permission bypasses. Supply relevant extracts and redact credentials and unnecessary personal data. The publisher receives no task data through the package; conversation and attachment processing and retention follow your assistant provider's terms, while runner providers, endpoints and logs follow that runtime's policies. Requested local artifacts remain under your control. There is no plugin-owned account, database, background job or automatic network call.
