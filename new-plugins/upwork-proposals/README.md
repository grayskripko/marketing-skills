# Upwork Proposals

Assess an Upwork job and prepare a proposal from the actual portfolio, screening questions, rate and current Connects conditions.
For freelancers and agency proposal writers. Provide pasted job text or exports, actual portfolio evidence, screening questions, availability, rate floor, and the current proposal-form Connects and fee figures. No account, key, install or paid API is required for preparation.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON platform metadata, and a static SVG icon. It bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The `.claude-plugin` and `.codex-plugin` directories contain platform metadata, not servers. Development notes and test results currently remain in this folder and should be excluded from a clean submitted package.

The skills analyze pasted task text, attachments, and user-selected local files. They are not strictly offline: all three instruct the assistant to refresh relevant rules before spending or submission decisions by retrieving only the eight official `support.upwork.com` article URLs in their bundled rule registers, their robots.txt, and official Upwork redirects through the assistant's existing retrieval tools. `draft-proposal` also calls for refreshing the registered edit article for a specific edit decision. Those requests disclose the requested URLs and ordinary connection metadata to the contacted Upwork sites and the assistant's tool provider; supplied job, portfolio and account material must not be included in retrieval queries. Portfolio URLs are evidence labels, not retrieval targets: paste the relevant content. If retrieval is unavailable, provide current official rule text and form/history values; unresolved rules must remain unresolved.

The skills do not direct code execution, software installation, API calls, account connections, or automated submission, messaging, bidding, purchases or settings changes. They return preparation text and arithmetic from supplied values. Reading selected files uses the assistant's existing file tools; outputs are saved only where the user requests through those tools. Proposal edit and offer-change steps describe actions for the user to perform in Upwork, not actions performed by this package.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider processes and may retain conversations, attachments and tool data under its own terms. Repository, documentation and support links identify project pages; they do not instruct the skills to contact GitHub.

## Skills

- **assess-job:** apply, pass, or clarify using portfolio scope, invitation status, the shown fee and a floor-preserving gross rate.
- **draft-proposal:** cover letter, separate screening answers, agency/form fields and invitation replies. For submitted proposals, separates the edit window from an offer-change request.
- **plan-connects:** base and optional boost budget, net-rate calculation, and charge/refund explanation from signed history rows, including confirmed placebo auctions.

Paste the records or supply selected local files. The agent can help identify the needed fields in Upwork; you retain control of submission and purchases. A video-interview form produces preparation notes rather than a substitute interview.
