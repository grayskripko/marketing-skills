# Privacy

This package bundles instructions, references, JSON platform metadata and a static SVG, with development notes and test results currently retained; it includes no executable scripts, dependencies, installers, hooks, servers, background processes or account connector. It analyzes pasted material, attachments and user-selected local files, but is not strictly offline: all three skills direct rule refreshes before spending or submission decisions through the assistant's existing retrieval tools, limited to the eight registered `support.upwork.com` articles, their robots.txt and official Upwork redirects; draft-proposal also refreshes the registered edit article for specific edit decisions. Requests disclose URLs and ordinary connection metadata to contacted Upwork sites and the tool provider; supplied job, portfolio and account material must not enter retrieval queries. Portfolio links are labels requiring supplied content, and project/support links are references. The skills do not direct code execution, installation, API calls, account access or automated sending, submission, bidding, purchases or settings changes; described Upwork actions remain the user's responsibility. Selected-file reads and explicitly requested output saving use existing assistant file tools. The publisher receives no task data and operates no collection, telemetry or storage service; the assistant provider controls conversation, attachment and tool-data processing and retention. Supply only necessary material, omit credentials and unnecessary personal data, and approve any necessary private details in outgoing drafts. If retrieval is unavailable, supply current official rule text and form/history values; unsupported decisions remain unresolved.
