# Privacy: SF425 Reporting

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installing it does not run a program or connect an account. Its drafting and calendar skills use only task text, attachments, and local files you explicitly supply plus bundled references; they do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, account access, message delivery, publication, or account-setting changes. Source and support URLs identify references you may open yourself, not endpoints used by these skills; paste relevant content rather than supplying a URL alone. The publisher receives no task data and operates no collection, telemetry, or storage service; your assistant provider processes and may retain conversations and attachments under its own terms. Any output file you explicitly request is created by your assistant's existing file tools at your requested destination, not by a bundled program. Supplied records may contain grant identifiers, recipient addresses, ledger entries, contributions, subrecipient amounts, and certifying-official details; remove unnecessary personal data, payroll names, bank details, and credentials before sharing. No passwords, API keys, or bank credentials are needed. Separate policy research or publisher reference maintenance is outside these offline drafting and calendar workflows.
