# Privacy

This skills-only package contains Markdown instructions and references, JSON metadata, and a static icon; it bundles no executable program, dependencies, installers, hooks, connectors, MCP/LSP servers, or background processes. Rubric repair and import diagnosis read only the task text, attachments, local files, exports, and errors you supply; they fetch nothing, request no credentials, and return text, API drafts, or manual Classroom steps without account access, API calls, uploads, message delivery, publication, or settings changes. Manual import/edit/save/export steps are performed by you in Google's service. The assistant may use its existing local calculation or code tools for arithmetic on supplied values and its file tools for an output file you explicitly request, without installing packages or requesting network access; execution and temporary files are managed by the assistant provider. Separately, both source registers instruct maintainers to recheck public documentation before submission: if performed, those network requests go to support.google.com and developers.google.com, including the documented Request.Errors redirect to troubleshooting/common-errors, exposing requested URLs and ordinary connection metadata to those sites and the retrieval provider, with no instruction to transmit rubric content. GitHub links identify author, repository, and support pages, not skill-directed retrieval or message destinations. The publisher receives no task data and operates no collection, telemetry, or storage service; your assistant provider processes and may retain conversations, attachments, and tool activity under its own terms, and requested local outputs remain under your control. Student names and grades are unnecessary for this workflow; omit personal data and credentials, and manage supplied files and conversations through the host's controls.
