# Privacy

The assistant reads pasted tokenizer or processor configs, templates, token maps, transcripts, errors and user-selected exports to audit serialization and draft corrected text. These inputs may contain personal or proprietary text; redact credentials and irrelevant personal details before sharing.

Network: none for normal work. An explicitly requested documentation refresh fetches only relevant official Hugging Face documentation or Transformers GitHub source pages. Pasted content is not uploaded. Transcript URLs, media and model weights are not fetched. No accounts, connectors or paid APIs are required.

This package runs no service, stores no inputs and adds no telemetry. Conversation processing and retention follow the assistant provider's settings. Delete the conversation or supplied files using that host's controls. Suggested snippets are text for the user to apply; the package performs no remote checkpoint changes or tool calls.
