# Privacy

Postgres Query Plans analyzes plan text, exports, attachments, and screenshot details you explicitly supply; redact sensitive literals and identifiers before sharing, and do not provide credentials. The package contains Markdown instructions and references, JSON metadata, a static SVG icon, and text-only development records, with no executable helper, installer, hook, MCP/LSP server, database connector, or background process. Its skills do not execute SQL, install software, access database accounts, call database APIs, upload plans, send messages, publish content, change account settings, or direct extra local copies or output-file writes. They do instruct the assistant to fetch relevant public documentation under https://www.postgresql.org/docs/ for needed refreshes or server-version checks, keeping redirects on that site and excluding supplied SQL, plans, identifiers, and private context from requests; those requests reach the documentation host through the assistant's existing web tools. The skills also propose SQL and guide user-run captures and controlled tests in the user's existing client, including EXPLAIN ANALYZE, targeted ANALYZE, candidate indexes, and transaction-local settings; the assistant does not run these actions, and user execution can add load or cause side effects that ROLLBACK or read-only mode cannot universally contain. The publisher operates no collection, telemetry, or storage service and receives no task data. Conversation and attachment processing and retention follow the assistant provider's terms and settings; project homepage and repository links are metadata references, not workflow connections.
