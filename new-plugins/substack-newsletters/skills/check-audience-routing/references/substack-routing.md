# Substack routing reference

Verified by opening official Help Center pages on 2026-10-11. Publisher update dates below are separate from the read date. These were the current accessible articles at build time; recheck before submission around 2026-10-13 if the feature or UI changes. Scope: Substack sections, saved subscriber filters and tags. This is a concise decision register, not a copied manual.

## Sources and supported facts

- **Sections** — updated 2026-09-24; read 2026-10-11. https://support.substack.com/hc/en-us/articles/360060687771-How-can-I-create-multiple-newsletters-or-podcasts-under-one-publication
  Creation path: Settings → Sections → Add section. Separate controls cover future signups and copying current readers. Copying includes other sections' readers and sends no addition notice. Later bulk addition enables section email. Display options are separate. Sections get `/s/<title>` URLs, editable in settings. An existing post can be moved using its editor's section dropdown. Deletion relocates posts to the main publication.
- **Segments** — updated 2026-08-06; read 2026-10-11. https://support.substack.com/hc/en-us/articles/52113249525140-What-are-subscriber-segments-on-Substack
  Saved filters change membership automatically. Documented criteria include tags, country, activity, paid status and signup date. Multiple filters can be combined. Edit offers updating the current segment or saving a new one. Direct email opens an email-only draft. Advanced publication targeting limits email/app push recipients, not the post's web/app visibility.
- **Section membership** — updated 2024-01-04; read 2026-10-11, currently accessible. https://support.substack.com/hc/en-us/articles/22523681632148-How-do-I-see-who-is-subscribed-to-a-section-on-my-Substack-publication
  Subscriber filters expose Receiving emails for and any/all/none operators. The article's tip loosely calls a single all-match exclusive. Do not infer exclusivity: inspect other memberships or exclude other sections.
- **Subscriber tags** — updated 2026-08-07; read 2026-10-11. https://support.substack.com/hc/en-us/articles/52110366555668-How-do-I-add-tags-to-a-subscriber-on-Substack
  Private writer-visible labels, unlimited per reader, editable/removable. Apply during import, to filtered selections or on an individual profile. Filter by tags or display a Tags column. Post tags are a separate navigation feature.

## Applying these paths

Use these Substack paths only after the platform is established. A documented control is not an observed account control: make unseen save-new, combined-filter and post-move steps conditional on what the user can see. Answer supplied audience logic or readiness first when the platform is unknown.

## Unknowns and authored choices

No numeric section limit, segment limit, tag-name length or exact section/segment/paywall intersection rule is established by these pages. Do not invent one. No error-code catalog is claimed. Optional-section defaults OFF, redacted inputs and separating access from notifications are authored workflow choices. A recipient count from an export describes its supplied snapshot, not the live dynamic segment. No field named in an export proves opt-in without the user's field definition and provenance.
