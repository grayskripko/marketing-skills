# Substack Newsletters privacy

This skills-only package contains Markdown instructions and references, JSON metadata and a static SVG icon; it bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes or account connector. Installation runs no program and connects no account. Ordinary planning and routing checks use only supplied publication notes, redacted exports, settings text and described screenshots plus bundled references; the skills do not direct code execution, software installation, API calls, automated account changes, subscriber imports, message delivery or publishing. They guide the publication owner through native settings, draft preparation, membership exports and post backups, pausing sends, contacting Support and owner-controlled verification; the owner performs those external actions. The package is not strictly offline: only when you explicitly request current-rule verification may the assistant use its existing web tools to retrieve the four public support.substack.com Help Center articles listed in the README and both bundled routing references, including redirects on that same host; no subscriber data is included in requests. Other source, publisher and support links are references, not automatic connections. No publisher service collects, stores or receives task data, and there is no telemetry; your assistant provider processes and may retain conversations, attachments and tool activity under its own policies. The skills require no output files; any file you explicitly request is created by the assistant's existing file tools. Redact reader names, email addresses and private tags where unnecessary, use anonymous row labels, and never supply passwords, tokens or session cookies.
