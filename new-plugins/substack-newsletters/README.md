# Substack Newsletters

Plan Substack newsletters, sections, reader choices and publication organization.
For Substack writers planning sections or checking audience routing. Needs pasted publication notes, redacted exports, settings text or screenshots described by you. Planning needs no Substack account access, key or paid API; applying changes needs your own publication settings access.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The Claude and Codex manifests describe the same skills for their respective assistant platforms; the Codex manifest is metadata, not a server.

Ordinary planning and routing checks use publication notes, redacted exports, settings text and screenshot descriptions that you supply, plus bundled references. The skills do not instruct code execution, software installation, API calls or automated account access. They return plans and checklists, not account changes, subscriber imports, subscriptions, messages or published posts. Native Substack steps are instructions for the publication owner: creating or editing sections and segments, inspecting memberships and recipient previews, preparing drafts, moving posts, exporting membership records and backing up posts, pausing sends, contacting Support and verifying behavior with owner-controlled accounts. The owner applies changes and performs any send in Substack.

**Optional network activity:** when you explicitly request current-rule verification, the assistant may retrieve only the four public `support.substack.com` Help Center articles listed below and redirects on that same host, using its existing web tools. Requests include no subscriber data. This exception means the package is not strictly offline. It does not authorize fetching arbitrary supplied URLs, general web search, robots.txt retrieval or account connections.

- [Sections](https://support.substack.com/hc/en-us/articles/360060687771-How-can-I-create-multiple-newsletters-or-podcasts-under-one-publication)
- [Subscriber segments](https://support.substack.com/hc/en-us/articles/52113249525140-What-are-subscriber-segments-on-Substack)
- [Section membership](https://support.substack.com/hc/en-us/articles/22523681632148-How-do-I-see-who-is-subscribed-to-a-section-on-my-Substack-publication)
- [Subscriber tags](https://support.substack.com/hc/en-us/articles/52110366555668-How-do-I-add-tags-to-a-subscriber-on-Substack)

Publisher, repository, documentation and support links identify resources; they are not automatic connection instructions. The publisher receives no task data and operates no collection, telemetry or storage service for this plugin. Your assistant provider processes and may retain conversations, attachments and tool activity under its own terms. The skills do not require output-file creation; any output file you explicitly request uses your assistant's existing file tools, not a bundled program.

- **Plan newsletter sections:** publication structure, newsletter purpose, owners, cadence, section setup and audience-routing/settings matrix, separating current readers from future defaults.
- **Prepare an issue:** editorial review and send checklist covering content, links, intended recipients, access settings and final owner approval.
- **Check audience routing:** corrected settings and recipient logic, separating subscriptions, segment notifications and post visibility.

The assistant can walk you through native Substack settings. This package does not connect to your account or change it. It does not import, enroll, send or publish. Exports describe a snapshot and may omit live memberships.

Example: “I want a core weekly issue and optional local-news and interviews sections. Existing readers should keep their current choices; new readers must opt into extras. Give me the settings matrix.”
