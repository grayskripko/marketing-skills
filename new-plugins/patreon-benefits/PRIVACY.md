# Privacy: Patreon Benefits

Work out who should receive this month's Patreon benefits and explain missing rewards from pasted member exports.

This package contains instructions and reference text; it operates no service.

- Data read: supplied membership rows, payment/status dates, tier terms and delivery records; user-selected local files may also contain names, emails, Discord handles and shipping addresses.
- Purpose: month-specific benefit lists and explanations of exceptions in the current conversation.
- Data minimization: use row IDs and address-present flags. Full contact details are unnecessary for an eligibility review. No credential collection or reconstruction of missing contacts.
- Recipients: the assistant provider processes supplied conversation data and selected files. The package sends no data to Patreon or another service.
- Network requests: none. Official knowledge is embedded; neither skill fetches pages or calls accounts, APIs or connectors.
- Storage: no telemetry, plugin-operated storage or background jobs. Assistant conversation and file retention follow the user's host settings. Any requested output file stays in the user-selected destination.
- Controls: redact unneeded personal data before sharing; remove files or delete the conversation through the assistant host.
