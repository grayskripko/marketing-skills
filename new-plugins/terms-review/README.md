# Terms Review

Review UK consumer terms, checkout notices and actual charging/cancellation practices against current CMA37 guidance; produce clause-specific findings and clearer proposed wording.
For teams selling goods, services or digital content to UK consumers. Provide pasted terms, ordered checkout screenshots or text exports, and charging or cancellation records. No account, key, paid API or setup is needed.

| Skill | Give it | Get back |
|---|---|---|
| consumer-terms-review | Terms, policies and offer context | Clause findings, replacement wording and policy changes |
| checkout-notices-review | Offer, basket, payment and confirmation copy in order | Screen-specific corrections and placement |
| charging-cancellation-review | Terms, notices and charge/cancellation/refund records | Promise-to-practice findings and matching wording |

Each review preserves supplied prices, dates, scope and exceptions. Proposed changes are identified as proposals. Missing details appear where they affect wording. A text export supports copy review; supplied screenshots support findings about visible placement.

## Example requests

- “Review these UK customer terms and propose clearer clauses: [paste terms].”
- “Check this checkout sequence and show where each corrected notice belongs: [paste copy or provide screenshots].”
- “Compare our cancellation terms with these charge and refund rows: [paste terms and anonymised export].”

## Data and network

For current rules, the assistant fetches public official pages on www.gov.uk, assets.publishing.service.gov.uk and www.legislation.gov.uk, including linked official documents and redirects within these hosts. It may search those official domains using generic legal topic queries. Customer text, names, transaction data and private URLs must never enter search queries or fetch requests. No customer website is fetched; paste or export its contents. The package contains instructions and reference text, with a static SVG icon. It has no connectors, executable tools, telemetry or storage service. It reads only materials supplied for the review.

## Source upkeep

The reference register records sources opened on 11 October 2026. CMA37 and the short business guide were updated on 22 July 2026. Check the publication page and relevant commencement rules again before the planned 22 October 2026 submission and during a current review.
