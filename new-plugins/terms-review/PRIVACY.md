# Privacy: Terms Review

This skills-only package reviews supplied contracts, checkout materials and transaction exports in the current assistant conversation. They may contain customer identifiers, communications, payment amounts and dates. Use anonymous row labels; names, addresses and payment credentials are not needed.

For current rules, the assistant fetches public official pages on www.gov.uk, assets.publishing.service.gov.uk and www.legislation.gov.uk, including linked official documents and redirects within these hosts. It may search those official domains using generic legal topic queries. Customer text, names, transaction data and private URLs must never enter search queries or fetch requests. No customer website is fetched; paste or export its contents.

The plugin operates no service, keeps no independent copy, sends no messages and changes no accounts. The assistant provider processes the conversation and any supplied files under its own retention settings. Delete the conversation or supplied files through that assistant. No telemetry or paid API is used.
