This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon, and text-only development evidence; it has no executable program, installer, dependency, hook, MCP/LSP server, background process or account connector. Normal checks analyze only pasted terms, attachments and explicitly selected files using bundled references. Both skills permit user-requested retrieval of only the official CSLB and California Legislative Information URLs listed in their references, with redirects within `cslb.ca.gov` (including `www.cslb.ca.gov`) and `leginfo.legislature.ca.gov`; source registers also call for release-time official-text verification. These requests use the assistant's existing web tools and disclose the public URL and ordinary connection metadata to those official sites and the tool provider, never contract text, personal data or contractor identifiers in URL queries. If retrieval is unavailable, supply official text or leave current verification unresolved against the dated snapshot. Contractor-specific registry status is assessed only from supplied exports. The skills direct no code execution, software installation, other API calls, account access, message sending, publication or settings changes; replies and notices are conversation drafts, and quoted statutory directions to call, write or send are user-facing reference text. No skill directs file creation; an explicitly requested saved output uses the assistant's existing file tools and chosen location. The publisher receives no task data and runs no telemetry, collection or storage service; the assistant provider processes and may retain conversations and attachments under its terms and settings, and manages any tool processing or saved outputs. Redact unnecessary names, addresses, signatures, account numbers and credentials while preserving labels needed to assess project/bond coverage. The supplied-material workflow makes no additional network requests; optional verification does. The support link below is not automatically contacted.
