# Privacy: Attio Imports

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon; it bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers, connector or background process, and installation runs no program or account connection. The assistant analyzes CRM text, selected exports and screenshot descriptions you supply, which may contain names, contact details, company links, deal values and notes. It may use existing local file/data-processing tools, including host code for CSV writing and full-file validation when tools exist, and write requested transformed, recovery or held-row files only at your chosen destination while preserving originals; the assistant provider manages execution and temporary files. Both skills permit optional public attio.com/help page retrieval and generic searches restricted to that site when current documentation is needed: requested URLs, generic search terms and ordinary connection metadata reach Attio and the assistant's web/search providers as applicable, but CRM rows, personal identifiers and private context are excluded and export-row links are not opened. Supplied-data preparation with bundled references requires no documentation retrieval. The skills do not install software, call account APIs, log in, connect to CRM or migration services, upload exports, send messages, publish content, execute imports/retries or change account settings. They explain user-performed imports, scoped UI edits/cancellation and optional Import2 setup; any import you perform yourself sends your reviewed file to Attio, and any separately chosen Import2 service has its own account/data handling. The publisher receives no task data and operates no server, telemetry, collection or storage service; your assistant provider's conversation, attachment, tool and file processing/retention terms apply, and generated local files remain until you remove them. GitHub documentation and support links are references, not runtime connection instructions. Supply only necessary data, never passwords, tokens or API keys, and avoid posting CRM data in public support issues.
