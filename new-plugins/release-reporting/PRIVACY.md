# Privacy

Release Reporting is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes; installation runs no program and connects no account. Its analysis uses only task text, attachments, and local files you explicitly supply, including release notes, PR details, contributor handles, labels, tags, configuration and exported responses; it does not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, message delivery, publication or account changes. Source and support URLs identify references, not runtime endpoints; paste relevant content rather than supplying a URL alone. One bundled reference advises the user to check request details and access through their normal GitHub workflow: following that advice connects the user's browser or GitHub client to GitHub under its normal account and data policies, without assistant account access or a request for credentials. Documentation-refresh reminders are publisher maintenance before submission, not runtime fetch instructions. The publisher receives no task data and operates no collection, telemetry, storage service or separate task-data copy; your assistant provider processes and may retain conversations and attachments under its own terms, and any output file you explicitly request is created by its existing file tools, not bundled code. Contributor handles support author-exclusion checks and requested attribution; redact credentials and unrelated personal details before supplying material or posting to the public support page.
