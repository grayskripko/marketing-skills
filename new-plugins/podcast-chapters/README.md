# Podcast Chapters

Review timed podcast chapters for Apple and Spotify and produce corrected timestamps and titles for each platform.
For podcast creators and editors preparing chapters or fixing missing chapter updates.
Needs pasted chapter text or exports; include the destination route and episode duration when known. No platform account, API key or additional software is needed to review supplied text.

## Skills

- **repair-chapter-list** — Correct manual description chapters and supplied RSS, JSON or file-metadata exports. Return a paste-ready list or a minimal corrected snippet, with requirements separate from recommendations.
- **review-auto-chapters** — Review automatic chapter downloads and editor values. Return corrected edits or a useful partial list, explain eligibility and diagnose update symptoms from supplied evidence.

Paste a description, Apple TXT download, Spotify chapter table, relevant RSS item, chapter JSON or host-form export. Known audio boundaries are preserved. Missing topics or times are marked for completion rather than invented. For both platforms, outputs are labelled by route.

## Data and network

Reads only text and files you supply for the task. Ordinary review fetches nothing. If current platform rules need verification, the agent may fetch public documentation on podcasters.apple.com, support.spotify.com, podlove.org and github.com/Podcastindex-org, including documentation redirects. Podcast feeds, audio, chapter artwork and URLs inside exports are not fetched automatically. No telemetry, account access, background jobs or plugin-managed storage.

The dated rule sources are in each skill's references/source-register.md. Rules were checked on 2026-10-11. Before submission around 2026-10-24, recheck these sources and the destination's package requirements.
