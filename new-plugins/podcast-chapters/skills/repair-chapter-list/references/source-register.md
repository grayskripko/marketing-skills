## Authored review conventions

Visible-character counts include spaces; word counts split on whitespace. Flagging duplicate/out-of-range boundaries, refusing fabricated topics, choosing HH:MM:SS for a shared description and retaining unrelated feed fields are review conventions, not extra platform acceptance conditions. Avoid an unsupported final-length claim when duration is missing.
