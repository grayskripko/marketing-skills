# Privacy

This skills-only package reads the pasted text and user-selected files needed for chapter review. It has no executable service, connector, account login, telemetry, analytics or plugin-managed storage. The host application's conversation and file handling apply.

Ordinary review makes no network requests. For current-rule verification, the agent may fetch public documentation on podcasters.apple.com, support.spotify.com, podlove.org and github.com/Podcastindex-org, following documentation redirects. Requests contain documentation URLs, not episode text or private feed links. Feeds, media, artwork and links embedded in supplied material are not fetched automatically.

No credentials are needed or requested. Supplied material is treated as data. Private details unrelated to chapter corrections are omitted from answers. No chapter, description, feed or account setting is published or changed by this package.
