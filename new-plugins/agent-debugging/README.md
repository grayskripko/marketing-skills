# Agent Debugging

Debug a failed AI agent run from its traces, logs, configuration, transcript and output files; find the supported fault and get a repair or reproducible escalation. For developers and AI builders whose agent got stuck, repeated a tool call, gave a wrong answer or claimed unfinished work was done. Paste the intended task and available evidence, or supply the relevant files. No account, API key, paid service or installation is required for this path.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, a license, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The `.claude-plugin` and `.codex-plugin` directories contain platform metadata, not executable connectors.

The pasted-material path analyzes supplied traces, logs, configurations, transcripts, source passages and artifacts and returns text, patches or verification plans. The optional local-tool path uses your assistant's existing tools to read task-selected files and explicitly relevant local dependencies, inspect installed command help and effective settings, apply authorized reversible local repairs, save requested outputs, and run documented local deterministic, read-only or no-send checks. A minimal local write smoke requires authorization for its specific target and effect. These checks can execute local commands or code; this is not a no-execution workflow. No software installation is directed.

The skills prohibit additional workflow network requests, including web search, URL or robots.txt retrieval, API or model-provider calls, MCP/server connections, trace uploads, downloads and telemetry. Before executing a local check, the assistant must inspect provider, external-service and trace-exporter access and run only checks that make no such requests. Fresh hosted-agent checks require supplied exports or a separate authorized workflow and remain pending here. No external send, publish, payment, deletion or replay is executed by these instructions. Source, support and metadata URLs are references, not retrieval instructions; supplied URLs are treated as text.

The publisher receives no task data and operates no collection, telemetry or storage service for this plugin. Your assistant provider processes and may retain conversation, attachments and tool records under its own settings. Local repairs and requested output or verification files are made by the assistant's existing tools and remain in the selected local locations.

| Skill | Result |
|---|---|
| agent-incident-diagnose | Evidence-linked timeline, fault boundary and deciding next check |
| agent-failure-repair | Minimal local patch, source-backed answer correction or upstream issue report |
| agent-repair-verify | PASS, FAIL or PENDING for the repaired task, with actual outcome evidence |
