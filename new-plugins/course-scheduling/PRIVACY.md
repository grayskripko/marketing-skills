# Privacy: Course Scheduling

This package contains instructions, reference text, JSON metadata, a static SVG icon, and development review/evaluation records; it bundles no executable program, installer, connector, server, hook, or background process. Both skills use pasted material and user-selected local files and may execute calculations through the assistant's existing datetime/zoneinfo or equivalent local tools; dependencies require a separate user request, outside this workflow. Calendar creation writes a local text/CSV file only to a destination the user requests. Calendar work does not fetch URLs, search, call APIs, access accounts, send email, or change course settings. The owner obtains exports in Teachable and manually reviews/performs recommended settings changes or custom Emails > Compose sends. Separately, the source register tells release maintainers to reopen four public help pages at support.teachable.com and Python zoneinfo documentation at docs.python.org before submission; those maintenance requests disclose URLs and ordinary connection metadata to the sites and tool provider, without requiring course data. Source, repository, and support links are otherwise references, not runtime endpoints. The publisher receives no task data and operates no collection, telemetry, or storage service. The assistant provider controls processing and retention of conversations, selected files, tool execution, and temporary files; requested local outputs remain under the user's control. Inputs can include settings, enrollment dates, section titles, subjects and access history; use student labels and omit unnecessary personal data and credentials. Support: https://github.com/grayskripko/marketing-skills/issues — avoid including private course or learner data in public issues.
