# Privacy — IntakeQ Forms

The package contains skills and reference text. It reads pasted questionnaires, mappings, payer settings and anonymous profile examples, or files the user supplies, to produce corrections and exception checklists.

Use anonymous labels and remove names, dates of birth, member IDs and account identifiers. These identifiers are not needed for the work. If supplied accidentally, the skills omit them from output.

Network: none during skill use. No login, connector, API, tracking, external upload or telemetry is included. The package stores no data and operates no service. Conversation and file processing and retention follow the assistant host's settings. Users can remove supplied files and delete conversations through that host.
