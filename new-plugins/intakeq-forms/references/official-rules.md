# Official IntakeQ / PracticeQ rules

All seven pages loaded on 2026-10-11; read 2026-10-11. Dates below are the pages' displayed last-updated dates. Current means accessible official guidance on the read date. Summaries are paraphrases; no screenshot-only field schema is inferred.

| Source | Updated | Supported scope and deciding knowledge |
|---|---|---|
| [Insurance and the Client Profile](https://support.intakeq.com/article/827-insurance-and-the-client-profile) | 2026-04-07 | PracticeQ profile billing: Self Pay/Unknown charges full service price; a submitted claim switches Billing Type to Insurance. Insurance uses Insurance 1/2. Deductible/out-of-pocket require manual entry; enabled coinsurance also needs payer Allowed Amounts. Secondary payer submission is unavailable; secondary payments may be recorded manually. |
| [Insurance Badges in Client Profile](https://support.intakeq.com/article/1250-new-insurance-badges-in-client-profile) | 2026-10-02 | In Network/Out Of Network require selection from the account's Payer List plus a clear/checked out-of-network checkbox respectively. Matching typed names alone do not establish selection. Outside-list client or staff entries can show Not On Payer List. The client unlisted-payer toggle controls client selection, while staff may enter unlisted payers regardless. Settings path: Lists → Claims → Claims Settings → Payers. |
| [Map Client Billing Type](https://support.intakeq.com/article/816-map-client-billing-type) | 2025-08-08 | Bulk claims require Insurance billing type. Existing clients: Lists → Clients → select client → Overview → Edit → Billing Type. The questionnaire's three-dot menu → Rules → Add New Rule → IF question / EQUALS answer / THEN Billing Type / mapping choice → Save maps billing type on subsequent form submission. |
| [Mapped Insurance Questions](https://support.intakeq.com/article/352-mapped-insurance-questions) | 2026-01-14 | Built-in primary/secondary insurance questions map into client profiles and support claims/superbills. Added or removed question fields are supported. |
| [Allow Unlisted Payers Setting](https://support.intakeq.com/article/1254-new-allow-unlisted-payers-setting) | 2026-10-02 | Lists → Claims → Claims Settings → Payers contains the client unlisted-payer toggle. Staff can manually enter payers regardless of its setting. The configuration chart is an image; no additional chart cases are inferred here. |
| [Set Allowed Amounts by Payer](https://support.intakeq.com/article/853-set-allowed-amounts-by-payer) | 2025-07-15 | Payers → Edit → Add Allowed Amount requires the payer amount for every CPT code used. Missing code-specific amounts prevent coinsurance application and produce an appointment-dialog notification. The article says Claim Settings; the newer profile/badge articles say Claims Settings for the same Payers route. |
| [Form Template Ownership](https://support.intakeq.com/article/981-form-template-ownership) | 2025-09-03 | To inspect Rules, open the questionnaire and use its three-dot menu. This corroborates that the Billing Type rule editor is in the form menu, not the individual question options. |

## Application judgments

Badge status is not patient coverage verification: this follows from the documented configuration logic, rather than a quoted insurance verification policy. Keep this inference explicit internally. Comparing declared mapping against observed profile values, refusing to infer destination IDs, and using affected-row tables are authored workflow choices. These sources do not enumerate all editable insurance fields, all payer rules, eligibility responses or claim error codes. Request the specific pasted configuration or official message when those details matter.
