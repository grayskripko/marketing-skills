# Privacy: Agent Design

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes, or account connector. It designs one process from task text, attachments, and files you explicitly supply or identify, using only relevant portions and redacting unnecessary identifiers and secrets in deliverables; never supply credentials. It does not direct code execution, software installation, business API calls, message delivery, deployment, or account changes: SDK/runtime installation, scoped service authorization, secret storage, and persistence are implementation-planning details only. It saves output files through your assistant's existing file tools only when requested. The supplied-material workflow needs no additional network requests, but an explicit request to refresh platform guidance permits your assistant's existing browsing tool to fetch the official documentation URLs in references/sources.md and their official redirects, or exact public documentation URLs you supply for the chosen stack. Registered destinations are www.anthropic.com, docs.cloud.google.com, code.claude.com, learn.chatgpt.com, openai.github.io, modelcontextprotocol.io, developers.openai.com, docs.langchain.com, and developers.llamaindex.ai; documentation requests disclose the requested URL and ordinary connection metadata to those sites and the assistant's tool provider, without uploading process notes, logs, configs, transcripts, or files. No web search or login is directed; paste documentation instead when browsing is unavailable or unwanted. Repository and support links are project references, not automatic retrieval or message-delivery instructions. The publisher receives no task data and operates no server, collection, telemetry, or storage service for this plugin. Your assistant provider processes and may retain conversations, attachments, and tool activity under its own terms; requested output files are managed by your assistant and host and can be deleted through their controls.
