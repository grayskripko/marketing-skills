# Privacy: Notion Templates

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, a static SVG icon, and development documentation; it bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installation does not run a program or connect an account. Skills use only task text, attachments and user-selected local files, without web search, URL retrieval, API calls, account connections, message delivery or publishing; source and support links are references, not retrieval instructions. The CSV skill asks the assistant to validate supplied rows with a real CSV reader when available, which may use its existing local code or file tools without installation or network access; otherwise it inspects fields without claiming parser execution. All three skills may create explicitly requested local output files through supported host tools. The provider manages execution and temporary files and processes and may retain conversations, attachments and tool outputs under its own terms; the publisher receives no task data and operates no collection, telemetry or storage service. Requested files remain where the host saves them and their deletion is under your control. Manual setup, CSV import and scratch formula/database checks are performed by you in Notion desktop/web, can connect to Notion and change your workspace, and disclose entered or imported content to Notion under its terms; the assistant neither performs those actions nor claims they succeeded. Supply only necessary workflow notes, property definitions, formula errors and rows, redact unrelated personal data, and never supply credentials.
