# Privacy: Hotel Fees

This package contains instructions, reference text and an icon. It runs no service and includes no executable tools.

It reads supplied rates, fee schedules, booking exports, screenshots and files identified for the task to check or draft price displays. Guest names, reservation identifiers and payment details are unnecessary; omit them. Supplied material stays in the assistant conversation and any output files the user requests. The package has no separate storage, telemetry or recipients. The assistant provider processes and retains conversations under its own settings; its conversation controls apply.

Network requests: none. No searches, URL fetches, robots.txt requests, accounts, connectors or external writes. Official source URLs in references are citations, not automatic fetch instructions. New rule text can be pasted or bundled in a package update.
