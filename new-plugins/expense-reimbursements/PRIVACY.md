# Privacy: Expense Reimbursements

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it provides no executable program, dependency, installer, hook, MCP/LSP server, background process, or account connector. The assistant uses only task material you explicitly supply and the bundled reference to draft policies and review expense evidence; it does not direct code execution, software installation, API calls, message delivery, publication, payments, payroll changes, tax filings, or account/settings changes. It is not strictly offline: to refresh a rule or rate, the assistant may fetch public IRS pages/PDFs at `irs.gov` or federal regulation pages at `ecfr.gov`, plus their `robots.txt`, respecting fetching restrictions and keeping redirects within those domains; private employee, receipt, and company facts must never enter network queries or requests. These public requests use the assistant's existing retrieval tools; source-register links support that refresh, while GitHub repository/support links are informational and do not submit issues. If retrieval fails, a user-pasted official excerpt can establish only its stated scope and effective period. The publisher operates no collection, telemetry, or storage service and receives no task data; your assistant provider processes and may retain conversations and attachments under its own terms, and an explicitly requested local output uses the assistant's existing file tools. Supply selected rows rather than unnecessary full exports, use employee aliases and masked identifiers, and redact card/bank numbers, home addresses, tax IDs, credentials, and unrelated receipt details; the assistant should not repeat sensitive details in its deliverable.
