# Privacy: Agent Orchestration

This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon, and historical development records; it bundles no executable runtime, installer, hook, MCP/LSP server, telemetry, or publisher storage service. It is not entirely offline or execution-free: authorized execution uses the assistant's existing native agent controls, passing worker briefs and relevant supplied inputs to the existing assistant provider and potentially adding charges; results checks and cost audits can also delegate authorized independent checks. Coding instructions can run local version/help and Git commands, create worktrees or copies, export patches, copy approved files, write results, run real tests, and clean up owned temporary resources; cost auditing directs deterministic code for counts and export-structure checks. Planning alone launches nothing. Supplied-text/local-file workflows do not direct web search, URL/robots.txt retrieval, direct Claude Messages API calls, billing-account access, software installation, or a separate service connection; API references explain supplied events and source/support links are citations, not endpoints to fetch. Separately requested setup uses local or supplied help and a read-only trial; documentation retrieval, live network tasks, sending, publishing, deployment, or account actions need separate relevant authorization and tools, and sign-in occurs through the provider's interface. The publisher receives no task data. The assistant provider processes and may retain conversations, attachments, delegated inputs, transcripts, usage logs, and tool artifacts under its own terms; local results and worktrees remain until scoped host cleanup. Supply only necessary redacted material, never credentials, and restrict each worker's inputs and permissions.
