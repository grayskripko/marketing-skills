# Planning sources and scope

For Claude Code coding plans involving a feature branch or dirty checkout, read the [revision preparation procedure](../../run-agent-work/references/sources.md). It contains the dated official sources and the input-verification barrier to include in the plan. Planning alone does not launch a worker or change session limits.

General task decomposition remains package policy. Host-specific revision, recovery and API accounting guidance belongs to the corresponding execution, result-checking and cost references, rather than a universal host capability promise.
