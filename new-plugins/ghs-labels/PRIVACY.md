# Privacy

GHS Labels is a skills-only package of Markdown instructions and reference text, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers or background processes, and installing it runs no program and connects no account.

It works only on material you paste or attach in the conversation: label text or artwork, classifications, SDS sections and container facts. The skills make no network requests: no URL fetching, web search, API calls, uploads or telemetry. Links in the references are for human reading, not runtime endpoints.

The publisher receives no task data and operates no collection, telemetry or storage service for this plugin. Your assistant provider processes and may retain conversations and attachments under its own settings. Share only what the label review needs; supplier contact details are used only where they belong on the label.
