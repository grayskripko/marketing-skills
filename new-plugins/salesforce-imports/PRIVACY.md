# Privacy

This skills-only package contains Markdown instructions and references, JSON platform metadata, and a static SVG icon; it bundles no executable program, installer, hooks, server, or account connector. Its skills analyze text, attachments, and local files you explicitly supply, may create requested local output files through your assistant's existing file tools, and do not direct code execution, installation, Salesforce API calls, account access, message delivery, or imports. If you explicitly request a documentation refresh, the assistant may retrieve only the public official URLs listed in the skill references on `help.salesforce.com`, `developer.salesforce.com`, and `trailhead.salesforce.com` through its existing browser/web tool; those sites and the retrieval infrastructure receive the public URL and ordinary connection metadata, but private row values, record IDs, credentials, and org URLs must not be included in requests or searches. Supplied-material analysis requires no such retrieval; paste documentation if retrieval is unavailable. Recommended sign-in, settings inspection, exports, mappings, Data Loader options, test imports, and real imports are actions you perform in Salesforce and may read or change records. The publisher receives no task data through the plugin and operates no telemetry, collection, or storage service; conversation, attachment, tool-activity retention, and local output handling belong to your assistant provider and your environment. Repository and support links are references, not connectors. Redact unnecessary personal or confidential CRM data and never supply passwords, access tokens, session cookies, or security tokens; sign in only through Salesforce's own interface.

Questions: https://github.com/grayskripko/marketing-skills/issues — avoid posting CRM data or credentials in public issues.
