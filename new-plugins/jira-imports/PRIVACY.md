# Privacy: Jira Imports

This skills-only package contains Markdown instructions and references, JSON metadata, and a static icon; it bundles no executable program, dependencies, installer, hooks, MCP or LSP server, account connector, background process, telemetry, or storage service. The assistant analyzes only task text and files you supply, which may include work descriptions, comments, names, email addresses, account IDs, project keys, and internal URLs; it may use an available CSV reader and write local outputs only when requested. Both skills permit public documentation searches and fetches on support.atlassian.com and linked official Atlassian documentation, including redirects, through the assistant's existing browsing tools: those requests contact the search service and documentation sites, but must never contain CSV contents, logs, identifiers, or attachment URLs. Attachment URLs and private Jira pages are not fetched, and the skills prescribe no shell commands, software installation, or API calls. You perform Jira validation, imports, retries, configuration changes, and Create or customer-request Send actions yourself; these may write Jira records, expose mapped comments, trigger configured notifications, and cause Jira to retrieve attachment URLs. Preparation requires no login, tokens, or API keys and performs no account actions. The publisher receives no task data or independent copy; conversation, attachment, tool, and output retention are governed by your assistant provider and chosen save location. Keep unnecessary personal data and credentials out of supplied material; exact import identifiers belong in the requested artifact rather than explanatory notes. GitHub publisher/support links identify project pages, not connectors.
