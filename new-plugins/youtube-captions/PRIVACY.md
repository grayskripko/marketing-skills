# Privacy

This skills-only package contains instructions, reference text, platform metadata and a static icon, plus development evidence; it provides no executable program, installer, server, account connector or telemetry. Routine caption repair and terminology review process only text, attachments, selected files and screenshot details you explicitly supply, without fetching anything. Both skills permit an explicit rules-refresh request to retrieve `https://support.google.com/youtube/answer/2734698?hl=en`, `https://support.google.com/youtube/answer/2734796?hl=en`, `https://support.google.com/youtube/answer/6054623?hl=en`, `https://www.w3.org/TR/webvtt1/` and `https://developers.google.com/youtube/v3/docs/captions`, including redirects, through the assistant's existing web tools; contacted sites, redirect destinations and the tool provider receive the requested URL and ordinary connection metadata, but no caption text or glossary content. If retrieval is unavailable, provide the relevant rules as text. The skills direct no code execution, software installation, API calls, account access, video downloads, message delivery or automated uploads; optional YouTube Studio upload guidance is for you to carry out yourself. Drafts are returned as artifacts or text, and any output file you explicitly request is created by the assistant's existing file tools at your chosen destination, without deleting the original. The publisher receives no task data and operates no collection or storage service; conversation, attachment and tool-activity processing and retention are controlled by your assistant provider under its own terms. Supply only necessary material and omit credentials and unnecessary private context.
