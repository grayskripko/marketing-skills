## Package conventions

Source availability → extraction/index → request eligibility/ranking → delivered context → claim/citation support is this package's operational ordering. Minimal repairs, exact identity preservation, no network fetch, a missing-detail question only when needed to complete the request and source-scoped follow-up verdicts are package rules of thumb. They are not attributed to a universal framework requirement.

Optional hit, reciprocal-rank and recall calculations use explicit relevant IDs and a declared document/chunk unit. They are arithmetic on the supplied list, not execution of a framework evaluator. The skills do not supply score thresholds or certification of unseen corpus behavior.
