# Privacy: Ticket Merging

This package contains instructions, reference text and an icon. It runs no service and includes no executable helpers.

- Data read: supplied tickets and exports can contain names, contact aliases, organizations, orders, private notes, attachments metadata and support history. Only material provided for this task is read.
- Purpose: assess proposed ticket merges and prepare preservation plans in the current conversation.
- Network: external URLs fetched at runtime: none. No helpdesk calls, web search, attachment retrieval, credential collection or telemetry. Bundled public sources were checked during development.
- Recipients: the assistant provider processes the supplied conversation and files. The package sends no data to another service.
- Retention: the package has no independent storage. The assistant host manages conversation and file retention. Outputs are saved only where the user requests.
- Controls: use stable aliases, redact personal details and secrets before supplying exports, and retain the relationship distinctions needed to assess exposure. Conversation deletion is managed through the assistant host.
