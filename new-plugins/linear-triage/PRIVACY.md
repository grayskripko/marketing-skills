# Privacy: Linear Triage

This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon and text/JSON development records; it provides no executable program, dependencies, installer, hook, MCP/LSP server or background process, and installation runs no program or account connection. The intake and snooze workflows analyze only task text, attachments and local files explicitly supplied by the user, returning recommendations without executing code, installing software, searching the web, fetching URLs or robots.txt, calling APIs, accessing accounts, sending messages, publishing content or applying changes. Supplied URLs are treated as text; paste the relevant content instead. The two source registers separately instruct release maintainers to “Recheck near 2026-10-20” the public pages https://linear.app/docs/triage, https://linear.app/docs/issue-property, https://linear.app/docs/issue-templates, https://linear.app/docs/triage-intelligence and https://linear.app/docs/inbox: following that instruction uses a browser or the assistant’s web tool and sends the requested URLs and ordinary connection metadata to linear.app and the tool provider, without requiring issue data or account access. Source maintenance therefore involves network requests; task analysis does not direct them. The publisher receives no task data and operates no collection, telemetry or storage service. The assistant provider processes and may retain conversations and attachments under its own terms; any explicitly requested output file is created by the assistant’s existing file tools, not a bundled program. Remove unnecessary personal data and credentials before supplying issue material. Support links are references users may open themselves, not task retrieval instructions.
