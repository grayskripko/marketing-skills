# Booking FAQ

Write booking FAQs, explain how to book and draft booking replies from recurring customer questions and approved policies.
For local service owners. Provide the information needed for your task: customer questions with unnecessary personal details removed, approved services, prices, deposit and cancellation terms, branch, language and booking steps. No accounts, installs or paid APIs are required by the plugin.

| Skill | Give it | Get |
|---|---|---|
| find-booking-questions | inquiry text and approved answers | grouped questions and missing decisions |
| write-booking-faq | questions, approved policies and booking steps | FAQ and booking instructions |
| write-booking-messages | request, status and policy that applies | reply or reusable message draft |
| check-booking-copy | current copy and approved policies that take priority | exact replacements and significant conflicts |

Use FAQ writing for new public answers; use copy checking for repairs. Message writing handles individual replies. Question finding prepares a list rather than finished answers. A request for a question list and FAQ can use both skills.

## How to use

Paste the relevant text or supply authorized readable files. If policy versions disagree, say which approved version takes priority. Remove unnecessary customer identifiers and health details. Keep public and reusable text anonymous. A private reply may keep supplied appointment details needed for that reply. Keep supplied branch exceptions beside their rules. Unknown details and conflicting policies remain marked for owner review.

An inquiry (a question or request about booking), a provisional hold and a confirmed appointment are different. A draft cannot create a booking. Review copy before use. For clinics, use only booking and administrative facts. Legal questions need the country or region whose law applies and qualified review.

## Data and network

Nothing is fetched, including booking links. Only supplied text and authorized task files are read. No calendar connection, live availability, reservation, payment handling, sending or publishing is supported. There is no telemetry or plugin-operated storage. The assistant provider processes the conversation under its own terms. A local tool may count words or rows without network access.

## Troubleshooting

If a supplied file is unreadable, paste the relevant excerpt. If policy versions conflict, say which one takes priority. The parts supported by the supplied facts can still be drafted. A missing booking link stays missing rather than being guessed.
