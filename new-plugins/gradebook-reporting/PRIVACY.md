# Privacy: Gradebook Reporting

This skills-only package contains instructions, reference text, metadata and a static icon, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes or account connector. Its skills analyze only explicitly supplied grade exports, settings and comparison reports plus bundled references, using the assistant's existing file-reading tools; existing local calculation tools may execute calculations, and file tools may create an explicitly requested report, with execution and temporary files managed by the assistant provider. The skills do not direct web search, URL retrieval, API calls, installation, account access, uploads, message delivery, grade publication or settings changes; API-shaped exports are data, and source/support URLs are references rather than retrieval instructions. The README's manual export steps are separate user actions in Google Classroom: downloading a CSV or copying grades to Sheets uses the user's Google account and Google's services. The publisher receives no task data and operates no server, collection, telemetry or storage service; conversation and attachment processing and retention follow the assistant provider's terms, while requested local reports remain under the user's control. Use student aliases and omit unnecessary identifiers, emails, comments and credentials. Development notes and evaluation records in this working folder should be excluded from the submitted release package.
