# Privacy: MCP Checkup

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static icon; it bundles no executable, installer, hook, MCP/LSP server or background process, and installation itself launches no program or account connection. Default diagnosis reads only pasted material and task files you explicitly supply and returns text or configuration snippets, without instructing the assistant to overwrite files. It is not offline-only: requested documentation retrieval can reach code.claude.com, developers.openai.com, learn.chatgpt.com, modelcontextprotocol.io or openai.github.io and official redirects, without sending your traces, configuration or secrets in queries; authorized initialization, discovery and documented read-only calls use an existing trusted client against your named server and its documented authentication provider, disclosing call arguments and ordinary connection metadata, with possible provider charges. Optional Inspector setup downloads from the npm registry and package download hosts and executes Inspector and the reviewed target server, whose own documented destinations, data access and effects must be reviewed before launch. User-led client status commands, local credential setup, provider login, discovery refresh and SDK cache invalidation may launch or reconnect that server or use its authentication flow; applying a proposed repair changes the user's local configuration. Pasted commands alone do not authorize execution, and a redacted pasted trace remains an alternative. Write-tool smoke tests, message delivery, purchases, account-data changes and permission expansion are prohibited. Redact personal data, tokens, cookies and session identifiers before sharing; credentials belong in local configuration or the provider login, never chat. The publisher operates no collection, telemetry or storage service for this package; your assistant provider processes and may retain conversations and supplied files under its own terms, while Inspector and clients may store credentials in a keychain or local files outside this package's control. Source links support diagnosis and may be retrieved for requested documentation updates; support links are user-opened references and fictional `.test` endpoints are examples.
