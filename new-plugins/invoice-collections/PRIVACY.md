# Privacy

Invoice Collections processes invoice details, contract terms and payment history you explicitly supply as conversation text, attachments or selected local files; provide only needed fields and redact bank details, signatures, personal addresses and unrelated records, and never supply credentials. The package contains instructions, reference text, JSON metadata, a static SVG and text/JSON development records, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes or account connector. Both skills direct public-source retrieval for charge verification from gov.uk, smallbusinesscommissioner.gov.uk, bankofengland.co.uk, legislation.gov.uk and bills.parliament.uk, with official document redirects to assets.publishing.service.gov.uk; requests disclose public source URLs and ordinary connection metadata to those sites and the assistant's tool provider, but must never include invoice contents, names, amounts or other customer details in URLs, search queries or calculator forms. The late-payment-charges skill permits the host's existing date/decimal calculation tool, potentially executing host code on supplied values, or carefully verified arithmetic; execution and any temporary calculation files follow the assistant provider's policies. Without browsing, supplied official extracts and bundled dated references support conditional answers. No skill directs installation, account access, sending messages, creating mail-account drafts, publishing, filing claims, collecting payments, editing external invoices or creating output files; messages and charge notices are text drafts. The publisher operates no server, telemetry or storage service and receives no task data; the assistant provider processes and may retain conversations, attachments and tool inputs under its own terms. Repository and support URLs identify package information and are not skill-directed retrieval destinations.
