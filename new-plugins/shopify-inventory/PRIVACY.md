# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP/LSP servers, or background processes, and installation runs no program or account connection. The skills analyze only task text, attachments, and local files you explicitly supply, including inventory rows, counts, movements, errors, and screenshots; the assistant may read these files and create requested correction or retry CSV copies using its existing file tools. They do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, store access, uploads, message delivery, publication, or account-setting changes. Source/support URLs are references, and supplied URLs are treated as text; paste their relevant content. The reference’s pre-submission recheck is publisher maintenance, not runtime retrieval. The user separately exports inventory, views Shopify history/reports, uploads and starts imports, and checks outcomes in their own account: those user actions connect to Shopify and imports change inventory, but the skills do not execute them. The publisher receives no task data and operates no collection, telemetry, storage, or other service for this plugin. Your assistant provider processes and may retain conversation and attachments under its own terms; requested output files remain under your control. Remove unnecessary customer/staff identities and credentials before supplying material; no credentials are required.
