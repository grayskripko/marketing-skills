# Privacy: Tool Autopsy

This skills-only package contains Markdown instructions and public reference text, JSON platform metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes, and installing it runs no program or account connection. The skills analyze only task text, attachments and local files you explicitly supply, and return diagnoses, patch text and verification plans without running code, installing software, searching the web, fetching URLs or robots.txt, calling APIs, connecting accounts, sending messages, publishing content or changing settings. Source and support URLs are references, and supplied URLs are treated as text; paste the relevant content instead. Plans may recommend later host/service checks, including read-only discovery or lookup, documented no-send checks, or a minimal real write requiring authorization for its exact target and side effect; those separate checks can execute tools, contact the relevant service or change its state, with destinations and data determined by the supplied host/service contract, and are not performed by these skills. The publisher receives no task data and operates no collection, telemetry or storage service; your assistant provider processes and may retain your conversation and attachments under its own terms, and any output file you explicitly request uses that assistant's existing file tools rather than a bundled program. Supplied traces, logs, arguments, schemas and settings may contain personal data, credentials or private endpoints: redact these before sharing and keep stable replacement labels; the skills do not request secret values and redact sensitive report details. Existing trace exports may already have been collected by their originating system; this package does not enable tracing or upload runs. Manage conversation deletion through your assistant provider's controls, and avoid sensitive material in public support issues.
