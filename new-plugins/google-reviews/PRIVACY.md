# Privacy: Google Reviews

The skills analyze only text, attachments and local files you explicitly supply, including reviews, approved branch facts and profile snapshots; minimize customer identifiers, private addresses and credentials before sharing. They do not direct web search, URL or robots.txt retrieval, API calls, installation, account access, sending, publishing, review reporting, profile edits or file writes; source/support links are references and supplied public links may appear in drafts without being fetched. Three profile skills permit a local character counter on the final description using an existing assistant tool, which may execute local code and create provider-managed temporary files; no counter or network access is supplied or requested, and the fallback is a short draft without an unchecked exact count. The publisher operates no collection, telemetry or storage service and receives no task data through these skills; your assistant provider controls processing and retention of conversations, attachments and tool activity. The current source folder includes inactive Python development harnesses and evaluation records under `tests/`: manually running them launches configured Codex model evaluations, sends evaluation prompts to the assistant provider and writes local prompts, answers, logs and result files; rerun scripts execute `/tmp/gbp-suite.py`, whose contents are not included here. They are not invoked by installation, skills or manifests and must be excluded from a clean submission package. Public drafts exclude private customer records and private home addresses; saved conversations and files remain subject to your host's deletion and retention controls.
