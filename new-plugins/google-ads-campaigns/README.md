# Google Ads Campaigns

Plan Google Ads Search keywords and draft ads from your brief. Review Google Ads search terms, negative keywords, conversions, bidding and Performance Max using reports and settings you supply.

For advertisers and people who manage ad accounts. The advice uses your offer and reports.

Paste text, upload exports or supply screenshots of settings. Reviewing exports needs no keys, installation, paid API or connection to your account. Live setup needs your Google Ads access and the requirements for the route you choose.

This package contains instructions. It includes no connector or code that runs account changes.

| Skill | Give it | You get |
|---|---|---|
| ads-search-campaign-draft | offer, supplied pages, market and keyword themes | proposed ad groups, ads based on your facts and format checks |
| ads-search-terms-review | Offer, search-term rows, current negatives | Table of searches to keep, exclude or review; negative match type, where to apply it and useful searches it could block |
| ads-keyword-plan | Offer, pages, markets, keywords or Planner export | Search campaigns, ad groups and keywords; missing metrics stay unknown |
| ads-conversion-bidding-review | Conversion actions, the goals each campaign actually uses, performance | Measurement fixes, bidding advice based on your data and checks to confirm it |
| ads-performance-max-review | Performance Max (PMax) goals, settings, assets, page and search-query reports | Which brand, query or page controls to use, where they apply and how to assess them |
| ads-access-setup | Desired operation and existing access | A route through exports, the interface, Editor, Scripts, API or MCP; setup steps and checks that it works |

## Try it

- “Turn this keyword plan and landing-page text into Search ad groups and ads; invent no claims.”

- “Review this search terms CSV. We sell only replacement filters; keep queries for filters and flag whole-machine intent.”
- “Group these keywords for our adult classes. Volume data is unavailable; give a plan without volume estimates.”
- “Our campaign custom goal includes a secondary page-view action. What are we actually bidding on?”
- “PMax is using an unwanted landing page. Here are its settings and destination report.”
- “Set up monthly reporting. Do I need a developer token, or can we use exports?”

## Start without setup

Paste the relevant rows or supply a CSV export with date range, filters, currency and conversion definition. Keep campaign and ad-group labels so the review can show where each change belongs. Remove personal identifiers, account IDs and secrets. Search terms can be downloaded from Campaigns → Insights and reports → Search terms after choosing columns and dates. Some queries may be missing, and conversions may arrive later. Both can limit the conclusions. A screenshot shows only the visible settings. The output is a proposal. It does not change your account or promise better performance.

Keyword ideas from a brief have no measured volume or cost data. To get new Keyword Planner metrics, you need your own account with setup completed, including billing information. There is no universal spend threshold stated here for exact volumes. An existing export works without Planner access.

## Optional setup

Ask the access skill to walk through your chosen route. Editor needs the official desktop app and a download of your account. Scripts needs code and authorization for each script. Preview can still send mail or write to spreadsheets. Changes can remain applied after a timeout.

API access needs a Cloud project, a suitable access level, secure OAuth sign-in, account permissions and a supported client. Current Google migration documentation assigns access to Cloud projects. Check older tutorials about manager-account developer tokens against current policy. Explorer access allows reporting but does not unlock keyword planning. MCP needs a separately installed server and the same API access.

The agent can prepare files and run checks you have authorized, using the tools available. You handle login, billing details and secure credential storage. A live connection is ready only after a successful read-only call to the intended account. A setup plan does not prove it works. Importing, previewing or checking a file does not mean its changes are live. Review the exact account, campaigns or other items to be changed before authorizing changes that affect spending.

## Data and network

Review skills fetch nothing. They read the material you supply in the assistant. Setup fetches official documentation URLs listed in the access skill’s references or supplied by you, plus their robots.txt. It follows only official documentation links needed for your setup. It respects robots.txt restrictions and sends no account data with those requests. Pasted documentation is the fallback. Live setup needs separate authorization. It exchanges authentication data, account settings and requested report data with the chosen Google interface, API or OAuth service. Editor, Scripts or MCP also process data when used for that route. The official MCP documents a usage-data header. These instructions add no telemetry and send no data to extra services. Your assistant and any separately connected tool store and process data under their own terms. See [PRIVACY.md](PRIVACY.md).

## Limits and troubleshooting

No invented cost per click (CPC), search volume, savings or claims that a change caused better results. A report cannot prove that a tracking tag ran or that an account edit succeeded. If it is unclear which account or items a change affects, verify them before applying it. If a control is disabled or an API call fails, check the current settings and the actual error with sensitive details removed. Use an export instead of repeating an action whose result is unclear. No credentials should be pasted into chat.
