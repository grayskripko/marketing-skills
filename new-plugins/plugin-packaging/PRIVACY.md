# Privacy: Plugin Packaging

This skills-only package contains Markdown instructions and references, JSON compatibility metadata, a license and a static SVG icon; it bundles no executable program, installer, hook, MCP or LSP server, connector or background process. Supplied-artifact review analyzes the text and files you provide and returns text or patches without commands, URL retrieval or web search. Requested local repair uses existing assistant tools to read and write the authorized package tree and run `claude plugin validate ./<package-directory>`; for supplied text, the command may be proposed for you to run. Requested checks through an available named host can inspect inventory/errors, load a local package with Claude Code's `--plugin-dir`, invoke a harmless skill and read a bundled resource after inspecting the complete package and excluding hooks or MCP companions. Those host checks may send prompts and file contents read for the check to the host's existing model provider and write host session logs, so this optional mode is not offline or execution-free. Other hosts need an available documented tool or supplied transcripts; unavailable hosts yield partial receipts. The skills do not install dependencies, fetch documentation/support URLs, call MCP companions, connect new accounts, send messages, publish or change account settings; remote MCP URLs and API/cache methods are diagnostic knowledge rather than execution instructions. The publisher operates no collection, telemetry or storage service and receives no task data through this package. Assistant and target-host providers control conversation, attachment and session retention under their own terms and settings; local repairs and logs remain in the existing tools' environments. Source/support links are references you may open yourself, and posting a public issue is a separate user action. Remove unnecessary personal data and credentials from supplied files, transcripts and public support requests; credentials are never required.
