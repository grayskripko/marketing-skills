# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes, or account connector. Installation does not run a program or connect an account. The skills analyze only task text, attachments, and local files you explicitly supply, including journal CSVs, mappings, reference exports, and import errors; they do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, message delivery, publication, or account changes. Oracle and support URLs are references, not retrieval instructions or connection endpoints; paste relevant content from a supplied URL. Proposed CSV corrections and retry plans are advice, and you perform any NetSuite exports, imports, or configuration changes yourself. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program. The publisher receives no task data and operates no collection, telemetry, or storage service; your assistant provider processes and may retain conversations, attachments, and tool-created files under its own terms. Redact unnecessary names, memos, personal data, and credentials before supplying material; credentials are never required. Dated Oracle-source refresh instructions are publisher maintenance work, not runtime network activity.
