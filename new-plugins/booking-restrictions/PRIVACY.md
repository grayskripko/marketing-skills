# Privacy

The skills read the text and files you provide in the assistant conversation. Guest names, contact details, payment data and credentials are unnecessary; remove them before supplying exports. Outputs use room/rate identifiers and dates only where needed for the requested trace.

The plugin adds no storage, telemetry, accounts or background jobs. Conversation and file handling follows the assistant host’s settings. Files are read only when supplied or selected for this task; outputs are saved only when requested.

Network: none during normal analysis. A user-requested source refresh may fetch public developers.booking.com pages and their official Booking.com documentation links, without itinerary, export or property data. The skills do not call Booking.com account endpoints or use connectors or paid APIs.
