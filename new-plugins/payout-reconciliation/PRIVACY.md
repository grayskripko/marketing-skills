# Privacy: Payout Reconciliation

The skills analyze authorized processor, payout, bank and ledger records you explicitly supply and bundled reference notes; they do not direct web searches, URL retrieval, API calls, credential handling, account connections, messages, payments or ledger edits. Source and support URLs are references, not connection endpoints. Optional report-download guidance asks you to use your own authorized Stripe account in your browser, which communicates with Stripe; pasted rows require no such download. Your assistant's existing file-reading, OCR and calculation tools may execute host-managed code and create temporary or explicitly requested output files; the assistant provider processes and may retain conversations, attachments, tool data and generated workpapers under its own terms. The working folder also contains `tests/run-eval.py`: if manually invoked, this development harness sends test prompts and skill text through the configured Codex model service and writes evaluation files at its historical `settlement-reconcile` path; it is not invoked by the skills and should be excluded from a submission artifact. The publisher operates no collection, telemetry, server or separate task-data storage service. Supply only authorized records, redact unnecessary customer details and full bank identifiers, retain references needed for matching, and never supply passwords or API keys; use your assistant provider's retention and deletion controls.
