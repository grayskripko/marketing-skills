# Privacy

The skills read pasted text and user-designated exports in the current conversation. They request no credentials or accounts. No telemetry, external log uploads, background collection or plugin-managed storage is provided. Conversation and file handling follow the host application.

Network: none for the default analysis. On a user request to verify a version-specific rule, the agent may fetch official pages at docs.vllm.ai or vllm-project/vllm source pages at github.com and raw.githubusercontent.com. Logs, inventory, private model paths and personal values must not appear in network queries.

The package contains instructions, references and an SVG icon. It has no connector, executable service or server access.
