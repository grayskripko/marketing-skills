## Package operating choices

These are this package's rules of thumb, not platform guarantees: compare entity, scope and effective time before calling claims contradictory; preserve unknown fields; prefer attributable original sources over recaps; use the existing approved audit mechanism for provenance, or a companion note by default when the schema lacks fields and a note is useful and permitted; separate storage, retrieval and answer evidence. Requested forgetting avoids a new rollback copy of sensitive content. Unresolved authority remains attributed.

Use these checks to explain the requested result, not as a mandatory output checklist. For a small repair, update the active conflicting passages within the existing load window before proposing configuration changes. A successful explicit read and answer can pass that narrow check while fresh startup loading remains unverified. For an audit-only request, give a concrete action for each uncertain note without requiring the user to resolve it before receiving the audit.
