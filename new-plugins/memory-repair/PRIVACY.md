# Privacy

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers, or background processes. Pasted-artifact analysis needs no account or installation, but the complete workflow permits optional retrieval of linked official documentation and user-supplied public URLs, following redirects: the visited sites, redirect destinations, and assistant web-tool provider receive the URL and ordinary connection metadata, while private memory, transcripts, and credentials must not be sent to documentation sites. Authorized live work reads relevant local files or uses an existing connector's configured store endpoint for schema inspection, selected entry reads, requested writes/deletions and readback, normal retrieval queries, and bounded status polling; the connector and store receive the selected queries, entries, and changes. Requested local repairs change named files and may create patches, companion notes, and ordinary rollback material through host file tools; requested forgetting avoids another copy of deleted sensitive content. Startup checks require a new host session/run in the same environment. The skills do not prescribe shell scripts, software installation, account creation, message delivery, or publication; authentication stays in the host's credential interface. The publisher receives no task data through this package and operates no telemetry, collection service, or separate conversation database. Output remains in the user's chosen location, while the assistant provider and any connected service control their own processing and retention.
