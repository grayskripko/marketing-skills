## Diagnostic conventions

This plugin's rule of thumb: separate destination selection from slot availability; distinguish a code category from a confirmed setting; return evidence, setting and same-slot recheck. Unknown labels and overlapping route matches remain unresolved until the missing evidence is supplied. These are output conventions, not Calendly precedence claims.
