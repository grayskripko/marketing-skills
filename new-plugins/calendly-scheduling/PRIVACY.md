# Privacy — Calendly Scheduling

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, and development records; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, connectors, or background processes. Installation does not run a program or connect an account. The assistant analyzes only task text, attachments, and local files you explicitly supply; the skills do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, message delivery, publishing, or account changes. Source and support URLs are references, and routing External URLs are supplied destination values, not assistant retrieval instructions. The skills do recommend actions you perform yourself in Calendly: Troubleshoot and setting/booking reviews, routing Preview tests, Responses/Meetings inspection, CSV exports (which Calendly may email), buffer and Free/busy exception edits and saving, host/distribution changes, and slot rechecks; a requested published-form test can record a response, and completing scheduling can book a meeting. Those user actions communicate with Calendly and any calendars already connected to your account, under their own terms; the plugin does not execute them. The publisher receives no task data and operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations and attachments under its own terms; any output file you explicitly request is created by its existing file tools, not a bundled program. Supply only relevant dates, settings, codes and form answers, use neutral labels, and remove invitee names, email addresses, credentials and unrelated calendar details. Development records are not runtime instructions and should stay outside the submitted release folder.
