# Privacy: Intercom SLAs

This package contains skills and local references. It runs no service.

It reads supplied conversation or ticket aliases, workflow text, SLA settings, report rows, timestamps and assignee labels to reconstruct target history and interpret reports. Supplied files may contain customer messages and contact details; contact details are unnecessary for this task and are omitted from answers.

Network fetches: none during skill use. No telemetry, account access, credentials, external recipients or plugin-managed storage. Linked official articles are citation destinations; skill execution uses the embedded reference text. Local arithmetic may run through the host's code tools. The assistant provider processes and retains the conversation and supplied files according to the host's settings. Redact unnecessary personal details before sharing and use the host's controls to delete conversations or files.
