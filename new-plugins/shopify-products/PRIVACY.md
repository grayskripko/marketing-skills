# Privacy: Shopify Products

This skills-only package contains Markdown instructions and references, JSON platform metadata, a static icon and text-only development records; it bundles no executable program, dependency, installer, hook, MCP/LSP server or connector. The skills analyze only product facts, supplier notes and task files you explicitly supply and direct the assistant's existing local code tool, when available, to parse CSV, count fields and write requested local output files without overwriting source exports; execution and temporary files are managed by your assistant provider. They prohibit fetching supplier pages or image URLs, using accounts or APIs, and changing your store, and do not direct web search, software installation, message delivery or automatic publication. Source and support links are references rather than retrieval instructions; supplied image URLs may remain as text in CSV output. The CSV skill gives user-led backup, import-preview, overwrite and one-product test steps: if you perform them, you access Shopify and may change store records, and Shopify may retrieve images from the supplied URL hosts. The plugin itself sends no task data to the publisher, operates no server, telemetry or separate storage service, and needs no credentials. Your assistant provider processes and may retain conversations, attachments and tool activity under its own terms; you control requested output files. Redact supplier contacts, customer details and secrets before supplying material.
