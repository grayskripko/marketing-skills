### Job Posting Quality Standards
URL: https://www.indeed.com/help/employers/articles/115005915763?co=US&hl=en

Description fields: company, pay, work hours, benefits, duties. Role-only title; move location/pay/shifts to the body. No clickbait, emoji, keyword stuffing or competitor lists. Outcomes can include hiding, removal or sponsorship requirement. No numeric title length established here.

### Job Posting Location Policy
URL: https://www.indeed.com/help/employers/articles/appropriate-use-of-location-on-indeed?co=US&hl=en
Read 2026-10-11; loaded; no revision date shown. States all employers are in scope.
Onsite/hybrid: reporting street address or postcode; public street address can be hidden. Remote: preserve state/country residency restrictions. Broad state/nation coverage requires genuinely remote or traveling work throughout that area. Travel: starting address or service area, travel percentage, expense coverage and remote time. Multiple genuine worksites may each have a post.

### Job Posting Integrity and Duplicates
URL: https://www.indeed.com/help/employers/articles/job-posting-integrity-and-duplicates
Read 2026-10-11; loaded via official legacy redirect; no revision date shown. States all employers are in scope.
One post per actual opportunity, or per real location. For an unchanged opportunity, update the existing post; the integrity policy permits reposting after the real role closes and later reopens. For actual significant job changes, apply the separate GB editing guidance below rather than treating relocation as an exposure-only duplicate. Duplicates can be blocked before moderation, hidden or require sponsorship. A reopened post can show “Flagged”; contact support. No fixed repost interval or unique diagnostic error code provided.

### Misleading Content and Activities
URL: https://www.indeed.com/help/employers/articles/misleading-content-and-activities

Sponsorship may be required for some commission-only/remote or misleading-pay posts, but paying does not correct misrepresentation.

## How to use this evidence

Use the detailed official policy for the deciding fact. Do not use the absence of a numeric cap here as proof that no cap exists in the posting interface. No budget minimum, review SLA, ranking guarantee or local statutory pay threshold was verified. The dated register supports offline checks; an unsupported changed rule stays unresolved. These are workflow decisions, not additional Indeed requirements: deliver corrections first, preserve approved facts, use exact locale/method evidence, and request the smallest missing detail.

### Posting a Remote Job — GB locale
URL: https://www.indeed.com/help/employers/articles/how-to-post-a-remote-job-on-indeed?co=GB&hl=en
Read 2026-10-11; loaded; no revision date shown.
Fully remote has no regular office attendance. Hybrid needs the exact in-person location. Mostly onsite with occasional work-from-home flexibility is neither remote nor hybrid: describe that perk instead. Without remote residency requirements, the platform defaults location to the whole country. XML uses <remotetype> values “Fully remote” or “Hybrid remote/in-office”; remote residency restrictions go in <state>. GB guidance recommends a new post for significant changes such as location; distinguish an actual changed role/location from duplicating an unchanged role for exposure.

### UK postcode structure — ONS
URL: https://www.ons.gov.uk/methodology/geography/ukgeographies/postalgeography
Read 2026-10-11; loaded; last updated 3 January 2023.
A complete UK postcode contains both an outward code (2–4 characters) and inward code (three characters). BS1, OX1 and CF10 alone are districts, not full reporting postcodes. This geography source explains the field value, not an additional Indeed rule. It is bundled evidence; runtime policy retrieval stays on Indeed's official sources.

### Editing Your Job Posts — GB locale
URL: https://www.indeed.com/help/employers/articles/203366260?co=GB&hl=en
Read 2026-10-11; loaded; no revision date shown. Followed the editing link from the GB remote-job page.
Minor corrections and typographical errors belong on the existing post. The page recommends a new post for significant detail changes, including location/title or requirements/responsibilities. Apply that to genuine changes in the job, not cosmetic corrections or duplicates created to gain exposure. Editing does not change the original posting date. Indexed ATS jobs have a reference number; edits made on Indeed appear only there and do not change the original posting. Jobseekers cannot apply to jobs more than once, a consideration when choosing edit versus new post.
