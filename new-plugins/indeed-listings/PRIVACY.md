# Privacy

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG icon; it provides no executable program, installer, hook, server, background process or account connector. It analyzes posting text, approved role details, messages and exports you supply, which may include company names, addresses, status and spending amounts. Both skills direct the assistant's existing browsing tools to refresh deciding public Indeed policy/help pages when available, including locale variants and linked policy pages on Indeed domains (`www.indeed.com`, `ca.indeed.com`, `uk.indeed.com`) and legacy redirects through `indeedinc.my.site.com` to `indeed.com`; public web searches use only policy terms and locale. Requested URLs, search terms and ordinary connection metadata reach those sites, the search service and the assistant tool provider; private posting text, applicant data and account identifiers must not be included in queries. The ONS link is bundled geography evidence, and GitHub links are source/support references. This is not a strictly offline workflow; without browsing it uses dated bundled references and supplied current excerpts, leaving unsupported changed rules unresolved. Skills do not direct code execution, software installation, API calls, file writes, employer login, publishing, budget/billing changes or sending messages: corrections and support drafts remain text, and any recommended Indeed/ATS edits, verification, support contact, reopening or budget review are user-performed external actions. The publisher receives no task data and operates no service, telemetry or storage; your assistant provider processes and may retain the conversation and supplied files under its own terms and account settings. Omit applicant records, credentials, payment-card details and identity documents before sharing.
