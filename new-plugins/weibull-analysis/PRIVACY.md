# Privacy

Weibull Analysis is a skills-only package: Markdown instructions, one reference file, JSON platform metadata, an MIT license and a static SVG icon. It contains no scripts, dependencies, installers, hooks, MCP or LSP servers, connectors or background processes, and installing it runs nothing and connects no account.

It works only on the failure data, repair records and software output you paste or export into the conversation. It makes no network requests: no web search, no URL fetching, no API calls, no uploads and no telemetry. Links in the files are references, not endpoints. If your assistant has a local code tool, the skills may use it to compute fits and test statistics on the data you supplied; nothing is installed or downloaded for this.

The publisher receives no data and runs no collection or storage service. Conversation and attachment retention follow your assistant provider's settings. Do not paste credentials or personal data; asset tags and site names can be replaced with labels.
