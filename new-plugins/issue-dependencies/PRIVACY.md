# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, and non-executable development evidence; it provides no program, installer, hooks, connector, server, telemetry, or plugin-managed storage. Issue audits analyze only text, attachments, or local files you explicitly supply, including issue IDs, titles, relationships, states, and export metadata; both skills prohibit network requests, connectors, and account changes, and do not direct code execution, installation, file writes, message delivery, publication, or API execution. Proposed relationship changes and API payloads remain text. The one retrieval exception is release maintenance: both bundled GitHub reference files instruct reopening their six public `docs.github.com` documentation URLs before submission if the snapshot changes; this is not live repository access or an audit step. Other source and support links are references, not audit endpoints. The publisher receives no task data and operates no collection service; your assistant provider processes and may retain conversations and attachments under its own terms, and any output file you explicitly request uses the host's existing file tools and remains under your control. Redact unnecessary personal details and credentials before supplying issue material.
