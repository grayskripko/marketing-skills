# Privacy

The skills read only text and files you supply for the export review. These may contain ticket text, user information and organization information. Reports should use record IDs and field names rather than repeat personal details. Remove credentials before supplying files.

Network: none during export analysis. On an explicit documentation-refresh request, only bundled official article URLs on support.zendesk.com and developer.zendesk.com and redirects within those domains are fetched. No ticket content, attachment URLs, account endpoints, credentials or export download links are sent to those sites. No telemetry, background jobs, connector or package download is included.

This package has no storage service. Files are written only to the output location requested by the user. Conversation and file retention follow the host application's settings.
