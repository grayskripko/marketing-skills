# Zendesk Exports

Check whether my Zendesk export is complete and explain missing comments, fields, tickets or mismatched dates.
For support operations teams checking a Zendesk data handoff. Supply pasted text or readable CSV, JSON/NDJSON or XML exports, the archive file list, export type, selected entities, date range, request time and account timezone at export. No account, keys, installation of helper software or paid API is needed.

- **export-coverage:** Reconcile supplied records and settings into a coverage manifest, timezone explanation, omissions and exact evidence requests.
- **export-format:** Diagnose full JSON parsing errors and prepare a loss-preserving conversion from supplied NDJSON.

A sample produces a sample-scoped result. Full coverage needs all archive parts and export settings. API exports can be reviewed when their response pages and pagination metadata are supplied.

Network: none during export analysis. If you request a documentation refresh, fetch only the official article URLs listed in the bundled references on support.zendesk.com and developer.zendesk.com, including redirects within those domains. Export content, attachment links and account URLs are never fetched. No telemetry.

The dated source register is [Zendesk export rules](references/zendesk-export-rules.md). Both host manifests point to the skills. The build record is [BUILD-NOTES.md](BUILD-NOTES.md).
