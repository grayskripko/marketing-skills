# Privacy: API Errors

This package contains skills and reference text. It runs no service and includes no executable code.

The assistant reads the responses, headers, bodies, documentation and selected exports you provide to draft error catalogs and replacement passages. These inputs can contain endpoint names, identifiers and personal data. Credentials and cookies are not needed; remove them before sharing. Sensitive values are replaced with neutral markers in examples.

Network: none for pasted text and exports. If you ask to refresh sources, the assistant fetches only the public official URLs in the bundled references or public documentation URLs you supply, plus each site's robots.txt. Redirects are limited to the same official documentation publisher. No supplied response body, private log, cookie or credential is included in requests. Disallowed pages are not fetched. No telemetry, crawling, login or paid API is used.

The plugin stores no data and sends no messages. Your assistant provider processes and retains the conversation under its own settings. Delete the conversation or redact inputs using the assistant's controls. Generated files are saved only where you request.
