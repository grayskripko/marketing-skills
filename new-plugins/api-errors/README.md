# API Errors

Make our API error reference consistent with these response examples.
For API writers and developers maintaining HTTP consumer documentation.
Needs pasted HTTP status, headers, response bodies and current documentation, or selected text/JSON/YAML exports. No account, API key, connector or installation beyond the plugin is required.

- **error-catalog** — turn supplied exchanges into a per-error catalog, with stable identity, field rules, headers and recovery guidance.
- **error-doc-replacements** — replace incorrect error-response passages with exact text grounded in supplied examples and HTTP standards.

Paste a response and the matching paragraph. Include the method, endpoint, API version and documentation date when available. Remove credentials, cookies and personal data first. A text-only path handles the complete job.

The package contains instructions and dated reference notes. It drafts documentation in the conversation. It does not call your API, implement servers or publish changes.

Network: none for pasted text and exports. If you ask to refresh sources, the assistant fetches only the public official URLs listed in the bundled references or public documentation URLs you supply, plus each site's robots.txt; permitted redirects are limited to the same official documentation publisher. No response body or private log is sent to those sites. No telemetry, crawling, login or paid API is used.

Embedded sources cover RFC 9457, HTTP semantics, additional status codes, OAuth Bearer errors and IANA status names. Verified 2026-10-11; source URLs, publication dates and deciding sections are in each skill's references.
