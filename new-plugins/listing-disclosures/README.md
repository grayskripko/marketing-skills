# Listing Disclosures

Check a US sale/rental lead-disclosure packet against property age, exemptions, available records, timing, electronic consent and signed-record retention.

For US property agents, sellers, landlords and property managers reviewing a packet before execution or checking its archive. Paste forms, property facts, report indexes, consent terms and dates, or provide user-selected document exports. No account, API key or installation beyond loading the plugin is needed.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account.

These skills work only from task text, attachments, and local files that you explicitly supply. They do not instruct the assistant to run code, install software, search the web, fetch URLs or robots.txt, call APIs, send messages, publish content, or change account settings. URLs in this package identify sources or support pages; they are not connection endpoints or retrieval instructions. A supplied URL is treated as text: paste the relevant content instead.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider still processes and may retain your conversation and attachments under its own terms. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

The bundled source registers also contain publisher pre-submission maintenance instructions: refresh the linked EPA rule/guidance pages, eCFR regulations, and GovInfo 15 USC 7001 resolver before submission. That maintenance retrieves public pages from www.epa.gov, www.ecfr.gov, and www.govinfo.gov and exposes the requested URLs and ordinary connection metadata to those sites and the retrieval provider; it does not require sending user packet material. It is separate from the pasted-material runtime workflow. Disclosure corrections, delivery, signatures, exports, and retention recommendations are text advice for the user, not actions performed on records. The .claude-plugin and .codex-plugin directories contain platform metadata, not executable servers.

| Skill | Request | Result |
| --- | --- | --- |
| check-lead-packet | “Is this lead packet complete before we sign?” | Applicability, missing records/fields and timing corrections |
| check-lead-delivery | “Is this portal consent enough, and when can we delete the disclosures?” | Consent and delivery gaps, signed-copy checks and minimum retention dates |

The rules distinguish sales from rentals, renewable short leases, new information at renewal, children under six in studios, building-wide records and buyer inspection rights. Dates and URLs are in each skill's references. Source registers record verification on 2026-10-11.

Use labels instead of names, addresses and signature images. Include construction permit date (or start date if no permit), completion year, transaction type, relevant exemption facts, known/available records and contractual obligation chronology. Missing evidence gets a specific question after the useful findings. Exports show the records supplied for review.

Network: none at runtime. Skills read pasted text and user-selected exports plus packaged references. They connect to no account or portal, send no documents, sign no records and create no archive service. No telemetry or plugin-operated storage. Official sources were fetched during the build, not by these skills.
