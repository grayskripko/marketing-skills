# Privacy: OpenAPI Review

These skills read supplied OpenAPI YAML/JSON, readable exports and validator output to produce location-cited findings and replacement fragments.

Inputs can include endpoint names, schemas, example payloads, internal URLs and personal data in examples. Supply only material needed for the review and redact secrets and unrelated personal data. Credentials are never required.

Network fetches: none during skill use. No contract, log or conversation text is sent to external validators or other services. Remote references, API servers and example URLs are not fetched. Files are read only when supplied for this task. The plugin ships instructions, references and an icon, with no executable helpers or connectors.

The plugin keeps no storage or telemetry. The assistant provider processes the conversation and supplied files under its own retention settings. You can remove files or delete the conversation using the assistant's controls.
