# Privacy: Search Reporting

This package contains Markdown instructions and reference text, JSON metadata and a static SVG icon, with no executable program, dependencies, installers, hooks, MCP/LSP servers or background processes; installation runs no program and connects no account. The assistant analyzes only supplied task text, attachments and local files plus bundled references, which may include property URLs, page paths, queries and aggregate metrics. Both skills prohibit fetching; they do not direct assistant web search, URL/robots.txt retrieval, API calls, installation, message delivery, publishing or account-setting changes. The assistant may use its existing local calculation tools on supplied data and create explicitly requested audit/report files using its existing file tools; execution and temporary files are managed by the assistant provider, no network access is requested for calculations, and raw exports must not be overwritten. The skills can recommend that you personally use Google's online Search Console to open a report, inspect the selected property and Search generative AI settings without changing them, or obtain rare-value filtered captures and matching exports; those actions contact Google through your own account, not an assistant connector. Google source links and GitHub support links are for you to open, not assistant retrieval endpoints; supply updated official text when needed. The publisher receives no task data and operates no collection, telemetry or storage service. Conversation, attachment and tool-output retention follows your assistant provider's terms; requested output files remain under your control. Supply only relevant columns and redact unnecessary identifying query text or credentials.
