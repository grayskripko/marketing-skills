Analyze product return reasons and reviews to find listing fixes, product investigations and supplier briefs for each product code (SKU).
For sellers and product teams. Give it authorized review/return text or exports, current listings and approved product facts. To calculate return rates, supply matching sales records. No accounts or paid APIs are required.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The .claude-plugin and .codex-plugin directories contain platform metadata, not executable runtimes.

These skills work only from task text, attachments, and local files that you explicitly supply. They do not instruct the assistant to install software, search the web, fetch URLs or robots.txt, call APIs, send messages, publish content, or change account settings. URLs in this package identify sources or support pages; they are not connection endpoints or retrieval instructions. A supplied URL is treated as text: paste the relevant content instead.

Pasted-text tasks need no additional software. Supplied CSV/XLSX files require the assistant's existing file reader; scans require its text recognition (OCR). The skills require arithmetic from supplied values and acknowledge arithmetic with a tool, without specifying a code runtime or an execution method. This is not a strict no-tool-execution promise: file reading, OCR, calculations and any output file you explicitly request use the assistant's existing tools, not a bundled program. Originals remain unchanged; supplier checks, listing changes and emails are drafts or proposals, not performed actions.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider still processes and may retain your conversation, attachments and tool activity under its own terms.

- “Draft a supplier investigation brief from these complaints and inspection notes.”

## Prepare the inputs

Paste text for the simplest path. For files, use readable CSV/XLSX or text. The assistant needs a file reader. Scans need text recognition (OCR). If a file cannot be read, paste the relevant rows. Keep neutral row IDs that stay the same, dates, SKU and variant. Say what each row represents. Remove customer names, contact details and identifying order information. State which product facts and listing versions are approved. Pasted text needs no additional software or credentials.

For return rates, define whether you count units or orders. Supply sales records for the same group of purchases and state the time allowed for returns. Without them, you get counts from the supplied sample. Refunds and cancellations are kept separate from physical returns. If reviews and returns cannot be linked, they may describe the same purchases.

## Review the result

Complaints guide investigation. They do not prove what caused a problem or predict fewer returns. Conflicting facts stay unresolved. Supplier checks are proposals unless already approved. Review drafts before using them. The package does not publish, send, change a store, decide refunds, suppress reviews or certify product safety. It does not fabricate testimonials or suggest favorable-review incentives. For a review action covered by law or platform policy, supply the jurisdiction that applies and the current rule.
