# Privacy

This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon and development records; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes, connector or storage service. Installation does not run a program or connect an account. Analysis uses only text and files you explicitly supply, inspecting tracking URLs and sanitized payloads as text without opening tracking URLs; the skills do not direct code execution, installation, API calls, credential handling, account access, outreach, publishing, record changes or settings changes. A user-requested documentation refresh may retrieve only named public Greenhouse documentation pages on `support.greenhouse.io`, `developers.greenhouse.io` or `docs.greenhouse.io` and their redirects through the assistant's existing retrieval tools; reference maintenance instructions also call for reopening cited sources before submission and when definitions change. Those network requests disclose the requested URL and ordinary connection metadata to destination sites, redirect destinations and the tool provider, never candidate rows, export contents, candidate details or tracking tokens. The publisher receives no task data and operates no collection, telemetry or retention service. Your assistant provider controls conversation and attachment processing and retention; requested output files are created by its existing file tools and remain under your control. Supply stable application or row IDs instead of names, contact details, resumes or sensitive demographic fields, and omit unnecessary personal data and secrets.
