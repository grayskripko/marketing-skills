# Privacy — Plumbing Permits

This skills-only package contains Markdown instructions and references, JSON metadata, development records and a static SVG icon; it bundles no executable program, installer, hook, server or connector, and installation runs no program or account connection. The assistant analyzes pasted task material and user-selected local files, which may contain project details, filing identifiers, addresses and stakeholder names; redact unnecessary personal information and credentials. Rule verification can use the assistant's existing web tools to retrieve public NYC DOB pages and PDFs in the source registers, official NYC updates and `https://www.nyc.gov/robots.txt`, and search public rule titles without project details. Registers direct reopening deciding sources before filing submission and when an objection contradicts the filing snapshot; later filing dates require effective-rule verification. Retrieval exposes URLs and ordinary connection metadata to NYC and the tool provider; searches expose public rule-title queries to the search provider. Supplied project text, identifiers, credentials and private export links must not be sent to those destinations. The skills do not direct code execution, software installation, DOB login, property lookup, account API calls, message delivery, application submission or record changes; filing, withdrawal and reporting advice describes user-performed actions. If retrieval is unavailable, supply the applicable official passage and date; unresolved rules are not verified. GitHub documentation/support links are references, not automatic requests or sends. The publisher receives no task data and operates no telemetry or storage service; conversation, attachment and tool-activity processing and retention follow the assistant provider's terms, and output files are created by its existing file tools only when requested.
