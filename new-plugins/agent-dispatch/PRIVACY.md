# Privacy: Agent Dispatch

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG icon; it ships no executable scripts, dependencies, installers, hooks, MCP/LSP servers or background processes, and installation runs no bundled program or account connection. Supplied-record planning, recovery and reconciliation use your provided material, but requested execution may use your assistant's existing native tools to launch, communicate with, collect results from, resume or authorize interruption of workers; requested workspace access permits local file/Git inspection, local acceptance tests and explicitly requested integration edits or output files at authorized destinations. Delegated inputs and permitted inherited history go to your host's existing model service and selected model providers under their terms and may consume your allowance; a redacted brief does not redact inherited history. The skills prohibit web search, URL/robots.txt retrieval, external connector/API calls, software installation, permission changes, shell-based substitute agents, publication and messages to people; source/support URLs are references, and the README's optional host setup is performed separately by the user. This is therefore not a strictly offline, no-execution workflow. The publisher receives no task data and operates no telemetry, database or storage service; your assistant provider controls conversation, attachment and worker-transcript retention, and requested local artifacts remain under your control. Supplied traces, configs, source and diffs can contain personal data and secrets: remove unnecessary data and credentials before sharing, check the host's context-sharing boundary before delegation, and use its deletion controls for retained conversations and transcripts.
