# GTM Consent

Diagnose pasted Tag Assistant events and consent settings, with an event-by-event explanation, likely fixes and the precise next trace needed.
For marketing operations teams and developers working on Google Tag Manager web containers.
Needs pasted events, default/update states and relevant container settings. No accounts, keys, installs or paid APIs are required for analysis.

## Skills

- **diagnose-consent-trace**: explain consent state at each event, distinguish missing defaults from late defaults and missing updates, and specify the next capture.
- **review-consent-settings**: review template triggers, consent fields, regional defaults and additional tag checks; return proposed changes with confirming traces.

Paste event order, page boundaries, banner actions, Consent-tab columns and tag fired/blocked reasons. Container JSON exports and copied template settings are also accepted. Remove visitor identifiers, cookie values, URL query values and credentials; retain field names, consent states and relative timings.

Analysis uses only supplied text/files and bundled references. Optional freshness checks fetch the cited documentation on developers.google.com and support.google.com, including redirects within those domains. No website scan, account connection or container publishing is included. No telemetry is collected.

For a new capture, the agent can explain how to open Tag Assistant or GTM Preview, record the first consent event and banner interaction, and copy the resulting events. You can also paste an existing export without setup.
