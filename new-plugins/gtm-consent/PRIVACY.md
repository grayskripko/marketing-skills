# Privacy

The skills analyze text you paste and files you explicitly provide. Container exports may contain identifiers and custom code. Share consent states, event order and settings with visitor identifiers, cookie values, URL query values and credentials removed.

The package contains Markdown instructions, JSON metadata and an SVG icon. It has no executable service, connector, storage backend or telemetry. It does not access a Google account or change a container.

No network access is needed for pasted-text analysis. If current documentation is requested or a rule needs refreshing, the agent fetches the cited documentation on developers.google.com and support.google.com and redirects within those domains. Pasted traces are not sent to those documentation sites. No user website is fetched. Conversation and file handling follow the host application's settings; the plugin adds no separate retention.
