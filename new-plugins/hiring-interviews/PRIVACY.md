# Privacy: Hiring Interviews

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes, or account connector. Its skills use only task text, attachments, and local files you explicitly supply and do not direct code execution, software installation, web search, URL or robots.txt retrieval, API calls, account access, message delivery, publication, settings changes, or ATS writes. Source and support URLs are references, not retrieval instructions or connection endpoints; paste relevant content for a supplied URL. The publisher receives no task data and operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations, attachments, and generated artifacts under its own terms; any output file you explicitly request is created by its existing file tools and remains wherever you or the host saves it. Supply only authorized role briefs, rubrics, panel constraints, and minimized interview notes; use candidate IDs and remove unnecessary personal details and credentials, since redaction does not guarantee anonymity. People apply ratings, approve accommodations, and make hiring decisions.
