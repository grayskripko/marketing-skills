# Privacy: Looker Studio Blends

This skills-only package contains instructions, reference text, JSON metadata and a static icon; it provides no executable runtime, installer, hook, connector, server, telemetry or publisher storage service. The assistant analyzes text, exports, local files and settings you explicitly supply and performs local reconciliation; the skills specify no code runner, shell command, installation, API call, message delivery or output-file write. Both skills permit public-documentation retrieval through the assistant's existing web tool under `https://docs.cloud.google.com/data-studio/` and redirects within Google documentation when platform rules need verification, so this optional workflow makes network requests: Google and the tool provider receive the requested documentation URL and ordinary connection metadata, never supplied rows, keys, private URLs or screenshots. Requested walkthroughs tell you to copy, edit and save reports or blends, validate formulas and reconnect missing sources yourself in Google's UI; the assistant does not log in, use third-party connectors or edit reports automatically. Those user-led actions use your existing Google access and can incur normal source-query costs. No task data is sent to the publisher; conversation and supplied-file processing and retention follow your assistant provider's terms, while Google handles your report actions under its own terms. Redact personal fields, replace join keys consistently and never supply credentials; use your provider's controls to delete conversations and files. Repository and support links identify resources, not instructions to send data.
