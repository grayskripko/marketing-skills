# Looker Studio Blends

My Looker Studio totals change when I blend these exports. Show which join or grouping caused it.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The `.claude-plugin` and `.codex-plugin` directories contain platform metadata, not executable servers. Development notes, reviews and test records in this working folder are not runtime components and should be excluded from the submitted package.

Analysis uses task text, exports, local files and settings that you explicitly supply. Both skills permit the assistant's existing web tool to fetch public documentation under `https://docs.cloud.google.com/data-studio/` and redirects within Google documentation when a platform rule needs verification. These requests disclose the requested documentation URL and ordinary connection metadata to Google and the assistant's tool provider. Supplied rows, keys, private URLs and screenshots must not be included in requests. This optional verification makes network requests; pasted-data analysis can proceed without it.

The skills instruct local calculation and reconciliation but specify no code runner, shell command, software installation, API call, message delivery or output-file write. They return analysis and proposed settings. Requested editor walkthroughs tell you to copy a report or blend, edit fields and joins, save settings, validate formulas and, for a missing source, reconnect it in Google's UI using your existing access. You perform those external actions; the assistant does not log in or edit reports automatically. Report queries can have the source's normal costs and access requirements.

The publisher receives no task data and operates no collection, telemetry or storage service for this plugin. Your assistant provider processes and may retain your conversation and supplied files under its own terms. Google handles user-led report actions under its own terms. Source-documentation links can be fetched within the scope above; repository and support links identify package resources and do not instruct the assistant to send anything.

For report owners and analysts comparing source totals with a Looker Studio blend. Needs pasted rows or exports and the blend/chart settings; screenshots described in text also work. No account connection, install, API key or paid service is needed for analysis.

Get the affected join or grouping, a reconciliation of the supplied totals, and a specific configuration correction. Google now labels these documentation pages Data Studio; the scope is the report blend editor, including reports users know as Looker Studio.

- **Diagnose blend totals:** explain inflation, missing rows, dimension-dependent totals or native Ads/Analytics ratio errors after filter changes.
- **Design and repair blends:** prepare table layouts, join conditions, aggregation grain, filters and date ranges for the intended metric and population. Troubleshoot calculated-field placement, missing components and aggregation errors from supplied settings and exports.

Supply each table's selected dimensions and metrics, aggregation, table order, join keys/operators, chart dimensions/formulas and date/filter settings. Include the expected metric meaning and period. Small complete examples are useful; partial exports support sample findings only. You can redact names and replace keys consistently. Do not paste credentials.

The agent can walk you through the report editor using your existing Google access and edit rights. It prepares settings and expected checks; it does not connect to your account or change reports. Pasted settings and exports remain the no-setup path. Source queries in your report may carry the source's normal costs and access requirements.

Not for Looker LookML/Explores, report styling or third-party connectors. A static export cannot verify live freshness, full-data completeness or the result of a settings change you have not checked.
