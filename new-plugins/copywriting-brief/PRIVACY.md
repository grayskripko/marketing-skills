# Privacy: Copywriting From a Brief

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. Its skills use only task text, attachments, and local files you explicitly supply, together with bundled references; they do not instruct the assistant to run code, install software, search the web, fetch URLs or robots.txt, call APIs, access accounts, send messages, publish content, or change account settings. Source and support URLs are references, not retrieval instructions or connection endpoints; paste the relevant content for a supplied URL. The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider processes and may retain your conversation and attachments under its own terms; any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program. Supply only material needed for the writing task, redact unnecessary personal data, and never provide credentials.
