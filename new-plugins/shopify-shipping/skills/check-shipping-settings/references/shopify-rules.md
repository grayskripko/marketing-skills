# Shopify shipping source register

All links below loaded in the public Shopify Help Center on 2026-10-11. No page displayed a revision date; the read date is verification of the live documentation, not a publication date or a promise about a particular store. Scope is Shopify checkout shipping. Shipping options by market are early access. Recheck system-specific documentation before submission on or around 2026-10-15.

- [Shipping profiles](https://help.shopify.com/en/manual/fulfillment/setup/shipping-profiles), read 2026-10-11. Products/variants not assigned to custom profiles use General. Up to 99 custom profiles are supported.
- [Shipping rates](https://help.shopify.com/en/manual/fulfillment/setup/shipping-rates), read 2026-10-11. Destination countries need an active market; profile zones group destinations with shared rates.
- [Troubleshooting shipping rates](https://help.shopify.com/en/manual/fulfillment/setup/shipping-rates/troubleshooting), read 2026-10-11. Price tiers use discounted value before tax. Weight includes default packaging; storage rounds up to whole grams. Existing weight gaps can select the next higher tier if no other rate applies. Names must match capitalization. Abandoned checkout rates are stale. Address shipping errors can reflect unmatched rate conditions.
- [Setting up market shipping options](https://help.shopify.com/en/manual/fulfillment/setup/shipping-options/setting-up-shipping-options), read 2026-10-11. Markets permission is required. Applies to selects collections; Ships from selects origins. Range fields are Minimum, Maximum and Price: begin at 0, leave the last maximum empty, avoid uncovered amounts/weights. Uncovered ranges cause shipping errors. Weight and carrier/app-calculated options each permit one rate; the weight rate itself can contain multiple weight ranges.
- [Understanding market shipping options](https://help.shopify.com/en/manual/fulfillment/setup/shipping-options/understanding-shipping-options-by-market), read 2026-10-11. Check market inheritance and overlapping markets. Flat/order amount rates combine by highest within an option; calculated rates and distinct options add.
- [Split shipping](https://help.shopify.com/en/manual/checkout-settings/split-shipping), read 2026-10-11. Draft-order shipping-line, B2B-draft and same-line multi-origin limitations affect eligibility. Local delivery hides multiple shipments. Customers cannot choose grouping. App-provided rates add.
- [Upgrading shipping](https://help.shopify.com/en/manual/fulfillment/setup/shipping-options/whats-changing-with-shipping), read 2026-10-11. Upgraded stores manage rates through Markets; split shipping is activated and its old toggle no longer applies.

Analysis practice: compare a fresh unpaid checkout to the same supplied cart and destination. A settings review without observed checkout is not a live result. This is an evidence-handling convention, not a platform guarantee.
