# Shopify shipping source register

All links below loaded in the public Shopify Help Center on 2026-10-11. No page displayed a revision date; the read date is verification of the live documentation, not a publication date or a promise about a particular store. Scope is Shopify checkout shipping. Shipping options by market are early access. Recheck system-specific documentation before submission on or around 2026-10-15.

- [Combined shipping rates](https://help.shopify.com/en/manual/fulfillment/setup/shipping-profiles/combined-shipping-rates), read 2026-10-11. Different profiles add. Within one profile/location group a flat charge applies once; weight, carrier and app rates can combine. Same-name rates share a checkout label; no common names produces the cheapest combined Shipping option. Price-based combinations use order value; weight-based ones use allocated item weights. Its two-product example adds the store default package to each separately rated product component before selecting and adding the rates. Distinguish product-only weights from supplied packaging-inclusive component weights; do not generalize this example into a package per unit for other allocations. Inventory and fulfillment priority decide eligible origins.
- [Split shipping](https://help.shopify.com/en/manual/checkout-settings/split-shipping), read 2026-10-11. Lowest total is the default; customers can choose methods per shipment. Preorders and immediate items add despite sharing an option.
- [Understanding shipping options by market](https://help.shopify.com/en/manual/fulfillment/setup/shipping-options/understanding-shipping-options-by-market), read 2026-10-11. Flat/order amount matches within one option use the highest charge. Different options and per-shipment calculated rates add. App-provided rates add. Included marks a covered shipment, not an absent shipment.
- [Upgrading shipping](https://help.shopify.com/en/manual/fulfillment/setup/shipping-options/whats-changing-with-shipping), read 2026-10-11. Rollout is gradual. Profiles versus market-organized Shipping options identifies the active system; use that evidence, not calendar assumptions.

Analysis practice: distinguish a reconciled total from a proved carrier quote cause; keep unknown allocation conditional. This is an evidence-handling convention, not a Shopify policy.
