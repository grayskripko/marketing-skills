# Privacy: Shopify Shipping

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG; it supplies no executable scripts, dependencies, installers, hooks, MCP/LSP servers, connector or background service. The skills analyze only material you explicitly supply and bundled references, without directing code execution, API calls, message delivery, publishing, account writes or file creation. Source links are citations, not automatic retrieval instructions. A separate request for current documentation may use your assistant's browsing tool to retrieve public help.shopify.com pages; the source registers also request a publisher recheck before submission. These requests expose public URLs and ordinary connection metadata to Shopify and the browsing-tool provider, never cart or customer details. The settings-check skill recommends a merchant-led new checkout stopping before payment: you inspect settings and test your storefront, which contacts the store and may involve its configured carrier/app rate services, then supply the observed rates. The assistant does not log in, operate checkout, change settings, place orders or buy labels. Missing documentation, quotes or checkout evidence must be supplied or left unresolved. Redact customer names, full addresses, order identifiers and credentials; a destination region normally suffices for manual rates. The publisher receives no task data through the plugin and operates no telemetry, collection or storage service. Your assistant provider controls processing and retention of conversations and attachments; any output file you separately request uses that assistant's existing file tools and your chosen destination, not a bundled program.
