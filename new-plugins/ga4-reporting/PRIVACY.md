# Privacy — GA4 Reporting

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, a static SVG icon and development documentation; it bundles no executable program, dependencies, installer, hooks, MCP/LSP server or background process, and installation does not connect an account. The skills read only task text, attachments and local exports you explicitly supply plus bundled references; they do not direct web search, URL/robots.txt retrieval, API calls, account access, message delivery, publishing or settings changes. Source and support URLs are references, not retrieval instructions; re-export requests ask you to obtain the specified GA4 data yourself. Both skills allow local calculation using your assistant's existing calculation, code or spreadsheet tools if available, so this is not a strict no-execution workflow; the assistant provider manages tool execution and temporary files. Report files are created only when you request them, through the assistant's existing file tools at your selected destination, and are not sent by these skills. The publisher operates no server, collection, telemetry or storage service and receives no task data; your assistant provider processes and may retain conversations, attachments and tool activity under its own terms. Inputs can include client names, campaign labels, URLs and revenue; aggregate exports suffice, so remove unnecessary personal data and credentials before sharing. You control saved reports and can remove them or delete conversations using your provider's controls.
