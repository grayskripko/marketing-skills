# Privacy: Guest Reviews

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon; it bundles no executable code, dependencies, installer, hook, server or connector and directs no code execution, software installation or file writes. The assistant analyzes the reviews, messages, reservation facts, request history and readable files or attachments you explicitly supply, which may contain personal or dispute information; use aliases and redacted copies, exclude government IDs, health information and details about children or criminal history from outgoing drafts, and preserve originals. It is not strictly offline: both skills direct public-policy retrieval when current rules are requested, before preparing a filing for a later date, or when supplied policy text conflicts. The assistant's existing web tool may fetch only https://www.airbnb.com/help/article/2673, https://www.airbnb.com/help/article/3582, https://www.airbnb.com/help/article/546, https://www.airbnb.com/help/article/13 and https://www.airbnb.com/help/article/32, or an official Airbnb policy URL you supply, plus the site's robots.txt, honoring robots restrictions and limiting redirects to airbnb.com. Airbnb and the assistant's tool provider receive the requested URLs and ordinary connection metadata, never review text, reservation identifiers or evidence in these requests. If fetching fails, the skills use embedded rules, flag uncertainty and request current official text before treating an unresolved allegation as filing-ready. They do not call application APIs, access accounts, upload, submit, send messages, publish or change settings; described filing, review searches and own-review removal are actions you perform manually in Airbnb. The publisher receives no task data and operates no telemetry or storage service; conversation, attachment, tool activity and saved-output retention are controlled by your assistant provider. GitHub documentation and support links are references, not runtime destinations.
