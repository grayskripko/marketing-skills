# Privacy: Skill Checkup

This skills-only package contains Markdown instructions and references, JSON metadata and a static SVG; it has no executable program, installer, hook, server, connector, background process, telemetry or publisher-operated storage. The assistant reviews only text and files you explicitly supply (such as logs, paths, configurations and tool declarations), returns diagnosis and proposed patches as text, and does not run code or commands, install software, retrieve URLs, search the web, call APIs or MCP tools, send messages, write files or change settings. Source and support links are references, not automatically fetched endpoints. The skills do recommend user-led verification: host invocation and trace inspection, command help or corrected syntax, conditional `invalidate_tools_cache()` cache refresh, and fresh tool-list discovery before a read-only lookup. If you perform these checks, your host may execute commands or contact your configured MCP server or lookup service; destinations, disclosed request data and retention depend on your configuration, and the plugin supplies no endpoint or credentials. No task data is sent to the publisher by the plugin; your assistant provider processes and retains conversations and attachments under its own terms. Independently opening support links or submitting issues is separate. Redact credentials, personal data and private endpoints before supplying artifacts or posting issues; credentials are not needed for this review.
