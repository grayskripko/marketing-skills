# Privacy: Webflow Redirects

This package provides instructions, references, metadata and a static icon, with no executable helper, installer, connector, background process, telemetry or publisher-operated storage; development reviews and test records are not runtime components. Redirect review and CSV preparation process only supplied text, attachments and local files plus bundled references, without browsing, fetching URLs, API calls, account access, uploads, publishing or message delivery. The assistant may run its existing local code/file tools to parse CSVs, save and reparse your requested artifact, compare rows and count bytes; it installs no packages, and without code returns copyable CSV with parsing and size unverified. The skills guide user-performed Webflow exports, imports/recovery, publishing and browser checks, which connect to Webflow or the selected sites and can change the redirect set or publish other pending changes; Webflow's export/error email delivery is performed by Webflow, not the assistant. Source-register instructions to reopen official guidance before a future submission concern separate release maintenance: visiting the listed help.webflow.com and developers.webflow.com pages exposes ordinary request metadata to those sites and the browser/tool provider, without requiring the supplied map; the API-reference URL does not instruct an API call. The GitHub support link is user-initiated. The package sends no task data to the publisher; your assistant provider processes and may retain conversations, attachments, code execution and tool outputs under its own terms, and requested files remain at the chosen destination under its file-retention controls. Inputs may contain paths, domains, query values, business details and screenshot text; remove unnecessary personal information, tokens and private query values, and never supply passwords or API credentials.
