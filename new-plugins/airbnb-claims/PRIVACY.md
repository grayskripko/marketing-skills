# Privacy

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static icon; it provides no executable scripts, dependencies, installers, hooks, MCP/LSP servers, account connector, or background process. Its skills prepare drafts from pasted records and explicitly supplied files and attachments, which may include reservation details, guest messages, invoices and photographs; use aliases and omit unnecessary personal data and payment credentials. They do not direct code execution, installation, API calls, message delivery, claim submission, account changes or file writes. Only on your explicit policy-refresh request, your assistant's existing retrieval tools read official Airbnb policy URLs listed in the skill references or supplied by you, plus the site's robots.txt, respecting robots restrictions and following only airbnb.com redirects; those sources include Airbnb help pages, the Japan insurance summary and the historical terms PDF on assets.airbnb.com. Requests contain no guest records, claim details or identifiers; there is no web search, login or reservation/account-page retrieval, and failed retrieval uses pasted official policy text. Filing requests and contacting support are actions you perform yourself; the Resolution Center URL is not an allowed policy-fetch endpoint, and publisher/support links are references. The publisher operates no collection, telemetry or storage service and receives no task data; optional policy retrieval contacts Airbnb, while conversation, attachment and requested output-file retention remain governed by your assistant provider and its storage settings. Any saved output you explicitly request uses the assistant's existing file tools, not a bundled program; original evidence is preserved.
