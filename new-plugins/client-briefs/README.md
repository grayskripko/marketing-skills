# Client Briefs

Check client emails, discovery notes and a draft brief before quoting. For freelancers and small agencies, it produces a corrected brief, the decisions still needed and a client confirmation draft. Provide the project messages you want checked, notes and any existing brief. Include known deliverables and limits on budget, dates or services. No account connection or paid API is needed.

| Skill | What you provide | What you get |
|---|---|---|
| reconcile-client-brief | Brief and selected project records | Corrected brief with sources for disagreements |
| find-brief-decisions | Brief, notes and known constraints | Decisions that affect the quote |
| draft-brief-confirmation | Selected records and intended recipient | Editable client confirmation message |

## Try it

- “Check this brief against the discovery notes before I quote.”
- “These emails disagree about the audience. What does the client need to decide?”
- “Draft a confirmation email. The launch date is their target; we have not accepted it.”

Requests, suggestions and approvals stay separate. An unknown price, date or revision limit stays unknown. Internal notes stay out of client text. The assistant uses source labels and short passages so you can check a correction. It gives a usable draft before asking one necessary follow-up question.

These drafts are for you or the client to confirm. The assistant does not quote prices, interpret contracts, make binding agreements about the work, access a live inbox or send messages. For extra requests, use a workflow that compares the request with an approved agreement. Ask a qualified professional in the relevant jurisdiction to interpret legal terms.

## Data and network

Nothing is fetched. The assistant reads only text and readable files you supply for this project. A link does not supply the text; paste the relevant passage. There are no external destinations, dependency downloads, telemetry, credentials or background services. The package has no storage of its own. Your assistant provider's conversation and file handling apply. Remove unnecessary personal contact details before sharing.

If a file cannot be read, paste the relevant text with source labels and any dates or version names. The assistant can compare the supplied records. It cannot confirm that they include every project message.
