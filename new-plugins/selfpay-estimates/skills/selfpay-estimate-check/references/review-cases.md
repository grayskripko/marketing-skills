# Conditional review cases

Authority and dates: [source register](../../../references/cms-sources.md).

| Case | Review decision |
|---|---|
| Request before scheduling | Keep the request clock; later scheduling creates its own estimate obligation. |
| Under three business days to service | No scheduling-based estimate duty; inspect earlier requests before marking a document voluntary. |
| Multiple providers | Match subtotal to provider; do not declare a whole-episode total while separately billed fees are missing. |
| Provider changed less than one business day before service | Replacement must accept the replaced provider's relevant estimate. |
| No billing for any services on scheduled dates, or any services when unscheduled; no included co-provider care | Check abbreviated model eligibility and its required identity/provider/rights text using Part 4 Q2. |
| Mixed paid and no-cost services | Keep standard itemization; a zero-priced row does not make the whole estimate abbreviated. |
| Sliding-scale eligibility unresolved | Read Part 4 Q1; distinguish new-patient missing eligibility from established approved discount. |
| Supplied bill comparison | Threshold compares each provider's billed total with that same provider's estimated total; $400 is not permitted fee drift. Return the relevant estimate defect, not a dispute ruling. |
| Missing method-appropriate written-issuance evidence | Due date can be calculated; timeliness cannot be established. |

For no-cost and sliding-scale exceptions, open Part 4 Q1–Q3 before issuing corrected conditional text. These exceptions supplement the ordinary fee-based rules inline in SKILL.md.
