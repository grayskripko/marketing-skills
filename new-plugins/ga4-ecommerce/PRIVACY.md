# Privacy

Routine use reads the text and files supplied for the request and bundled reference files. It fetches nothing. A requested source refresh reads only the official Google Developers, Analytics Help and Firebase documentation URLs listed in each skill's references/field-rules.md, following their documentation redirects.

The plugin contains instructions and a static icon. It adds no telemetry, storage service or account connection. It does not send ecommerce events, upload orders or alter GA4, GTM or store settings. Responses and any files the user requests remain within the host's conversation and file handling.

Supply order facts without customer names, addresses, emails, credentials or payment-card data. Skills preserve nonpersonal order/item identifiers and avoid repeating personal data in corrected examples.
