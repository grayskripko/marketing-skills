# Privacy

Expense Exports supplies Markdown instructions and references, JSON metadata, and a static icon; it bundles no executable program, installer, connector, hook, or background service. It analyzes only task text and readable files you explicitly supply, which may contain expense IDs, amounts, dates, names, accounting fields, and ERP identifiers. Both skills permit optional retrieval through the assistant’s existing web tool of public Brex help pages linked in the source registers or supplied by you, and the registers instruct reopening relevant pages before the planned submission and when errors or UI differ. These requests disclose the requested URL and ordinary connection metadata to Brex and the assistant’s tool provider; private expense content, names, account identifiers, and credentials must never enter a request. This is network activity. The skills do not direct code execution, installation, web search, API calls, account access, message delivery, publishing, or account mutations; suggested mapping refreshes, imports, exports, field/form changes, and external-payment bill closures are user actions in Brex or the ERP. No file-writing tool is prescribed; explicitly requested output files use the assistant’s existing file tools. The publisher operates no collection, telemetry, or storage service and receives no task data. Processing and retention of conversations, attachments, tool requests, and generated files follow the assistant provider’s terms and workspace controls. Supply only necessary fields, alias unnecessary names, and never supply credentials. Development notes and evaluation records in this folder are not runtime components and belong outside the submitted release folder.
