# Privacy: GDPR Requests

This package contains skills, reference text and an SVG icon. It runs no service and includes no connectors or executable runtime code.

It reads only text and readable files supplied for the access-request task. These may contain customer identifiers, email/CRM histories, opinions, health or employment data, receipt dates and search logs. Use pseudonyms for unrelated people and supply only necessary fields. The purpose is to reconcile records, prepare disclosure proposals and draft a response.

Network scope: none. No web searches, URL fetches, account access, telemetry or external messages. Source URLs are citations. Updated official text must be supplied if needed.

The package stores no task data and defines no external recipients. The assistant provider processes supplied conversation and files under its own retention settings. Any output file saved at the user's request remains in that chosen location; it may contain personal data. Use the assistant's conversation/file deletion controls and delete local outputs when no longer needed.
