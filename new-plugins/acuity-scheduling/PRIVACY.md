# Privacy

This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon, and development records; it includes no executable program, dependencies, installer, hooks, MCP or LSP server, background process, or account connector. Installation does not run a program or connect an account. The assistant analyzes only task text and files you explicitly supply and reads bundled references; use anonymous appointment labels and omit client contact details, intake answers, and credentials. The skills do not direct code execution, software installation, API calls, account access, message delivery, or configuration writes. They do direct public documentation retrieval at `help.acuityscheduling.com` and help-article redirects when current rules need verification; the source registers also request re-opening relevant articles before relying on a different setting or submission date. These network requests disclose the requested help URL and ordinary connection metadata to the help site, any help-article redirect destination, and the assistant's tool provider, but do not upload supplied settings or exports or fetch booking links or account endpoints. GitHub publisher, repository, and support links are references, not retrieval instructions. Account changes and scheduler checks remain user-performed recommendations. The publisher receives no task data and operates no telemetry, collection, or storage service; conversation, attachment, and retrieval retention follow your assistant provider's terms. Any output file you explicitly request uses the assistant's existing file tools and remains under your control.
