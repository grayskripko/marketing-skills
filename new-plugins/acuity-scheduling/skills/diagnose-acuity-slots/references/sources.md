| Source and displayed update | Deciding knowledge and setting path |
|---|---|
| [Booking limits](https://help.acuityscheduling.com/hc/en-us/articles/27141282369037-Limit-when-clients-can-book-edit-or-cancel-their-appointments), updated 2026-06-24; read 2026-10-11 | Calendar/group equivalents replace global limits. Availability → Global Scheduling Limits has Minimum Hours and Maximum Days. Availability → Edit Availability/Limits → Calendar Scheduling Limits has local booking windows, concurrent capacity, Max hours per day, Max number per day and Max number per week. Zero minimum hours allows booking until just before start. Cancellation/intake limits are separate from new-booking restrictions. |
| [Overlapping appointments](https://help.acuityscheduling.com/hc/en-us/articles/16676952402957-Using-overlapping-appointments-and-double-booking-in-Acuity-Scheduling), updated 2023-11-09; read 2026-10-11 | Appointments per time slot permits simultaneous/staggered appointments. Availability groups cannot overlap each other on a calendar. Classes still block ordinary appointments there. Negative padding permits partial overlap. Setting: Availability → Edit availability/limits → Calendar scheduling limits. |
| [Missing appointment times](https://help.acuityscheduling.com/hc/en-us/articles/16676931784333-Fix-availability-issues-and-missing-appointment-times), updated 2026-08-07; read 2026-10-11 | Check duration/padding, busy events, resources, groups and override hours. Appointment details identify resources in use; Calendar → Day View → Show separate columns for type availability exposes group conflicts. Look Busy hides random available starts; Minimize Gaps offers starts adjoining existing appointments. Daily/monthly next-availability display horizons: 90 days/18 months. Private types and restricted calendar/category links affect visibility. Online-scheduling-unavailable message suggests private types. Classes need explicit sessions; past-first-session series are hidden. |
| [Padding](https://help.acuityscheduling.com/hc/en-us/articles/16676926857101-Adding-padding-between-appointments), updated 2025-12-22; read 2026-10-11 | Before/after buffers add between appointments. Before-padding is ignored at the first start of an availability window. Duration plus applicable padding must fit. Client duration and Acuity appointments synced out to external calendars omit padding; imported busy events are separate intervals. Appointment types → Edit → Block off time before or after appointment; values are minutes. |
| [Resources](https://help.acuityscheduling.com/hc/en-us/articles/16676949567757-Use-resources-to-limit-bookings), updated 2026-09-25; read 2026-10-11 | Shared capacity spans calendars, but not different time zones. All required resources must be available. Positive padding holds resources; negative padding does not shorten base-duration use. A scheduled class uses one unit even without bookings; canceling attendees does not remove that scheduled resource use. Resources cannot prevent simultaneous classes, so separate calendar/resource feasibility from actual equipment capacity. Type-specific unit quantities require Customer Support enablement. Availability → Rooms/Resources; appointment types → Edit → Resources assigns types. |
| [Start intervals](https://help.acuityscheduling.com/hc/en-us/articles/16676924846733-Controlling-start-time-intervals-in-Acuity-Scheduling), updated 2024-11-18; read 2026-10-11 | Automatic interval is greatest common divisor of base durations per calendar/group; add-ons excluded. Custom interval applies globally. Busy time hides starts without recalculating their grid. Availability → Global scheduling limits → Start time intervals. Comma-separated starts permit irregular schedules. |
| [Basic availability](https://help.acuityscheduling.com/hc/en-us/articles/27016341585421-Setting-and-editing-your-basic-availability), updated 2025-12-22; read 2026-10-11 | Availability → Edit Availability/Limits: weekly hours or specific-day hours. With regular hours disabled, blank specific dates cannot be booked. Hours accept ranges, individual starts or both. Weekly day field: 250 characters; specific-day field: about 760 characters. Apply these field limits if a proposed hours entry is too long; preserve “about” for the latter. |
