# Privacy: CSAT Analysis

These skills process only authorized text, attachments and readable local files you explicitly supply, and permit the assistant's existing tools to read those files and perform local calculations, which may execute code and create host-managed temporary files. They forbid fetching URLs (including supplied URLs), web search, installation, API calls, account connections, sending, publication and ticket changes; Zendesk/source/support links are references, not endpoints these skills contact. The publisher operates no collection, telemetry or storage service and receives no task data through a plugin service; your assistant provider processes and may retain conversations, attachments and tool outputs under its own terms, and requested output files remain in your chosen location. Remove credentials and contact details, use stable anonymous case IDs, and keep identifying mappings outside the conversation. This working folder additionally includes development-only `tests/run.py`: manually running it launches the installed Codex CLI, submits test prompts and skill text to its configured model provider for generation and judging, and writes evaluation inputs, traces, answers and JSON files under `tests/`; no skill or manifest invokes it. Move tests and development records outside the submitted plugin folder before submission. This is supplied-material analysis with host computation, not a promise of no code execution or that the assistant provider runs offline.
