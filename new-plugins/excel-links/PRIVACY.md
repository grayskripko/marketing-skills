# Privacy

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG; it has no executable program, installer, dependency, hook, MCP/LSP server, background process or account connector. The assistant analyzes supplied formulas, exported entries, errors and screenshot descriptions and reads bundled references locally; the skills direct no assistant code execution, installation, web search, URL retrieval, API calls, message delivery, account access or workbook writes. Supplied paths and URLs are evidence only; Microsoft and GitHub links identify sources or support, and the dated pre-submission recheck is publisher maintenance guidance. The repair guidance asks you to use Excel to open, inspect, back up, edit, recalculate, refresh, convert, break links, save and reopen workbooks, and where appropriate set a workbook refresh-on-open preference. Those user-led actions can write local files, contact the cloud/network/query sources configured in your workbook, and transfer workbook contents when saving to cloud storage through your Excel account; their destinations and data depend on your configuration, so following the guidance is not universally network-free. The publisher operates no collection, telemetry or storage service and receives no task data through this plugin. Conversation processing and retention follow your assistant provider's terms, and Excel/cloud activity follows those providers' terms. Use redacted aliases for personal names and paths; credentials are unnecessary and must not be supplied.
