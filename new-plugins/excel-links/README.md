# Excel Links

Find why Excel still asks for another workbook, and choose a repair that preserves the intended calculations.
For people diagnosing Excel workbook links and preserving useful calculations.
Needs pasted formulas, exported names or link entries, exact errors, or screenshots described in words. No accounts, keys, installs or paid APIs are required for analysis.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account. The `.claude-plugin` and `.codex-plugin` directories contain platform metadata, not connectors.

The assistant analyzes only pasted formulas, exported names or link entries, exact errors, and screenshots described in words, using packaged references read locally. The skills do not direct the assistant to run code, install software, search the web, fetch URLs, call APIs, send messages, access accounts, or write workbooks. Workbook paths and supplied URLs are evidence, not destinations to open; paste the relevant content instead. Microsoft source URLs and GitHub documentation/support URLs identify references, not automatic retrieval endpoints. The reference notes' pre-submission recheck is publisher maintenance guidance, not a task-time fetch instruction.

The guidance also asks **you to operate Excel**: inspect formulas, names, objects, charts and connections; open source/destination workbooks; make backups; change sources or formulas; recalculate and refresh; convert formats or break links for a chosen snapshot; save, close and reopen; and adjust an appropriate workbook refresh-on-open preference. These actions can write local files. Opening or refreshing cloud, network-share or query sources can contact the configured source services, and saving back to a cloud location transfers workbook contents through your Excel account. Destinations and data depend on your workbook paths, queries and account configuration; this package supplies no fixed endpoint or credentials. The assistant returns a plan and relies on your observed results; it does not execute these actions. This is offline analysis with user-led Excel operations, not a promise that following every repair step uses no network.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider processes and may retain the conversation under its own terms; user-led Excel/cloud operations follow those services' terms.

- **Find workbook links:** inventory external dependencies in formulas, names, objects, charts and connections; explain the supported cause and the next targeted inspection.
- **Repair workbook links:** plan source changes, review refresh and security behavior, or choose an intentional snapshot with break-link consequences and verification steps.

Ordinary hyperlinks navigate to a page, file or workbook location; they are listed separately from dependencies that supply calculation or query data. A HYPERLINK formula may also contain an external workbook reference, which belongs in the dependency inventory.

The assistant can walk you through Excel's native inspection and repair controls. Performing those steps requires your own Excel access; this package supplies instructions, not a live connection or automatic editor. Windows and web behavior are distinguished. Excerpts cannot establish that an entire workbook is free of dependencies.

Analysis uses supplied text and bundled Microsoft references. Do not paste credentials or unnecessary personal folder details. Use workbook aliases where possible.
