# Provider settings sources

Read the [source register](../../../references/official-sources.md) for exact URLs, read dates, freshness and conflicting catalogs. For SentenceTransformer prompts/token limits use the API and Matryoshka pages; for Voyage fields use the API plus current model guide; for Gemini use both the current model guide and REST field reference. For supplied Voyage errors use its error-code page. No credential or provider call is needed to review pasted settings.
