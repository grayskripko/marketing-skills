# Vector representation sources

Read the [source register](../../../references/official-sources.md) for exact URLs and dates. Voyage API/current guide define packed output and model compatibility. Gemini guide defines the incompatible spaces and model-specific normalization. Qdrant collections defines named fields and automatic Cosine normalization. SentenceTransformer API, semantic search and Matryoshka pages distinguish output truncation from token handling and score normalization.
