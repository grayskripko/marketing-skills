# Privacy

SPC Charts is a skills-only package of Markdown instructions and reference text, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, installers, hooks, MCP/LSP servers or background processes, and installing it runs no program and connects no account.

The skills work only on data you provide for this task: values or table text you paste, or the export you name or attach for this request. They do not scan folders or projects, read every attachment, or use memory, chat history, conversation summaries or Claude conversation exports. They make no network requests: no web search, URL fetching, uploads, downloads, API calls or telemetry. When your assistant can run local code, the skills may compute and plot in a local script with the assistant's existing tools and save output where you ask; the execution location and retention of generated scripts and outputs depend on your assistant provider and host tools.

The publisher receives no data from this plugin and runs no collection, telemetry or storage service. Your conversation and attachments are processed and retained by your assistant provider under its own settings. Do not include personal data that the analysis does not need; operator names can be replaced with stable labels.
