# Privacy: Voice Note Cleanup

This package contains instructions, reference text and a local icon. It has no executable code, transcription engine or service.

- Data read: supplied dictation, transcripts, reply context and speaker-authored style samples. These may contain names, professional history, opinions and sensitive information.
- Purpose: clean up the supplied words or adapt them into the requested draft in the current conversation.
- Recipients: the assistant provider you already use, under its own terms. The plugin does not transmit text to another service.
- Network scope requested by these skills: none. They instruct the assistant not to fetch URLs, search the web, access accounts or call additional services. The package has no network integration or telemetry. Audio transcription by a separate recorder or assistant is outside this package and has its own processing terms.
- Retention: the plugin stores nothing itself. The assistant's conversation and file retention applies.
- Controls: share only what the task needs; redact contact details, credentials and unrelated personal information. Output replaces private contact details with markers. You can delete the conversation or uploaded files using your assistant's controls.
