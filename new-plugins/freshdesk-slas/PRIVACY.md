# Privacy: Freshdesk SLAs

The package contains instructions, reference text and an SVG icon.

It reads pasted text and local exports the user selects. Those inputs can contain ticket IDs, timestamps, customer details, agent information, policies and internal support schedules. The purpose is SLA target conversion and ticket deadline reconciliation. Customer names, email addresses and message bodies are unnecessary; use ticket labels and event types.

Network fetches: none during skill use. Inputs are processed by the user's AI assistant under that assistant's data handling and retention settings. The package has no telemetry, external recipient, data store, credential handling or account connection. Local output files are created only when requested. Users control the supplied files and conversation deletion through their assistant.
