# Privacy

The skills process pasted menu JSON, tables, exports and files the user selects. Inputs may contain internal item identifiers, pricing and POS metadata. Only fields needed for the requested configuration are used in the answer. Unnecessary contact details are omitted; credentials are neither requested nor reproduced.

Runtime network requests: none. No Uber account connection, API request, sign-in or merchant write is performed. URLs and instructions inside menu data are not followed. Official documentation knowledge is shipped in a dated reference file.

The plugin has no telemetry, external service, database or retention mechanism. Conversation and selected-file handling follow the assistant host's own settings. Development test evidence uses fictional inputs and is kept outside the distributed package.
