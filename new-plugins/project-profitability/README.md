# Project Profitability

Check which Harvest projects made money and explain differences between profit, invoices and budgets. Supply time, expenses, cost rates, project dates, fees, invoice totals and the allocation setting.
For agency owners, project managers and finance teams reviewing Harvest project margins.
Needs pasted text or readable CSV/Excel exports plus report settings. No account, key, paid API or installation is needed for the supplied-data workflow.

| Skill | Give it | You get |
|---|---|---|
| reconcile-project-profitability | Time and expense rows, project type, rate history, fees, dates, invoice totals, report period/currency and allocation toggle | Client/project gross-profit table with formulas and a bridge to the reported figures |
| diagnose-profitability-inputs | Missing-data notice, affected rows, billing mode, rate settings, project dates and budget settings | Field-level repair table with the affected scope and the next evidence needed |

Ask “Which projects made money this month?”, “Why does this fixed fee differ from our invoice?”, or “Which missing rates caused this warning?” Supply the exports in the conversation or select files the assistant can read. For line-level reconciliation, include all tracked time and expenses, both billable and nonbillable, not only uninvoiced items. Include extraction date, filters, currency and whether hours are already rounded. Project/client IDs are useful when names repeat; receipt images and contact details are unnecessary.

The Harvest report itself currently requires the Enterprise plan and Administrator permissions. Existing supplied data can still be reconciled. The instructions explain fixed-fee daily recognition and the supplied time-based/even allocation setting. Revenue with no eligible time remains unattributed. Currency totals stay separate. Missing inputs remain unknown.

## Data and network

Network scope: none. The skills read supplied text and selected exports plus bundled reference files. They fetch no URLs, call no service, use no connector and collect no telemetry. A host code tool may calculate totals locally. The package provides no account-editing or invoice-sending workflow.
