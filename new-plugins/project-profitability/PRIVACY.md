# Privacy: Project Profitability

This package contains skills and reference text. It operates on text pasted into the conversation and files the user selects for the assistant to read.

Inputs may contain client/project names, teammate identifiers, hours, expenses, internal cost rates, fees and invoice amounts. Contact details and receipt images are not needed. Answers use only the identifiers needed to trace a finding and omit unrelated personal details.

Network scope: none. No URLs are fetched, no account is accessed, no connector or paid API is used, and no telemetry is collected. The package runs no external service and has no storage of its own. Conversation and file handling follow the assistant host's settings. Local calculations may use the host's code tool. A saved result is written only when the user asks to save it.

Support: https://github.com/grayskripko/marketing-skills/issues
