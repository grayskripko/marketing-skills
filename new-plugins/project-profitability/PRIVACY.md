# Privacy: Project Profitability

This skills-only package contains Markdown instructions and references, JSON metadata, a static SVG icon, and development/evaluation records; it bundles no executable program, installer, hook, connector, server, or background process. The skills analyze only text, attachments, and selected local files you supply plus bundled references, and permit the assistant's existing local calculation/code tools to compute totals and its file tools to save results only when requested; execution and temporary files are managed by your assistant provider. Supplied-data analysis does not fetch URLs, search the web, access Harvest accounts, call APIs, send messages or invoices, publish content, or change settings. Both bundled reference registers instruct a public-source refresh before the planned 2026-10-19 submission, which entails retrieving their nine listed Harvest help pages as separate preparation, not automatic task-data retrieval. Source links are citations; the GitHub support link is an issue tracker you may open separately. The publisher operates no plugin collection, telemetry, or storage service and receives no task data through the plugin; conversation, attachment, execution, and temporary-file retention follow your assistant provider's terms, and requested output files remain under your control. Inputs may contain project/client names, teammate identifiers, hours, expenses, rates, fees, and invoice amounts; omit credentials, unnecessary personal details, contact information, and receipt images. Answers retain only identifiers needed to trace findings.
