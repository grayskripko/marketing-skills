# Privacy: MTD Income Tax

This skills-only package contains instructions, public reference text, JSON metadata, a static SVG icon and development/evaluation records; it bundles no executable program, installer, hook, server or connector. It is not offline-only: the assistant's existing web tool may retrieve public HMRC guidance on `www.gov.uk` for current-year, eligibility, conflicting wording or amendment checks and the linked software finder on `www.tax.service.gov.uk/find-making-tax-digital-income-tax-software/how-to-find-software` for setup help, following redirects only within these hosts. These requests disclose the public URL and ordinary connection metadata to those sites and the tool provider; supplied user records must never enter requests or search queries. Existing file tools may read user-designated exports, write explicitly requested pack files, and edit an actual source file only after user authorisation in the repair workflow. The skills do not direct code execution, installation, submission API calls, account connections, credential handling or message delivery; software authorisation, imports, corrections and submissions are user-led actions in compatible software. Inputs can contain financial information: use neutral labels and row references, and remove tax identifiers, bank account numbers and credentials before supplying material. The publisher receives no task data and operates no telemetry, collection or storage service; conversation, attachment and tool retention follow the assistant provider's terms, while local outputs remain under your control. GitHub support links are informational, not retrieval instructions; avoid putting financial records or secrets in public issues. Support: https://github.com/grayskripko/marketing-skills/issues
