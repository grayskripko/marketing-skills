# Privacy: Statuspage Updates

The package contains skills and reference text. It reads incident notes, timelines, component names, metrics and recovery observations that you paste or supply as files. These may contain staff or customer names; remove personal details and credentials before supplying them.

Purpose: prepare incident drafts and assess proposed states in the current conversation. Data is processed by the assistant hosting that conversation. The package has no service, storage, telemetry or additional recipient. Conversation retention follows the hosting assistant's settings; its conversation controls manage deletion.

Network scope: none. No URLs are fetched at runtime, no searches run and no Statuspage account is read or changed. Bundled sources were retrieved during development. No account, API key or paid service is required for drafting.
