# Privacy

Turn paired OpenAPI exports or an exported diff into a consumer-impact matrix and migration checklist.

This skills-only package contains instructions, reference text and an icon. It runs no service and ships no executable helper.

- Inputs: pasted contracts, attached exports, change reports and consumer notes. These may contain internal endpoint names, contact details and example payloads. Credentials are not needed; omit tokens and personal payload data.
- Purpose: compare supplied contracts and prepare consumer migration work in the current conversation.
- Processing: the assistant reads supplied text/files and bundled references. Its provider processes the conversation under the user's existing service settings.
- Network fetches at runtime: none, including remote schema references. No connectors, API calls, telemetry, uploads or additional recipients.
- Storage: the package creates no database or retained copy of inputs. Assistant conversation/file retention follows the host's settings. Save reports only when the user requests a file.
- Controls: redact unnecessary personal data and secrets before providing exports; use the host's conversation and file deletion controls.
