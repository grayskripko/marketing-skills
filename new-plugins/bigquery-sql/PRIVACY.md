# Privacy: BigQuery SQL

This skills-only package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, and development notes/test records; it provides no executable program, installer, hook, server or database connector. Its main workflow drafts SQL and diagnoses supplied differences from your SQL, schemas, errors, exports and screenshot descriptions, without executing SQL or accessing a warehouse. It is not strictly offline: both skills permit public documentation retrieval through the assistant's existing web tool from docs.cloud.google.com or docs.snowflake.com and their redirects; source registers also request publisher freshness checks before submission. Your SQL, results and private identifiers must not be included in retrieval requests, but documentation sites, redirect destinations and the tool provider receive the requested URL and ordinary connection metadata. Optional requested dry-run guidance is user-led in your own BigQuery console: you send the query to Google BigQuery using your account and table permissions for syntax/type validation and a bytes estimate, without result rows; the assistant does not collect credentials or execute it for you. The skills do not direct installation, other API calls, message delivery, publication, settings changes or file writes; separately requested output files use the assistant's existing file tools. The publisher receives no task data and operates no telemetry, collection or storage service. Your assistant provider controls conversation, attachment and tool retention; you control requested output files. GitHub links identify the repository/support page and do not direct automatic retrieval or issue submission. Redact unnecessary personal data and never supply credentials; bundled references support drafts without retrieval, and you can supply current documentation text where needed.
