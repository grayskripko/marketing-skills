# Privacy: YouTube End Screens

This skills-only package contains instructions, bundled reference text, JSON metadata, a static SVG icon and text/JSON development records; it includes no executable program, dependencies, installer, hooks, MCP/LSP server or background process, and installation does not connect an account. The assistant reads supplied endings, upload metadata, settings, export rows and screenshot descriptions to prepare an editor handoff or diagnosis. The skills do not direct code execution, software installation, API calls, file writes, message delivery, publishing, video retrieval, upload discovery, login or account changes. They are not strictly offline: when Studio conflicts with stored rules, the assistant may refresh only https://support.google.com/youtube/answer/6388789?hl=en, https://support.google.com/youtube/answer/9527654?hl=en and https://support.google.com/youtube/answer/9054257?hl=en, with no task data included in those requests; requests go to Google through the assistant's browsing tools or provider. Supplied target URLs/IDs are planning inputs; repository, documentation, privacy and support links are informational. The creator/editor performs the proposed YouTube Studio edits, previews and saves, video-editor artwork changes and YouTube app/desktop playback and destination checks; the plugin does not perform them. The publisher operates no collection, telemetry or storage service and receives no task data from this plugin. Your assistant provider processes and may retain conversations and attachments under its own terms. Unpublished titles and transcripts can be sensitive: supply only necessary material, redact personal contacts, and provide no passwords or tokens.
