# Privacy

This skills-only package contains Markdown instructions and references, JSON metadata and a static SVG; it supplies no executable program, installer, dependency, hook, MCP/LSP server, account connector or background process. Reviews use only task text and files you explicitly supply, but both skills permit public-document retrieval from www.irs.gov or help.givebutter.com and their necessary public source links when current-rule verification is needed, using the assistant's existing browsing tools. Donor identities, gift records and account settings must never be included in those requests. The skills do not direct code execution, software installation, API calls, file writes, account changes, account tests or message delivery; suggested Givebutter setting repairs, tests and resends are actions for an authorized user. The publisher receives no task data and operates no telemetry, collection, storage or retention service; the assistant provider processes and may retain conversations and attachments under its own terms, and browsing contacts the referenced public sites. Supply only necessary rows and redacted gift references, omit credentials, card details, addresses and unrelated contact data, and include personal information in output only where needed for the requested acknowledgment.
