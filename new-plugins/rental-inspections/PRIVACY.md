# Privacy: Rental Inspections

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon, with development notes and evaluation records currently alongside them; it bundles no executable scripts, dependencies, installers, hooks, MCP or LSP servers, connectors or background processes, and installation does not run a program or connect an account. The assistant reviews pasted material, attachments and explicitly selected local exports; use aliases and omit unnecessary tenant names, addresses, signatures and credentials. October 2026 reviews need no network requests, but date-sensitive later reviews, including inspections or decisions on or after 30 November 2026, may use the assistant's existing browsing tools to fetch listed official sources and necessary gov.uk or legislation.gov.uk guidance/instrument pages and those sites' robots.txt, with redirects restricted to those domains and robots restrictions respected; searches use public instrument titles and dates only, or you may supply current official text instead. These requests disclose public URLs, public search terms and ordinary connection metadata to visited sites, the search service and the assistant tool provider; private report content, tenant details and case context must never be included. The skills do not direct code execution, installation, API integrations, account access, file writes, message delivery, publication or settings changes; landlord notification, delivery and retention duties are recommendations to review, not actions performed by the assistant. The publisher receives no task data and operates no case database, collection, telemetry or storage service; conversation, attachment and tool-activity processing, retention and deletion are governed by your assistant provider's terms and settings.
