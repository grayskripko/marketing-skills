# Privacy: YouTube Analytics

These skills analyze only the text, Studio exports, local files and readable screenshots you explicitly supply; all three permit the assistant's existing local tools to read those files and calculate results, which may involve host code or spreadsheet execution and provider-managed temporary files. They forbid web search, URL retrieval, account access, API calls and dependency downloads, request no credentials, and direct no source-file edits, channel changes, publishing or message delivery. Source and support URLs are references, not retrieval instructions; creator feedback requests in an experiment brief are advice, not messages sent by the assistant. The publisher operates no service, telemetry or storage for this workflow and receives no task data through it; your assistant provider controls processing and retention of conversations, attachments and tool activity. Remove personal viewer details and credentials before sharing. This working folder also includes historical evaluation records and two development harnesses (`tests/round3-20261010/harness-original.py` and `harness-retest.py`), neither invoked by skills or manifests: manually running them launches the installed Codex CLI with existing developer authentication, sends test prompts and skill text to its model service, and writes local results and temporary files. Those scripts and evaluation records must be kept outside the submitted package before making a no-executable-code claim.
