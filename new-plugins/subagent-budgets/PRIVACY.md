# Privacy

This skills-only package contains Markdown instructions and reference text, JSON platform metadata, and a static SVG icon; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes, or connectors. Its skills analyze only task text, attachments, and local files you explicitly supply and return usage reports or written budget/configuration proposals; they do not run code, install software, search the web, fetch URLs or robots.txt, call APIs, access accounts, launch or cancel workers, change configuration or account settings, send messages, publish content, or write to external services. Source and support URLs are references, not retrieval instructions or connection endpoints; paste relevant content for a supplied URL. The publisher receives no task data and operates no collection, telemetry, or storage service. Your assistant provider processes and may retain conversations, attachments, and host logs under its own terms; any output file you explicitly request is created by its existing file tools, not a bundled program. Remove credentials and unnecessary personal data before supplying logs; reports must not reproduce secrets or unnecessary personal data.
