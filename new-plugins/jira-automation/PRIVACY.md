# Privacy

This package contains Markdown instructions and public reference notes, JSON platform metadata and a static SVG icon, plus text-only development records; it provides no executable program, installer, hook, server, account connector, telemetry or publisher-operated storage. It is not strictly offline: both skills may use the assistant's existing web tool to retrieve relevant public documentation from `support.atlassian.com` and `developer.atlassian.com`, with official redirects limited to those hosts, including verification of unfamiliar syntax or changed facts. These requests expose the documentation URL and ordinary connection metadata to Atlassian and the assistant's tool provider, not supplied exports, logs or private endpoints. The skills analyze only task material you supply; they do not fetch private Jira sites, embedded or arbitrary user URLs, run code, install software, call APIs, connect accounts, write files, change Jira records or settings, publish or send messages. They may guide you to export flows (downloading a file), save configurations and create, enable, inspect and disable a diagnostic copy in Jira; real edits or notifications are user-operated under applicable authorization. Draft email, comment, creation and authenticated web-request actions remain proposed configurations. The publisher receives no task data through this plugin; your assistant provider processes and may retain conversations, attachments and web-tool activity under its own terms. Redact unnecessary personal information, credentials and private endpoints. GitHub source and support links are references you may open yourself, not skill connection endpoints.
