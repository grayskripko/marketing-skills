# Accounting Closing

Check a NetSuite period close checklist to see what blocks month-end close and what can happen next. Keep accounting-book, subsidiary, feature and preceding-period scope separate.
For controllers and finance teams using NetSuite. Needs pasted checklist text or local exports with book, subsidiary, feature and prior-period states. No account connection, keys or installation beyond the plugin is required.

## What this package runs and connects to

This is a skills-only package of Markdown instructions and reference text, JSON metadata, and a static SVG icon. It includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it does not run a program or connect an account.

The accounting workflows use only task text, attachments, and local exports that you explicitly supply, plus bundled local Oracle reference text. Neither skill directs code execution, software installation, web search, URL or robots.txt retrieval, API calls, message delivery, publication, or account changes. A supplied URL is treated as text: paste the relevant content instead. Proposed reopen, unlock and Quick Close steps are recommendations for the user, not actions performed by the plugin.

The bundled `oracle-close-rules.md` references include a release-maintenance instruction to recheck their 11 public Oracle NetSuite help URLs before the planned 2026-10-19 submission. That recheck involves opening public `docs.oracle.com` pages; it is not part of analyzing a user's accounting case and requires no NetSuite login or submission of case data. GitHub source, publisher and support URLs identify project pages, not account connectors.

The publisher receives no task data and operates no collection, telemetry, or storage service for this plugin. Your assistant provider still processes and may retain your conversation and attachments under its own terms. Any output file you explicitly request is created by your assistant's existing file tools, not by a bundled program.

| Skill | Request | Result |
|---|---|---|
| close-readiness | What blocks this close, and what can happen next? | Remaining work linked to prerequisites, with scope gaps and work evidence. |
| close-state-diagnosis | Why is this period unavailable, or what would reopening affect? | State explanation and a scoped next-step plan. |

Include the selected accounting-book filter, role-visible subsidiaries, enabled features, task statuses and preceding-period states. For an unavailable task, include its lock-tooltip or error text. Unknown values remain unknown. A partial export still produces a useful list with missing-evidence markers.

## Data and network

The skills read pasted text and local exports supplied by the user. Case analysis fetches nothing, uses no connectors and performs no account actions. The public-source release recheck is described above. Oracle knowledge is embedded in dated references. No telemetry or plugin storage. See [PRIVACY.md](PRIVACY.md).
