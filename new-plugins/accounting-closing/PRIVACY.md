# Privacy: Accounting Closing

This skills-only package contains Markdown instructions and reference text, JSON metadata and a static SVG icon, with no executable scripts, dependencies, installers, hooks, MCP or LSP servers, background processes or account connectors. Installing it runs no program and connects no account. Accounting analysis uses only user-supplied task text, attachments or local exports and bundled local references; neither skill directs code execution, installation, web search, URL retrieval, API calls, message delivery, publication or account changes. Proposed reopen, unlock and Quick Close steps are advice, not performed actions. The bundled Oracle references separately instruct a pre-submission release recheck of 11 public `docs.oracle.com` help pages; that maintenance retrieval needs no NetSuite login or case data. Supplied URLs are text, and GitHub project/support links are references rather than connectors. The publisher receives no task data and operates no collection, telemetry or storage service. Your assistant provider processes and may retain conversations and attachments under its own terms; requested output files use the assistant's existing file tools, not a bundled program. Inputs may include financial amounts, subsidiary names, book states, employee names and transaction identifiers: omit credentials and unnecessary personal identifiers before supplying them.
