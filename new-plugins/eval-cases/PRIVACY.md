# Privacy

Eval Cases uses only task text, attachments, and local files you explicitly supply. The package contains Markdown instructions and references, JSON metadata, a license, a static SVG icon, and development notes; it bundles no executable program, dependencies, installer, hook, MCP or LSP server, background process, or account connector. Its export skill instructs your assistant to use an available local parser on final JSON, JSONL, or CSV bytes and an available local schema validator for a supplied schema, which can execute local parsing or validation through the assistant's existing tools; it forbids dependency installation and remote schema resolution and reports unavailable validation. The skills write exports, review collections, and provenance sidecars only when requested, at your chosen local paths; otherwise they return conversation content. They direct no web search, URL or robots.txt retrieval, API calls, account access, message delivery, uploads, publishing, trace collection, agent replay, or runner execution. Public links identify sources and support pages, not runtime endpoints; supply relevant content rather than a URL to fetch. The publisher receives no task data and operates no server, telemetry, collection, or storage service for this plugin. Your assistant provider processes and may retain chats, attachments, and tool data under its own terms; local execution and files are managed by its existing tools, and requested exports remain until you remove them. Inputs may contain personal data, credentials, private paths, and confidential results: redact them before sharing; the skills redact before quotation or output, keep no reversible secret map, and mark incomplete fixtures for context or review.
