# Performance Review Draft

Draft performance reviews and self-assessments from dated work examples, with claims checked against sources and separate source notes when requested.

For managers and employees preparing a review. Supply the review period and selected notes or feedback you are authorized to use. Include role expectations and goals if available. Add your company template, approved ratings and rating definitions if you have them. No accounts, paid APIs or extra tools are required. Your assistant must be able to load plugin skills and read your text or files.

## What you get

| Skill | Give it | You get |
|---|---|---|
| assemble-review-evidence | selected dated notes, person, period and goals | internal evidence table with contribution, source and conflicts |
| draft-performance-review | examples, goals and company format | review or self-assessment in your format; separate source notes when requested |
| check-review-claims | draft and supporting records | corrected passages and unresolved claims with source locations |

Each skill works on its own. You do not need to run all three.

## Try it

- “Sort these dated notes against my review goals; keep team results separate.”
- “Write my self-assessment from these examples using our template.”
- “Check this review for claims about the wrong person or quarter.”

## Human review

Preparation for manager or professional HR review. Record the country or region whose employment law applies if supplied. Missing jurisdiction does not add a caveat to an ordinary draft. Inspect the linked source passages before using the draft. Supplied ratings stay unchanged. Conflicts are flagged for the person responsible for the rating. No invented ratings, compensation or promotion recommendations, termination decisions, disciplinary findings or performance improvement plans. Selected notes are not a complete performance record. This does not certify legal compliance or provide an independent audit.

## Data and network

Nothing is fetched. No web search, URL reading, HR information system or email connection, monitoring, sending, credentials or system writes. Paste text if you have only a URL. Supply readable files; unreadable scans need a checked text excerpt. The plugin is instructions and reference text, not a running service. It adds no telemetry or storage. Your assistant provider's processing and conversation retention apply.

Use selected authorized records instead of a whole mailbox. Redact contact details, health/accommodation information and unrelated employees. Source notes are for the person authorized to prepare the review. The plugin does not control who can access it. Keep source notes separate when sharing the review. Drafting keeps source links in working context unless you request notes; this is not a private store.
