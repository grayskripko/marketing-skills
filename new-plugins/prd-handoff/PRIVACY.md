# Privacy: Spec Handoff

This package contains instructions, reference text and an icon. It runs no service or executable code.

- Data read: authorized PRDs, stories, criteria, decision notes and textual design descriptions supplied for the task. These may contain staff names, customer information or confidential product plans.
- Purpose: compare documents and draft source-linked findings or proposed text edits.
- Recipients: the AI host you use processes your supplied material under its own terms. The package has no separate recipients, telemetry or service.
- Retention: the package stores no data itself. Host conversation retention and any user-requested saved output files still apply.
- Network fetches: none. Even linked documents must be supplied as readable text or files. No tracker connection, account, paid API or credentials are required.
- Controls: share only authorized material and redact personal contact details and secrets. Use the host's conversation and file controls to delete retained material.
