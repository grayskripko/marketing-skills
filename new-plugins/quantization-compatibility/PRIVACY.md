# Privacy

Check whether my checkpoint, quantization config, GPU architecture and backend/version work together.

Inputs are pasted text or files the user selects. Read only relevant metadata, configuration and supplied logs; do not load model weights or scan unrelated files. Keep credentials, private hostnames and personal identifiers out of the answer.

Evidence refresh reads public documentation on docs.vllm.ai, rocm.docs.amd.com and developer.nvidia.com and vLLM source/release pages on github.com or raw.githubusercontent.com, including official redirects, or an official source URL the user supplies. Send public page paths only. Never put checkpoint contents, private repository names, logs or secrets in requests or search queries. Offline use relies on bundled knowledge and supplied official exports.

The package has no telemetry, external storage, connector, account authentication or executable helper. It creates no persistent input log. Conversation and file retention follow the host's settings. No installation, weight conversion, inference or external write is part of these skills.
