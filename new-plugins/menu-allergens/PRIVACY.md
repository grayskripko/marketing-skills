# Privacy

This package contains skills and reference text. It reads pasted recipes, product labels, supplier exports, kitchen notes and user-selected files to prepare allergen matrices and handoff text in the current conversation. Customer names and health histories are not needed; keep handoffs tied to an order or dish rather than an identity.

Optional source refresh fetches public guidance from GOV.UK, food.gov.uk, foodstandards.gov.scot and legislation.gov.uk, including official redirects and linked official guidance. Searches use public rule terms only. Recipe text, supplier exports and customer details are never sent as search queries or to websites. No accounts, keys, connectors, telemetry or plugin storage. The assistant provider processes and retains conversation data under its own settings; the package operates no separate service. Delete uploaded files or conversations using the host’s controls.
