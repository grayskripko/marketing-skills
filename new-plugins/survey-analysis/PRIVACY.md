# Privacy: Survey Analysis

This package contains Markdown instructions and reference text, JSON metadata, a static SVG icon, a license, and build notes; it bundles no executable program, dependency, installer, hook, MCP/LSP server, or background process, and installation runs no program or account connection. All four skills analyze authorized pasted responses or supplied files, question wording, routing, codebooks, segments, and optional population data using the assistant's existing local file and calculation tools; calculations, CSV/XLSX creation and reopening, and requested chart rendering may execute host code and create new copies while leaving original inputs unchanged. No software installation is directed; unavailable tools mean readable inputs or equivalent pasted tables. The skills do not direct assistant web searches, URL or robots.txt retrieval, API calls, survey-account access, message delivery, publication, or settings changes. Qualtrics/AAPOR source links and GitHub repository/support links are references, not retrieval endpoints; supply relevant content rather than a URL alone. The export notes optionally ask the user to obtain a matching dictionary in their own Qualtrics account via Survey tab → Tools → Import/Export → Export survey to Word with Show Coded Values enabled; that user-led browser action contacts Qualtrics, while the assistant only reads the supplied artifact. The publisher receives no task data and operates no server, telemetry, or storage service; the assistant provider processes and may retain conversations, attachments, local tool results, temporary artifacts, and generated files under its own terms, including backups. Use pseudonymous IDs, redact identifying text, omit unsafe small-group detail, keep response-level coding separate from shareable reports, supply no credentials, and review outputs before sharing; manage generated copies and conversation retention through the host.
