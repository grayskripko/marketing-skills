# TikTok Permissions

Check what a TikTok permission request allows and whether its scope and expiry match your deal.
For creators and media teams reviewing Spark Ads requests or existing authorizations.
Needs a pasted request, agreed deal terms and, optionally, a redacted authorization export or selected local file. No account, keys, connector or installation beyond the skills package is required.

| Skill | Give it | Get back |
|---|---|---|
| check-tiktok-permission-request | Brand request, agreed terms, optional permission rows | Scope and expiry checklist before acceptance |
| reconcile-tiktok-authorizations | Redacted export, deal terms, planned ad dates | Rows needing action and known delivery boundaries |

Examples:

- “This brand asks for 365 days but our deal says 30 days from first delivery. What should I check?”
- “Only this post is licensed. Does their account permission request include new uploads?”
- “Compare these redacted rows with our agreement and tell me which ads need an earlier stop.”

The checklist separates platform access from agreed commercial rights. It checks post versus account permissions, caption and visibility effects, duration defaults, program-specific windows and supplied expiry errors. Platform timestamps, deal dates and planned delivery dates remain separate. Missing timezones or start events remain visible.

Remove code and QR-code columns before supplying an export. Codes are never generated, extracted, displayed or shared. Use row numbers or post labels instead. The package returns checklists; accepting invitations, changing permissions, linking accounts and operating ads remain outside its scope.

Network requests: none during skill use. The assistant reads the packaged references and only the text or local files you select. No telemetry, account calls, paid APIs or stored export copies. Official sources were verified on 2026-10-11 and are recorded in [platform evidence](references/platform-rules.md).
