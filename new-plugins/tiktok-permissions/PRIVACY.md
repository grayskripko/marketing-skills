# Privacy: TikTok Permissions

This package contains skills, reference text and an icon. It runs no service and includes no executable runtime or connector.

- Inputs: pasted requests, deal terms and user-selected local authorization exports. These may contain creator names, handles, post labels, advertiser names, fees and campaign dates.
- Purpose: compare permission scope and expiry with the user's supplied commercial terms and planned ad delivery.
- Codes: authorization and QR codes are unnecessary. Remove them before intake. If already supplied, skills omit them from output and never extract, transmit or share them.
- Recipients: the assistant provider processes supplied material in the conversation. The package instructs no upload or forwarding to any other service or person.
- Network requests: none during skill use. References are bundled. No account calls, searches, telemetry or paid API requests.
- Files and storage: only user-selected files are read. The package creates no export copies, persistent data store or background process. The assistant's conversation retention applies.
- Controls: redact unnecessary personal details, remove code columns and use post labels or row numbers. Conversation deletion follows the assistant's controls.
