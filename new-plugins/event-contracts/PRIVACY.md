# Privacy: Event Contracts

This skills-only package reads the event registers, sample payloads, error replies, and local exports you supply to prepare field corrections and implementation plans. Inputs can contain URLs, user identifiers, and free text. Replace personal values with representative values before sharing; account credentials are not needed.

Network scope: the assistant may fetch only public documentation URLs listed in skills/*/references/sources.md on support.google.com, developers.google.com, and firebase.google.com, following documentation redirects within those domains. It sends no pasted data, export contents, personal identifiers, or credentials in these requests. It calls no Analytics collection endpoint, account API, or connector. Local tools may count fields, lengths, and quota totals.

The plugin operates within your existing assistant conversation. The assistant provider processes that conversation. The plugin runs no service, retains no data, writes no account changes, and adds no telemetry. Any exported answer is created only at your requested destination. Your assistant's conversation retention and deletion controls apply.
