# Privacy

VAT Records contains Markdown instructions and references, JSON platform metadata and a static icon, with no executable program, dependencies, installers, hooks, MCP/LSP server, background process, connector, telemetry or publisher-operated storage service. The assistant reads workflow text, exports, formulas and screenshot descriptions you explicitly supply through its existing tools; that review needs no network request. The skills do not direct external requests or search memory, chat history or conversation summaries. Where current policy, a scheme exception or setup needs checking, the review identifies the relevant official reference for you or your accountant to verify. Supply relevant guidance and provider instructions as text. Client records, VAT numbers and credentials must never be included in URLs, queries, uploads or external requests. The skills do not direct code execution, installation, API calls, account access, messages, publication or edits to original records; HMRC API references describe filing software, not a plugin connection. Checklists propose accountant/bookkeeper-led imports, repairs in a retained copy, reconciliation and software-authority checks; authentication, authorisation and filing remain with the user/accountant. The publisher receives no task data. Your assistant provider controls processing and retention of conversations, attachments and tool activity; requested output files are handled by its existing file tools in your chosen location, with no plugin cleanup service. Supply anonymised samples and omit unnecessary identities and credentials.
