# Privacy: Help Articles

This skills-only package contains Markdown instructions and reference text, JSON platform metadata and a static SVG icon; it includes no executable scripts, dependencies, installers, hooks, MCP or LSP servers, or background processes. Installing it runs no program and connects no account. The skills use only task text, attachments and local files you explicitly supply, such as approved policies, articles, saved replies and ticket excerpts; they do not instruct code execution, software installation, web search, URL or robots.txt retrieval, API calls, sending, publication or account changes. Source and support URLs are references, not retrieval instructions; supply relevant passages as text. Your assistant may read supplied files or images with its existing readers and creates a local output file only if you request it, without overwriting originals; paste text if an input cannot be read. The publisher receives no task data and operates no collection, telemetry, storage service or connector. Your assistant provider processes and may retain conversations, attachments and outputs under its own terms; requested local files remain under your control until you delete them. Supply only authorized material and remove unnecessary personal data, private case details and credentials; stable ticket IDs can remain sensitive. Public drafts exclude private ticket details, while internal review notes share the same conversation or requested file and have no separate access controls.
