# Privacy

DOE Designs is a skills-only package: Markdown instructions and reference text, JSON platform metadata, a license and a static SVG icon. It bundles no executable scripts, dependencies, hooks, MCP or other servers, connectors or background processes, and installing it runs no program and connects no account.

The skills work only from factor lists, bounds, run sheets and other material you paste or explicitly supply. They make no network requests: no web search, URL or robots.txt fetching, API calls, uploads, downloads or telemetry. URLs inside your material are treated as text. If your assistant can run code, it may use its own local tools for calculations such as a seeded random run order; this package adds no tools.

The publisher receives no task data and operates no collection, telemetry or storage service. Conversation and attachment retention follows your assistant provider's settings. Do not paste credentials or personal data; experimental data you supply stays within your assistant session and any local files you choose to save.
