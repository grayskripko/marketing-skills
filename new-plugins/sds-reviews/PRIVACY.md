# Privacy

This skills-only package contains Markdown instructions, a reference file of official sources, JSON platform metadata, a license and a static SVG icon. It has no executable scripts, connectors, MCP servers, hooks or background processes. Installing it runs no program and connects no account.

The skills read only the SDS text, inventory lists, exports and label text you paste or attach in the conversation. They make no network requests: no web search, URL fetching, uploads, downloads or telemetry. Links in the files are references for the reader, not fetch instructions. Supplier questions are drafted as text; nothing is sent.

The publisher receives no data from your use of the package and operates no collection or storage service for it. Your assistant provider processes and may retain conversations and attachments under its own settings. Remove personal contact details from documents you share if they are not needed for the review.
