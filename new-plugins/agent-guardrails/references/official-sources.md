## Applied control decisions

For each action, keep policy, effective configuration and observed outcome separate. Match the principal, tenant, target and payload to a pre-effect decision. Inspect denial, expired permission, interruption, retries and handoffs. These are this plugin's operational rules of thumb derived from the documented control surfaces, not additional MCP or SDK requirements.

The proposed approval record can bind requester, approver, action, target, arguments, destination, policy version, expiry, decision and execution identity; select the fields needed for the user's action rather than requiring every field in every answer. A supplied site name is not necessarily its authoritative API ID, and publishing does not establish visibility. Recommend no-send checks conditionally unless that mode is supplied or confirmed. The matrix format, stop-on-unknown policy and record fields are this plugin's rules of thumb. No universal amount threshold or required approver role is asserted.
