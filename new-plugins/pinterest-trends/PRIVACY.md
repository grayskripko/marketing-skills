# Privacy

This skills-only package contains Markdown instructions and references, JSON platform metadata and a static SVG icon, with no executable program, dependencies, installer, hooks, MCP/LSP server or background process; installation runs no program and connects no account. Ordinary analysis uses only supplied topics, dates, values, regions, filters, images, screenshot descriptions, local exports and production constraints, plus bundled references; local reading, calculations or requested output use the assistant's existing tools, and the skills prescribe no code execution, installation, API calls, file writes, message delivery or account changes. This is not a strictly offline package: only an explicit documentation-refresh request permits the assistant's web tool to retrieve https://help.pinterest.com/en/business/article/pinterest-trends, https://help.pinterest.com/en/business/article/schedule-pins, https://create.pinterest.com/en-in/blog/leverage-seasonal-trends-moments/ and https://business.pinterest.com/en-au/pdf/2026-marketing-moments-guide/, their sites' robots.txt and redirects serving those documents; requests expose the requested URLs and ordinary connection metadata to those Pinterest sites, any document-serving redirect host (which may be Pinterest's content delivery host), and the assistant's tool provider, without uploading supplied trend data. If refresh is unavailable, dated bundled facts remain the fallback. No web search, assistant login, dashboard scraping, connector or assistant publishing is supported; browser collection and optional scheduling instructions are actions you perform yourself in Pinterest and may publish through your account. Movable event dates require separate verification or remain unknown, with no additional retrieval destination specified. The publisher receives no task data and operates no telemetry, collection or storage service; your assistant provider processes and may retain conversations, attachments and tool activity under its own terms and retention controls. Remove unnecessary personal data and account identifiers; never supply passwords, tokens or cookies. Support reference: https://github.com/grayskripko/marketing-skills/issues (not a skill connection endpoint).
