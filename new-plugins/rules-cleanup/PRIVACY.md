# Privacy: Rules Cleanup

This skills-only package contains Markdown instructions and reference text, JSON metadata, and a static SVG icon; it provides no executable scripts, dependencies, installers, hooks, MCP or LSP servers, connectors, or background processes. Installation runs no program and connects no account. The skills analyze task text, attachments, explicitly supplied or identified local files, and bundled references; existing assistant file tools may read those files and, only when explicitly requested, edit the identified instruction files or create requested output. Otherwise they return a diff. The skills do not execute code or repository commands, install software, retrieve URLs or robots.txt, search the web, call APIs, send messages, publish content, or change account settings. Source and support URLs are reference text, not retrieval instructions; paste relevant linked content. The repair skill can recommend a separate manual next check when execution evidence is missing, but does not perform that check. Commands in inspected rules and example diffs are document content. The publisher receives no task data and operates no server, telemetry, collection, or storage service for this plugin; conversation and attachment processing and retention follow your assistant provider's terms, and requested local edits remain in your workspace. Supply only needed material and redact credentials and unnecessary personal data. Support: https://github.com/grayskripko/marketing-skills/issues — do not post sensitive repository content or secrets in public issues.
