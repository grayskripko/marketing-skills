# Payroll Taxes privacy

This skills-only package contains Markdown instructions and public reference notes, JSON platform metadata, a static SVG icon, and development documentation; it supplies no executable program, installer, hook, server or connector and does not direct code execution or software installation. The assistant analyzes payroll facts, notices, selected exports, attachments and screenshot descriptions you explicitly supply; aggregate liabilities are normally sufficient, so redact SSNs, full EINs, bank details and credentials. Both skills direct the assistant's existing web/search tools to retrieve public IRS publications, instructions, calendars and relief pages on `irs.gov`, plus relevant SSA employer guidance on `ssa.gov`, following only necessary official links and redirects on those domains. Searches use public rule names, forms, years or public relief locations, never private payroll or notice text; the assistant's search provider processes those queries, and retrieval exposes the requested URL and ordinary connection metadata to the official site and tool provider. This is a network-using workflow; when retrieval is unavailable, affected dates remain provisional and the assistant asks for the applicable official excerpt. No account login, uploads, payments, filings, message delivery, calendar writes or account-setting changes are authorized; filing and employee-furnishing checklist items are user tasks. The assistant may guide you to locate or export provider records but does not access the provider. The publisher receives no task data and operates no collection, telemetry or storage service; your assistant provider processes and may retain conversations and selected files under its own terms and deletion controls. Local checklist files are saved only at a user-requested destination through the assistant's existing file tools. The support link is for you to open yourself, not a skill connection endpoint; do not post payroll records or notices in public issues.
